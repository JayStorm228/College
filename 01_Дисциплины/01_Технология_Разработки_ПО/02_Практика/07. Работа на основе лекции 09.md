# Работа на основе лекции 09: паттерны программирования

## Часть А. Тестовые задания
**1.** Что такое паттерн проектирования?

а) Готовая библиотека функций.  
б) Проверенная идея для решения типовой задачи.  
в) Обязательное требование для всех проектов.  
г) Конкретный алгоритм сортировки.

Ответ: Б

**2.** Сколько категорий паттернов выделяют?

а) 2 (порождающие и структурные).  
б) 3 (порождающие, структурные, поведенческие).  
в) 4 (порождающие, структурные, поведенческие, архитектурные).  
г) 5.

Ответ: Б

**3.** Какой паттерн гарантирует, что у класса только один экземпляр?

а) Фабрика.  
б) Строитель.  
в) Одиночка.  
г) Прототип.

Ответ: В

**4.** Какой паттерн позволяет менять алгоритм на лету?

а) Наблюдатель.  
б) Стратегия.  
в) Адаптер.  
г) Фасад.

Ответ: Б

**5.** Что из перечисленного является антипаттерном?

а) Использование паттерна Стратегия для выбора алгоритма.  
б) Класс на 1000 строк, который делает всё.  
в) Вынесение повторяющегося кода в функцию.  
г) Использование Фасада для упрощения интерфейса.

Ответ: Б
# Часть Б: Установление соответствий
| Паттерн     | Категория     | Какую проблему решает                               |
| ----------- | ------------- | --------------------------------------------------- |
| Адаптер     | структурный   | несовместимые интерфейсы                            |
| Наблюдатель | Поведенческие | Уведомления всех объектов об изменении              |
| Строитель   | Порождающие   | Создания объекта с множеством параметров            |
| Декоратор   | Структурный   | Добавить функционала без изменения исходной функции |
| Стратегия   | Поведенческие | Выбор необходимого алгоритма для задачи             |
# Часть В: Анализ ситуаций
**Ситуация 1.** Интернет-магазин должен уведомлять пользователей о появлении товара, на который они подписались. Какой паттерн подходит и почему?

Ваш ответ: Наблюдатель. Потому что с помощью такого подхода можно быстро оповестить всех пользователей об изменении базы магазина

**Ситуация 2.** Приложение для рисования позволяет применять к изображению фильтры: размытие, яркость, контраст. Пользователь может применить несколько фильтров в любом порядке. Какой паттерн подходит и почему?

Ваш ответ: Декоратор. Потому что функции можно выполнять в любом порядке и давать объекту новые свойства.

**Ситуация 3.** Приложение для заказа такси должно рассчитывать стоимость поездки разными способами: по километражу, по времени, по фиксированной цене. Пользователь выбирает способ расчёта. Какой паттерн подходит и почему?

Ваш ответ: Стратегия. Поскольку есть выбор алгоритма для выполнения задачи.
# Часть Г: Открытые вопросы на размышление
**Вопрос 1.** Объясните своими словами разницу между паттерном и антипаттерном. Приведите по одному примеру каждого.

Ответ: Паттерн - инструкция, как нужно выстраивать своё решение. Антипаттерн - пример, как их выстраивать не нужно
Пример: Фабрика, чтобы создавать различные объекты в одном месте. Как антипаттерн: класс швейцарский нож, который делает всё и сразу.

**Вопрос 2.** Ваш коллега говорит: «Давай используем паттерн Фабрика для создания каждой кнопки в интерфейсе». Объясните, почему это плохая идея и когда Фабрика действительно нужна.

Ответ: Для создания каждой кнопки нет смысла делать фабрику: каждая кнопка создаётся отдельно со своими свойствами, и каждый раз новую создавать не нужно. Фабрику хорошо использовать, когда нужно создать объекты другого типа. С фигурами, к примеру: фабрика хранит конструкторы разных фигур по их названию, и при обращении в фабрике - выдаёт новую фигуру с указанными свойствами.

**Вопрос 3.** Как паттерны проектирования связаны с принципами DRY и KISS? Могут ли паттерны нарушить эти принципы? Приведите пример.

Ответ: Паттерны проектирования наоборот, помогают следовать указанным принципам. Но только если применяется действительно правильный паттерн. Необходимо уметь правильно выбирать архитектурные решения.
