# Основные определения
- Коммуникация - процесс двустороннего обмена информацией, ведущий к взаимному пониманию
- Коммуникативная компетентность - способность устанавливать и поддерживать поддерживать контакты с другими людьми
# Основные функции коммуникации
1. Информативная
2. Интерактивная
3. Перцептивная
4. Эспрессивная
# Направления коммуникации
1. Сверху-вниз
2. Снизу-вверх
3. Горизонтальное
# Основные элементы коммуникации
1. Отправитель информации
2. Информация/Сообщение
3. Канал связи
4. Получатель
# Этапы коммуникационного процесса
1. Начало передачи
2. Воплощение идеи в слова/символф/сообщения
3. Передача информации через канал связи
4. Декодирование
5. Фидбек
# Виды коммуникаций
1. Формальные
2. Неформальные
3. Межуровневые
4. Горизонтальные
5. Межличностные
# Виды слушания
1. Нерефлексивное/Пассивное
	 - Умение внимательно молчать, не вмешиваясь в речь собеседника своими замечаниями.
2. Рефлексивное/Активное
	- Процесс расшифровки смысла сообщения
	- Выяснение, перефразирование, отражение чувств, резюмирование
# Типичные ошибки
1. Перебивание
2. Поспешные выводы
3. Поспешные возражения
4. Непрошенные советы
