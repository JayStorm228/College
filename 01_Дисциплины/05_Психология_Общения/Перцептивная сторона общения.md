# Понятие перцептивной стороны общения
- Перцепция - психологический процесс получения, обработки и интерпретации информации, поступающей через наши органы чувств с целью формирования целостного, осмысленного окружающего мира, событий, объектов, явлений.
- Аперцепция - исключительно из прошлого опыта

# Социальная перцепция
## Понятие социальной перцепции
- Социальная перцепция - частный случай перцепции, направленный на восприятие социальных объектов:
	- Других людей
	- Социальных групп
	- Самих себя в социальном контексте
	- Различных социальных ситуаций/явлений
## Задачи социальной перцепции
1. Понимание мотивов, намерений, эмоций, личностных качеств людей.
2. Осознание социальных ролей и статусов
3. Формирование представлений о группах
	- Стереотипы
4. Самовосприятие/Самооценка
## Функции социальной перцепции
1. Познание себя
2. Познание партнёров по взаимодействию
3. Установление эмоциональных отношений
4. Организация совместной деятельности
## Условия/факторы, влияющие на точность/адекватность оценки
1. Закономерности формирования первого впечатления
2. Влияние прошлого опыта, характера взаимоотношений, самооценки, личностных свойств взаимодействующих
