# Как выполняется программа на C++

C++ — **компилируемый статически типизированный** язык. Путь от текста до запуска:

```mermaid
flowchart LR
    A["Исходный код
    main.cpp"] --> B["Компиляция
    (g++)"]
    B --> C["Объектный файл
    main.o"]
    C --> D["Компоновка"]
    D --> E["Исполняемый файл
    main"]
    E --> F["Запуск: ./main"]
```

- **Статическая типизация** означает: тип каждой переменной известен на этапе компиляции. Многие ошибки — например, попытка сложить число со строкой — ловятся до запуска.
- Для сравнения: Python — интерпретируемый и динамически типизированный, типы выясняются уже во время выполнения. Rust, как и C++, компилируемый и статически типизированный.
- Команда компиляции: `g++ main.cpp -o main` — см. [[01. Введение в предмет#Компиляция и запуск программы на C++|раздел про компиляцию в лекции 01]].

# Структура программы

Минимальная программа выглядит так:

```cpp
#include <iostream>   // подключить стандартную библиотеку ввода-вывода

int main() {          // точка входа: с неё начинается любая программа
    // тело программы — операторы выполняются сверху вниз
    return 0;         // сигнал операционной системе: «завершилась успешно»
}
```

Ключевые правила:

- `#include <...>` — директива препроцессора «подключи заголовочный файл». Без него функции из этого файла для твоего кода «не существуют».
- `main` — единственная точка входа. Программа без `main` не запустится.
- `;` — конец оператора. `{}` — блок: тело функции, цикла или условия.
- `std::` — префикс стандартного пространства имён: `std::cout`, `std::string`.
- Комментарии: `//` — до конца строки, `/* ... */` — многострочные. Компилятор их игнорирует.

# Ввод и вывод

Потоки ввода-вывода живут в заголовке `<iostream>`:

- `std::cout << ...` — поток вывода. «Стрелка» `<<` направлена к потоку: данные уходят в консоль.
- `std::cin >> ...` — поток ввода. «Стрелка» `>>` направлена к переменной: данные приходят из консоли в переменную.

```cpp
std::cout << "Радиус: " << r << "\n";   // выводить можно цепочкой
std::cin >> r;                          // чтение до первого пробельного символа
```

> [!note] `endl` против `\n`
> `std::endl` делает две вещи: переводит строку **и сбрасывает буфер вывода**. `\n` только переводит строку. В циклах с большим объёмом вывода `"\n"` быстрее; `endl` нужен там, где важно показать текст немедленно.

Важное свойство `cin >>`: чтение останавливается на первом пробеле, табуляции или переносе строки. Чтобы прочитать строку целиком (например, имя с пробелом), нужен `std::getline(std::cin, s)` из `<string>`.

# Переменные и типы данных

Объявление переменной — это **тип, имя, значение**:

```cpp
double radius = 2.5;   // объявление с инициализацией
int count;             // объявление без инициализации
count = 3;             // присваивание
const double g = 9.8;  // константа: переприсвоить нельзя
```

Базовые типы:

| Тип | Что хранит | Типичный размер | Пример |
|---|---|---|---|
| `int` | Целые числа | 4 байта (±2 млрд) | `int n = 42;` |
| `long long` | Большие целые | 8 байт | `long long big = 9000000000LL;` |
| `float` | Дробные, одинарная точность | 4 байта | `float pi = 3.14f;` |
| `double` | Дробные, двойная точность | 8 байт | `double r = 2.718;` |
| `char` | Один символ | 1 байт | `char grade = 'A';` |
| `bool` | Логическое значение | 1 байт | `bool done = true;` |
| `std::string` | Строки (заголовок `<string>`) | Растёт динамически | `std::string name = "Ирина";` |
| `void` | «Нет значения» | — | Возвращаемый тип функций, которые ничего не возвращают |

Что важно помнить:

- **Для дробных чисел бери `double`.** `float` оправдан только при экономии памяти в больших массивах: его точности для расчётов часто не хватает.
- **Тип — это контракт.** Положить строку `"два"` в `int` не получится — компилятор откажется.
- Имена переменных: буквы, цифры, `_`; не могут начинаться с цифры; не могут совпадать с ключевыми словами (`int`, `return`, ...). Хороший тон — осмысленные имена: `radius`, а не `r1`.

> [!warning] Неинициализированные переменные
> Если объявить `int x;` и прочитать `x` без присваивания, там окажется «мусор» — то, что раньше лежало в этой памяти. Локальные переменные в C++ сами не обнуляются. Правило: объявил — сразу инициализируй.

# Математические операции

| Оператор | Действие | Примечание |
|---|---|---|
| `+` `-` `*` `/` | Арифметика | — |
| `%` | Остаток от деления | Только для целых: `7 % 2 == 1` |
| `++` `--` | Инкремент / декремент | `i++` — постформат, `++i` — преформат |
| `+=` `-=` `*=` `/=` | Операция с присваиванием | `x += 5` — то же, что `x = x + 5` |

Главная ловушка начала курса — **целочисленное деление**:

```cpp
int a = 7 / 2;      // 3! Дробная часть отбрасывается
double b = 7.0 / 2; // 3.5 — хотя бы один операнд дробный
```

Приоритет операций — как в математике; при сомнениях ставь скобки: `(a + b) * c`.

Математика сложнее `+ - * /` живёт в `<cmath>`:

| Функция | Что делает |
|---|---|
| `pow(x, n)` | x в степени n |
| `sqrt(x)` | Квадратный корень |
| `fabs(x)` | Модуль дробного числа |
| `sin`, `cos`, `tan`, `atan2` | Тригонометрия (в радианах) |
| `log(x)`, `exp(x)` | Натуральный логарифм и экспонента |

Со стандарта C++20 есть заголовок `<numbers>` с константами: `std::numbers::pi`, `std::numbers::e`. Он используется в программе про шар из [[03. Функции в C++|лекции о функциях]].

# Стандартные библиотеки

Библиотека в C++ — это **заголовочный файл**, который подключают через `#include`:

```cpp
#include <iostream>   // угловые скобки — стандартная библиотека
#include "my.h"       // кавычки — файл, лежащий рядом с твоим
```

Набор первых программ курса:

| Заголовок | Что даёт |
|---|---|
| `<iostream>` | `std::cout`, `std::cin`, `std::endl` |
| `<string>` | `std::string`, `std::getline` |
| `<cmath>` | `pow`, `sqrt`, `sin`, ... |
| `<numbers>` | Константы `pi`, `e` (C++20) |
| `<vector>` | Динамический массив `std::vector` |
| `<algorithm>` | `std::sort`, `std::min`, `std::max`, ... |

Два правила:

1. **Подключай то, что используешь.** Лишний заголовок «на всякий случай» — дурная привычка; недостающий — ошибка компиляции.
2. **«Наверное, уже подключено» не работает.** Заголовки могут включать друг друга транзитивно, и иногда `pow` компилируется без `<cmath>` — но это везение, а не гарантия. Разбор такого случая — в [[03. Функции в C++#Разбор программы «площадь и объём шара»|программе про шар]].

> [!warning] «Скомпилировалось без заголовка» — это технический долг
> Транзитивные включения различаются у компиляторов и их версий. Код, который «работает» на MSVC без `<cmath>`, может не собраться на g++. Надежда на случайное включение — типичный пример ненамеренного [[06. Принципы качественного кода и технический долг|технического долга]].

# Платформенно-специфичный код: `windows.h` и кодировка консоли

В программах-примерах курса есть две строки:

```cpp
#include <windows.h>
...
SetConsoleOutputCP(CP_UTF8);
SetConsoleCP(CP_UTF8);
```

- `<windows.h>` — **не часть стандарта C++**, а Windows API. На Linux или macOS этот код не скомпилируется.
- `SetConsoleOutputCP(CP_UTF8)` переводит вывод консоли Windows в UTF-8, `SetConsoleCP` — ввод. Без этого кириллица в консоли старого Windows превращается в кракозябры.
- В Linux консоль работает в UTF-8 по умолчанию — там этот блок не нужен вовсе.

> [!tip] Как читать это в примерах курса
> Такие строки — косметическая обвязка для консоли Windows, смысл примера никогда не в них. Под Linux или WSL их можно просто удалить вместе с `<windows.h>`.

# Разбор программы «приветствие»

Это первая программа дисциплины из [[01. Введение в предмет|лекции 01]]. После всего сказанного каждая её строка объяснима:

```cpp
#include <iostream>    // cout, cin
#include <string>      // std::string
#include <windows.h>   // консоль Windows; не нужен в Linux

int main() {
    SetConsoleOutputCP(CP_UTF8);   // вывод кириллицы без кракозябр (Windows)
    SetConsoleCP(CP_UTF8);         // ввод кириллицы без кракозябр (Windows)

    std::string name;                          // переменная для имени, пока пустая
    std::cout << "Введите имя: ";              // приглашение на экране
    std::cin >> name;                          // прочитать слово (до первого пробела)
    std::cout << "Привет, " << name << "!\n";  // собрать приветствие из трёх частей

    std::cout << "Нажмите Enter, чтобы выйти...";
    std::cin.ignore();   // выбросить перенос строки, оставшийся после cin >> name
    std::cin.get();      // дождаться «чистого» Enter, чтобы окно не закрылось сразу

    return 0;            // успешное завершение
}
```

Самое тонкое место — `std::cin.ignore()`. После `cin >> name` в буфере **остаётся символ переноса строки** от нажатого Enter. Если сразу вызвать `cin.get()`, он проглотит этот остаток, и программа закроется, не дождавшись тебя. `ignore()` сначала выбрасывает остаток — и только следующий ввод доходит до `get()`.

# Аналогии с Python и Rust

Одни и те же идеи в трёх языках — чтобы новое цеплялось за уже знакомое:

| Операция | C++ | Python | Rust |
|---|---|---|---|
| Переменная | `int x = 5;` | `x = 5` | `let x = 5;` |
| Константа | `const int x = 5;` | `X = 5` (по соглашению) | `let x = 5;` — без `mut` уже константа |
| Вывод | `std::cout << x << "\n";` | `print(x)` | `println!("{x}");` |
| Ввод | `std::cin >> x;` | `x = input()` | `io::stdin().read_line(&mut s)` |
| Строка | `std::string s;` | `s = ""` | `let s = String::new();` |
| Дробный тип | `double` | `float` (всегда двойная точность) | `f64` |
| Возведение в степень | `pow(x, 2)` | `x ** 2` | `x.powi(2)` |
| Как выполняется | Компиляция в исполняемый файл | Интерпретация | Компиляция в исполняемый файл |
| Типы переменных | Объявляются, проверяются при компиляции | Определяются во время выполнения | Выводятся, проверяются при компиляции |

Три отличия, которые стоит запомнить:

1. В C++ ты **думаешь типами**: у каждой переменной тип объявляется до того, как она начнёт жить.
2. В C++ поведение **явное**: `return 0;` в конце `main` — отчёт операционной системе об успехе, а не украшение.
3. То, что в Python выясняется во время выполнения, в C++ решается при компиляции — поэтому ошибки всплывают раньше, а программа работает быстрее.

# Ключевые термины

| Термин | Определение |
|---|---|
| Компиляция | Перевод исходного кода в исполняемый файл до запуска программы |
| Статическая типизация | Типы переменных известны на этапе компиляции и проверяются компилятором |
| Точка входа | Функция `main`, с которой начинается выполнение программы |
| Заголовочный файл | Файл с объявлениями, подключаемый директивой `#include` |
| Поток | Объект последовательного ввода-вывода: `std::cout` — вывод, `std::cin` — ввод |
| Переменная | Именованная область памяти с типом |
| Целочисленное деление | Деление целых чисел с отбрасыванием дробной части: `7 / 2 == 3` |
| Транзитивное включение | Ситуация, когда один заголовок подключает другой и его символы «появляются сами» |
| Платформенно-специфичный код | Фрагменты, работающие только в одной ОС (`windows.h` — только Windows) |

# Типичные заблуждения

- ❌ «`7 / 2` — это `3.5`». Если оба операнда — `int`, результат `3`. Нужна дробь — сделай хотя бы один операнд дробным: `7.0 / 2`.
- ❌ «`endl` и `\n` — одно и то же». `endl` дополнительно сбрасывает буфер вывода; в горячих циклах это заметно тормозит.
- ❌ «`windows.h` — часть C++». Это Windows API; на других ОС такой код не скомпилируется.
- ❌ «Раз скомпилировалось — все нужные заголовки уже подключены». Транзитивные включения не гарантированы между компиляторами.
- ❌ «`cin >> name` прочитает всю строку с пробелами». Чтение останавливается на первом пробельном символе; для строки целиком есть `std::getline`.
- ❌ «Неинициализированная переменная равна нулю». Локальные переменные без инициализации содержат мусор.
