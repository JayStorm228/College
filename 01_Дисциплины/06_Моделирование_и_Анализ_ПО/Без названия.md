#  создание заголовочного файла C++
```cpp
// file lib.h
#ifdef LIB_H
#define LIB_H
#include <iostream>
using namespace std;

#endit
```
```cpp
// file func.h
#ifdef FUNC_H
#define FUNC_H
#include <lib.h>
#endif
```
```cpp
// main.cpp
#include "func.h"

int main() {
	cout << "Hello World!";
}
```
Прототип функции располагается в заголовочном файле и указывает компилятору, что внутри программы есть функция с таким именем.
