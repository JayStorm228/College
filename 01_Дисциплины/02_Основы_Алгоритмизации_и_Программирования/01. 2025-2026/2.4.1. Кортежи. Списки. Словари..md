# Понятие Кортежа - Tuple
- Кортеж - один из способов представления последовательности значений через запятую
- Кортеж - неизменяемая последовательность
Синтаксис:
```python
tup = 1,2,3
tup = 1,
tup = tuple()
tup - (
"Never",
"Gonna",
"Give",
"You",
"Up",
)
```
## Индексация 
- Индекс - порядковый номер элемента, начиная с нуля
- позволяет обращаться к элементу итерируемого объекта
Синтаксис:
```python
a - (1, 2, 3)
print(a[0])
```

# Понятие словаря - Dictionary
- Словари - массив с индексацией по произвольному объекту
Синтаксис:
```python
dictionary:dict[str, int] = {
"key1":1
"key2":2
}
dictionary["key3"] = 3
```
