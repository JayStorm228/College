# 00. Лабораторные работы — обзор

> [!abstract] Что за работа
> Тринадцать лабораторных за 2025-2026 учебный год: условие, код, блок-схема и отчёт.
> Раньше они лежали внутри репозитория с кодом и в курсе не упоминались вовсе.
>
> **Теория:** каждая работа опирается на лекцию — см. колонку «Тема» и
> [[02_Основы_Алгоритмизации_и_Программирования/00_Курс|00_Курс дисциплины]].
>
> **Что даёт результат:** для каждой работы уже есть образец полного цикла —
> от условия до отчёта. Осталось описать сами условия (задача в [[02_Основы_Алгоритмизации_и_Программирования/00_Курс|00_Курс]]).

> [!note] Состав папки с работой
> `Code.py` — решение · `Flowchart.drawio` + `Flowchart.png` — блок-схема ·
> `Отчёт.docx` — отчёт · `Answer.csv`, `LabData.txt/json` — входные или выходные данные,
> если работа с ними связана.

# Обзор работ

| Работа | О чём | Тема из лекций | Что демонстрирует |
|---|---|---|---|
| `Lab 1` | вычисление выражения по формулам при заданных `x, y, z` | [[04. Линейный алгоритм]] | линейный алгоритм, `round()`, точность |
| `Lab 2` | кусочно заданная функция: случаи `x < 1.3`, `x = 1.3`, `x > 1.3` | [[05. Разветвляющийся алгоритм]] | ветвление, подключение своих модулей |
| `Lab 3` | кусочно заданная функция `z` при `xy > 0`, `xy = 0`, `xy < 0` | [[05. Разветвляющийся алгоритм]] | `custom_assertions`, валидация ввода |
| `Lab 4` | таблица значений `F = sin²x + ctg x` на отрезке с шагом | [[06. Циклический алгоритм - цикл for]] | циклы, `numpy`, `pandas` |
| `Lab 5` | таблица значений `y = 3·cos²(2x+1)` и максимум на `[-π, π]` с шагом `π/8` | [[06. Циклический алгоритм - цикл for]] | циклы, поиск максимума |
| `Lab 6` | значения `z` для `x` от `xn` до `xk` с шагом `dx` | [[06. Циклический алгоритм - цикл for]] | циклы, обработка таблицы |
| `Lab 7` | члены последовательности `x, x²/2!, …, xⁿ/n!`, большие порога `0.001` | [[07. Циклический алгоритм - цикл while]] | цикл с условием, рекуррентные формулы |
| `Lab 8` | среднее арифметическое положительных элементов списка | [[08. Кортежи, списки, словари]] | обход списка, условия, генераторы |
| `Lab 9` | матрица 10×10 по формуле `−5 + 10r`, замена знаков, нижний треугольник | [[10. Вложенные последовательности и NumPy]] | матрицы, срезы, `numpy`, `pandas` |
| `Lab 10` | средняя длина слов во введённой строке | [[09. Работа со строками]] | методы строк, `string.punctuation` |
| `Lab 11` | треугольник по трём сторонам с проверкой ввода | [[09. Работа со строками]] → [[13. Объектно-ориентированное программирование]] | функции, исключения, подготовка к ООП |
| `Lab 12` | генерация данных, запись и чтение JSON через `pathlib` | [[12. Работа с файлами]] | файлы, `json`, `Path`, кодировки |
| `Lab 13` | класс `Triangle`: валидация сторон, площадь по Герону, периметр | [[13. Объектно-ориентированное программирование]] | `@dataclass`, `__post_init__`, `@property` |

> [!tip] `Lab 13` — самая показательная для будущего
> Это единственная работа, где видно, как выглядит код «по-взрослому»: данные описываются
> классом данных, проверка выполняется прямо при создании объекта, а площадь и периметр —
> вычисляемые свойства, а не функции с длинным списком аргументов.
