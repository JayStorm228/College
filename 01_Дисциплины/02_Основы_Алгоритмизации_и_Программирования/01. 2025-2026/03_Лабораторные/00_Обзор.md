# 00. Лабораторные работы — обзор

> [!warning] Эти папки — исходный материал, а не курс
> Тринадцать лабораторных за 2025-2026 учебный год: условие, код, блок-схема и отчёт
> на каждую работу. Решение владельца от 24.09.2026: **условия этих работ становятся задачами
> практик курса**, а папки с отчётами после переноса уходят в архив.
>
> Почему так: отчёт и блок-схема к каждой задаче — время, потраченное впустую. Схемы в курсе
> нужны один раз, в блоке А (лекции 01–04), чтобы понять устройство ветвления и цикла;
> дальше закрепление идёт задачами и мини-проектами — см. [[00. Обзор практик]].
>
> **Что здесь полезного:** примеры задач по всем темам курса, готовые решения (`Code.py`)
> и образец того, как выглядит код «по-взрослому» (`Lab 13`). Пока перенос не закончен,
> условия читаются в `Отчёт.docx` каждой папки.

> [!note] Состав папки с работой
> `Code.py` — решение · `Flowchart.drawio` + `Flowchart.png` — блок-схема ·
> `Отчёт.docx` — отчёт · `Answer.csv`, `LabData.txt/json` — входные или выходные данные,
> если работа с ними связана.

# Обзор работ

| Работа | О чём | Тема из лекций | Что демонстрирует |
|---|---|---|---|
| `Lab 1` | вычисление выражения по формулам при заданных `x, y, z` | [[07. Линейный алгоритм]] | линейный алгоритм, `round()`, точность |
| `Lab 2` | кусочно заданная функция: случаи `x < 1.3`, `x = 1.3`, `x > 1.3` | [[08. Разветвляющийся алгоритм]] | ветвление, подключение своих модулей |
| `Lab 3` | кусочно заданная функция `z` при `xy > 0`, `xy = 0`, `xy < 0` | [[08. Разветвляющийся алгоритм]] | `custom_assertions`, валидация ввода |
| `Lab 4` | таблица значений `F = sin²x + ctg x` на отрезке с шагом | [[09. Циклический алгоритм - цикл for]] | циклы, `numpy`, `pandas` |
| `Lab 5` | таблица значений `y = 3·cos²(2x+1)` и максимум на `[-π, π]` с шагом `π/8` | [[09. Циклический алгоритм - цикл for]] | циклы, поиск максимума |
| `Lab 6` | значения `z` для `x` от `xn` до `xk` с шагом `dx` | [[09. Циклический алгоритм - цикл for]] | циклы, обработка таблицы |
| `Lab 7` | члены последовательности `x, x²/2!, …, xⁿ/n!`, большие порога `0.001` | [[10. Циклический алгоритм - цикл while]] | цикл с условием, рекуррентные формулы |
| `Lab 8` | среднее арифметическое положительных элементов списка | [[11. Кортежи, списки, словари]] | обход списка, условия, генераторы |
| `Lab 9` | матрица 10×10 по формуле `−5 + 10r`, замена знаков, нижний треугольник | [[13. Вложенные последовательности]] | матрицы, срезы, `numpy`, `pandas` |
| `Lab 10` | средняя длина слов во введённой строке | [[12. Работа со строками]] | методы строк, `string.punctuation` |
| `Lab 11` | треугольник по трём сторонам с проверкой ввода | [[12. Работа со строками]] → [[16. Объектно-ориентированное программирование]] | функции, исключения, подготовка к ООП |
| `Lab 12` | генерация данных, запись и чтение JSON через `pathlib` | [[15. Работа с файлами]] | файлы, `json`, `Path`, кодировки |
| `Lab 13` | класс `Triangle`: валидация сторон, площадь по Герону, периметр | [[16. Объектно-ориентированное программирование]] | `@dataclass`, `__post_init__`, `@property` |

> [!tip] `Lab 13` — самая показательная для будущего
> Это единственная работа, где видно, как выглядит код «по-взрослому»: данные описываются
> классом данных, проверка выполняется прямо при создании объекта, а площадь и периметр —
> вычисляемые свойства, а не функции с длинным списком аргументов. Этот код остаётся
> в курсе как образец для темы [[16. Объектно-ориентированное программирование]].
