# Ввод и вывод данных
- Функция `input(text)` используется для ввода данных из консоли
- Возвращает тип данных `str`
- Принимает на вход текст, который выводится на экран перед вводом
- функция `print()`используется для вывода данных на консоль
- Принимает любые данные на вход
Пример использования:
```python
x = input("Enter your name: ")
print(f"Hello, {name}")
```
