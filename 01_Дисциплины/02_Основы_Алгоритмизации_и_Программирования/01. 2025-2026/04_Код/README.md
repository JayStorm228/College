# 04_Код — задачи, лабораторные и схемы дисциплины

Это бывший репозиторий `CollegeProgramming-master`, перенесённый внутрь базы конспектов
и разложенный по назначению. Здесь живёт **код**, а не конспекты: теории — в `01_Лекции/`,
условия лабораторных — в `03_Лабораторные/`. Работы, сделанные на заказ, и дубликат учебника
удалены (решение владельца от 24.09.2026) — в базе остаётся только собственный код автора,
работы других студентов — в `Ревью/` как материал для разбора.

## Что где лежит

| Папка | Что внутри | Как использовать |
|---|---|---|
| `Arkhipov/` | решения задач по темам (номера тем учебного плана: `2.3.1`, `4.1.2 - 4.1.4`) | сверить своё решение, посмотреть приёмы |
| `Mods/` | общие модули: `custom_assertions.py` (ввод и проверки), шаблон `CopyPaste.py` | импортировать в свои решения |
| `GUI/` | ноутбук и код с окнами и кнопками (событийно-ориентированное программирование) | выходит за рамки программы курса, но любопытно посмотреть |
| `Схемы/` | блок-схемы `.drawio` и их экспорт `.png` | образцы оформления схем |
| `Ревью/` | работы других студентов (Kucenko, Shupenin, Vavilova) | материал для практики «ревью чужого кода» |
| `Архив/` | история репозитория и примеры-листинги (в курсе не используются) | см. `Архив/ПРОЧТИ_МЕНЯ.md` |

## Как запускать

```bash
uv sync                       # поставить зависимости (numpy, pandas) из pyproject.toml
uv run python Arkhipov/2.3.1/"Задача 1.py"
```

Без `uv` подойдёт любой интерпретатор **Python 3.14+** (см. `.python-version`):
часть решений использует синтаксис `type X = ...` и вложенные кавычки в f-строках,
который появился в 3.12.

```bash
python3 Arkhipov/2.3.1/"Задача 1.py"        # если версия подходит
```

> [!warning] Известные дефекты кода
> - `Arkhipov/4.1.2 - 4.1.4/Ex 2.py` и `Ex 3.py` содержат **маркеры конфликта слияния**
>   (`<<<<<<< HEAD`) — файлы не запускаются, нужно разрешить конфликт.
> - Часть решений рассчитана на ввод с клавиатуры — при запуске без ввода они «висят».
> - В `2.5.2/Ex 4.py` и `4.1.2 - 4.1.4/OPT_Ex 13.py` вложенные кавычки внутри f-строк
>   (`f"{r.choice(["+"])}"`) допустимы только на Python 3.12+.

## Что здесь стоит изучить отдельно

Часть решений выходит за рамки программы курса — это заготовки инженерного модуля:

- `Arkhipov/Labs/Lab 13` — `@dataclass` с валидацией в `__post_init__` и `@property` для вычисляемых величин;
- `Arkhipov/4.1.2 - 4.1.4/OPT_Ex 12.py` (~570 строк) — `ABC` + `@abstractmethod`, общий интерфейс фигур,
  `TypeAlias`, типизация `numpy`, docstring по стилю NumPy;
- `Arkhipov/4.1.2 - 4.1.4/OPT_Ex 13.py` — реестр фабрик через словарь `{1: lambda: ...}`;
- `Arkhipov/3.1.2 - 3.1.5/F1_20.py` — 20 функций с docstring и `TypeVar`;
- `Mods/custom_assertions.py` — свои исключения и проверки ввода;
- `Mods/CopyPaste.py` — как **правильно** находить папку модулей (`pathlib` и поиск вверх по дереву)
  вместо отсчёта `../..`.
