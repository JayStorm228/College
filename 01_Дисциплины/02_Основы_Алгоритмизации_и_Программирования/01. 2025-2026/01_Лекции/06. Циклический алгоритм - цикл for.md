# Понятие циклического алгоритма
- Циклический алгоритм - определённая последовательность шагов выполняется некоторое число раз в зависимости от параметров цикла
# Цикл с заданным количеством повторений
```python
for name in iterable:
	pass
```
- `range(start, stop, step)` - последовательность от start до stop с шагом step
# Вложенные циклы - циклы внутри циклов
```python
for i in range(10):
	for j in range(10):
		print(f"{i=}, {j=}")
```
