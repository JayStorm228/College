# Идентификаторы: Переменные/Постоянные
- Для определения переменной необходимы?
	1. Имя
		- Через него осуществляется связь переменной с ОЗУ
	2. Тип
		- Позволяет компилятору определить вид информации в переменной
	3. Значение
		- Определяет содержание информации в переменной
- Правила создания переменных:
	1. Без пробелов
	2. Начинается с буквы или нижнего подчёркивания
	3. Состоит из букв, цифр, подчёркиваний
	4. Не является служебным словом
# Типы данных в Python
- В Python - динамическая типизация.
- Это значит, что тип данных выясняется во время выполнения команды, а не перед этим.
- `type(var)` - функция для определения типа данных переменной.
- Однако можно указывать тип данных, который ты **ожидаешь** получить в переменной:
```python
a:int = 1
b:str = "123"
```
## 1. Числовые
- Доступные операции(простая арифметика):
	1. Сложение: +
	2. Вычитание: -
	3. Умножение: * 
	4. Деление: /
	5. Целочисленное деление: //
		- Округляет результат до целых
	6. Остаток от деления: %
		- Возвращает остаток от целочисленного деления
### 1. Integer - целые числа
- обозначение:  `int`
- пример значений: `1, 2, 3`
### 2. Float - числа с плавающей точкой
- обозначение: `float`
- Пример значений: `1.0. 5.4`
- Можно представлять экспоненциально: `1e+10, -5e-2`
## 2. String - строковые
- обозначение: `str`
- пример значений: `"Text"`, `'Text'`

# Основные операторы
## 1. Присваивание: "="
- Присваивание - связь значения с именем переменной
- Помимо простого "=" есть и другие:
	1. `x /= a` - тоже, что и `x = x / a`
	2. `x %= a`
	3. `x += a`
	4. `x -= a`
	5. `x *= a`
## 2. Вывод на экран: `print()`
- Выводит в консоль то, что указано в скобках, будто то значение переменной или строчки
- Имеет аргументы:
	1. sep
		- Разделитель элементов при выводе
	2. end
		- Конец строки
