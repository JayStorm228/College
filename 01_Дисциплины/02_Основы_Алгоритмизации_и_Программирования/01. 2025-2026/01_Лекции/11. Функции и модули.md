# Понятие пользовательских функций
- Есть встроенные функции - их можно использовать сразу.
- А если подходящей нет?
- Возьми и сделай сам.
- А зачем?
	1. Позволяют избегать повторения кода
	2. Позволяют использовать группу операторов кода со знакомым именем
	3. Делают код более читаемым
	4. Упрощают разработку проектов
	5. Позволяет повторно использовать функции в других проектах.
	6. Расширяет язык программирования.
- А как?
```python
def func(arg1: int, arg2: str = "значение") -> str:
	"""Что делает функция — одной строкой."""
	...
	return "результат"
```
- Имя функции следует тем же правилам, что и имена переменных
- Что такое аргументы? Как они работают? Как их можно указывать?

# Создание модулей
- В основном, в языках программирований это DLL - Dynamic Link Library. Про это тоже можно рассказать
- В Python модулем является обычным .py файлом
## Процесс создания модулей
### 1. Создать файл с функциями или классами
### 2. Отделить "висячий" код от модуля
Не делай вот так:
```python
def func():
	pass
test = func()
func()
```
Почему? А потому что весь код после функции выполнится в момент импорта модуля.
Поэтому делай так:
```python
def func():
	pass
def main():
	test = func()
	func()
if __name__ == "__main__":
	main()
```
### 3. Файл хранить в той же папке, что и скрипт. Ну или запихать его в path. А зачем? А мне почём знать, так библиотеки из интернета ставятся

## Пример синтаксиса хорошего модульного кода
Структура:
```text
/src
	cotan.py
	main.py
```
Код модуля:
```python
#filename: cotan.py
from math import cos, sin
def ctg(x:float) -> float:
	"""Возвращает котангенс от значения х в радианах"""
	return cos(x)/sin(x)
def main() -> None:
	while True:
		try:
			x = float(input("Введите величину угла в радианах: "))
		except ValueError as e:
			print(e)
		else:
			break
	print(ctg(x))
if __name__ == "__main__":
	main()
```
А теперь импортируем его в файл:
```python
#filename: main.py
from cotan import ctg        # импорт из файла cotan.py — расширение не пишется
def main() -> None:
	while True:
		try:
			x = float(input("Введите величину угла в радианах: "))
		except ValueError as e:
			print(e)
		else:
			break
	print(f"Котангенс угла {x}рад.: {ctg(x)}")
if __name__ == "__main__":
	main()
```
