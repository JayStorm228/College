# Понятие алгоритма
- Алгоритм - точное простейшее описание последовательности решения данной задачи
- Содержит несколько шагов, которые должны выполняться в определённой последовательности
- Каждый шаг алгоритма может состоять из одной или нескольких простых задач
- Пример:
	1. Достать ключ
	2. Вставить ключ в замочную скважину
	3. Повернуть ключ 2 раза против часовой стрелки
	4. Вынуть ключ
# Свойства алгоритма
## 1. Дискретность
- Алгоритм должен представлять процесс решения задачи как последовательность простых шагов
## 2. Определённость
- Каждый шаг алгоритма должен быть чётким и однозначным
## 3. Результативность
- Алгоритм должен приводить к решению задачи за конечное количество шагов
## 4. Массовость 
- Алгоритм решения разрабатывается в общем виде

# Основные этапы решения задач
## 1. Общая постановка задачи
- Содержание задачи, исходные данные
## 2. Разработка Математической модели
- Установка формализированных связей между исходным и искомым
- Запись расчётных формул/функциональных зависимостей
## 3. Разработка Алгоритма
- Описание последовательности действий для получения результатов.
## 4. Разработка программы
- Программа составляется в соответствии с алгоритмом
## 5. Отладка
- Поиск ошибок и их устранение
## 6. Анализ результатов
- Принятие решения о необходимости внесения корректировок или окончании работы
