# 11. Кортежи, списки, словари

> [!abstract] О чём эта лекция
> До сих пор в переменной лежало одно значение. Здесь появляются **коллекции** — способы хранить
> много значений под одним именем: кортеж, список, словарь и множество. С этого места задачи
> перестают быть «посчитать одно число»: появляются списки оценок, словари с данными, наборы
> уникальных значений.
>
> **Зачем это нужно.** Почти вся работа с данными — это «есть много чего-то, надо пройти по нему
> и получить ответ». Плюс выбор коллекции решает задачу наполовину: там, где нужен словарь,
> список превращается в кашу из индексов. Здесь разбирается, что чем хранить и как не наступить
> на три классические ловушки: копирование «по ссылке», изменение коллекции во время обхода
> и `KeyError` при обращении к несуществующему ключу.
>
> **Что ты должен уметь после лекции:** выбрать коллекцию под задачу; прочитать и изменить
> элемент, срез, ключ; добавлять и удалять элементы; обходить коллекцию циклом; строить
> коллекцию списковым включением; скопировать список так, чтобы оригинал не изменился;
> убрать дубликаты множеством.
>
> **Куда идти дальше:** [[12. Работа со строками]] — строка устроена как последовательность
> символов, и всё это пригодится там.

# Последовательности: общие правила

**Последовательность** — набор значений, упорядоченный по номерам. Строка, кортеж и список —
последовательности, поэтому у них одинаковые базовые умения:

| Умение | Как записать | Что даёт |
|---|---|---|
| длина | `len(items)` | сколько элементов |
| обращение по номеру | `items[0]` | элемент с заданным **индексом** |
| индекс с конца | `items[-1]` | последний элемент |
| срез | `items[0:3]` | часть последовательности |
| проверка вхождения | `x in items` | есть ли значение |
| обход циклом | `for x in items:` | все элементы по очереди |

> [!important] Индексация с нуля
> Первый элемент имеет индекс `0`, последний — `len(items) - 1`. Обращение вида `items[5]`
> к последовательности из трёх элементов даёт `IndexError: list index out of range`: индекс
> вышел за границы.

# Кортеж (tuple): неизменяемая последовательность

**Кортеж** — упорядоченная последовательность, которую после создания изменить нельзя.

```python
point = (10, 20)
rgb = 255, 128, 0                  # скобки необязательны
one = (7,)                         # кортеж из одного элемента: запятая обязательна!
empty = ()                         # пустой кортеж
```

Что можно и чего нельзя:

```python
print(point[0])                    # 10 — читать можно
print(point[-1])                   # 20
# point[0] = 5                     # TypeError: 'tuple' object does not support item assignment
```

Зачем нужно то, что нельзя изменить:

- **данные не пострадают случайно**: координаты, цвет, размеры — то, что не должно «поехать»
  в середине программы;
- **кортеж можно положить ключом в словарь** или в множество (список — нельзя, он изменяемый);
- **распаковка** — красивый приём для нескольких значений сразу:

```python
point = (10, 20)
x, y = point                       # x = 10, y = 20
print(f"Точка: x={x}, y={y}")

a, b = b, a                        # обмен значений из лекции 07 — тоже распаковка
```

# Список (list): изменяемая последовательность

**Список** — упорядоченная последовательность, элементы которой можно менять, добавлять
и удалять. Это самая используемая коллекция в Python.

```python
scores = [5, 4, 3, 5, 4]
names = ["Аня", "Борис"]
empty = []
mixed = [1, "два", 3.0, True]      # типы могут быть любыми, но смешивать без нужды не стоит

scores[0] = 5                      # изменить элемент — можно
scores.append(3)                   # добавить в конец
print(len(scores))                 # 6
```

Основные методы:

| Метод | Что делает | Пример |
|---|---|---|
| `append(x)` | добавить один элемент в конец | `scores.append(4)` |
| `extend(seq)` | добавить все элементы другой коллекции | `scores.extend([5, 5])` |
| `insert(i, x)` | вставить по индексу `i` | `scores.insert(0, 2)` |
| `remove(x)` | удалить первый элемент со значением `x` | `scores.remove(3)` |
| `pop(i)` | забрать элемент по индексу (по умолчанию последний) | `last = scores.pop()` |
| `count(x)` | сколько раз встречается `x` | `scores.count(5)` |
| `index(x)` | индекс первого вхождения `x` | `scores.index(4)` |
| `sort()` | отсортировать **сам список** | `scores.sort()` |
| `reverse()` | развернуть **сам список** | `scores.reverse()` |
| `clear()` | удалить все элементы | `scores.clear()` |

> [!warning] `sort()` меняет список, `sorted()` возвращает новый
> `scores.sort()` сортирует список «на месте» и возвращает `None` — его результат в переменную
> не записывают. `sorted(scores)` возвращает **новый** список, а исходный не трогает.
> То же с `reverse()` и `reversed()`.

Сортировка по своему правилу — через `key`:

```python
words = ["груша", "яблоко", "слива"]
words.sort(key=len)                          # по длине: слива, груша, яблоко
pairs = [("Аня", 5), ("Борис", 4)]
pairs.sort(key=lambda pair: pair[1])         # по второму элементу пары
```

> [!note] Про `lambda` (продвинутое)
> `lambda pair: pair[1]` — короткая безымянная функция: «взять второй элемент». Функции
> разбираются в [[14. Функции и модули]], а `lambda` — в инженерном модуле в конце курса;
> пока достаточно читать её как правило «сортировать по…».

# Срезы: часть последовательности

**Срез** — запись `[начало:конец:шаг]`. Как и в `range`, правый конец не входит.

| Срез | Что получится для `[0, 1, 2, 3, 4, 5]` | Смысл |
|---|---|---|
| `items[1:4]` | `[1, 2, 3]` | с индекса 1 до 4 (не включая) |
| `items[:3]` | `[0, 1, 2]` | с начала |
| `items[3:]` | `[3, 4, 5]` | до конца |
| `items[-2:]` | `[4, 5]` | два последних |
| `items[::2]` | `[0, 2, 4]` | каждый второй |
| `items[::-1]` | `[5, 4, 3, 2, 1, 0]` | развёрнутый порядок |
| `items[:]` | копия всего списка | — |

Срезы — это то, чем пользуются постоянно: «первые три», «все, кроме последнего»,
«каждая вторая оценка».

---

# Копия списка: главная ловушка

```python
first = [1, 2, 3]
second = first            # это НЕ копия: два имени для одного списка
second.append(4)
print(first)              # [1, 2, 3, 4] — «первый» тоже изменился
```

Присваивание **не копирует** коллекцию: оба имени указывают на один и тот же список в памяти.
Копию создают явно:

```python
first = [1, 2, 3]
second = first[:]         # копия срезом
third = list(first)       # копия через list()
fourth = first.copy()     # копия методом

second.append(4)
print(first)              # [1, 2, 3] — оригинал цел
```

> [!warning] Копия поверхностная
> `first[:]` копирует только верхний уровень. Если внутри списка лежат **другие списки**
> (например, строки матрицы), они останутся общими: изменение вложенного списка будет видно
> в обеих «копиях». Подробнее — в [[13. Вложенные последовательности]].

# Списковые включения

**Списковое включение** — способ построить список одной строкой, вместо «создать пустой
и набить его в цикле»:

```python
# так пишут начинающие: много строк ради простого действия
squares = []
for number in range(1, 6):
    squares.append(number ** 2)

# так пишут в проектах: то же самое одной строкой
squares = [number ** 2 for number in range(1, 6)]
print(squares)                                    # [1, 4, 9, 16, 25]
```

С условием:

```python
scores = [5, 3, 4, 2, 5]
good = [score for score in scores if score >= 4]  # [5, 4, 5]
labels = ["сдал" if score >= 3 else "не сдал" for score in scores]
```

Читается как «собрать «оценку» для каждой «оценки» из `scores`, если…».
Правило простое: **если выражение не влезает в одну строку и понятно не с первого чтения —
пиши обычным циклом**. Включение существует для читаемости, а не вместо циклов.

## Обход двух списков сразу: `zip`

Когда данные идут парами (имя и оценка, товар и цена), их удобно держать в двух списках
одинаковой длины и обходить сразу оба:

```python
names = ["Аня", "Борис", "Вера"]
scores = [5, 4, 5]

for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

`zip` соединяет элементы по порядку: первый с первым, второй со вторым. Если списки разной
длины, лишние элементы просто не попадут в пары — ошибки не будет, но данные потеряются,
поэтому длины лучше сверять.

# Словарь (dict): данные по ключу

**Словарь** — набор пар «ключ → значение». Это не «список с интересными индексами»,
а способ хранить данные, у которых есть имена: сколько чего, кто кого, какое свойство.

```python
student = {
    "name": "Аня",
    "age": 17,
    "scores": [5, 4, 5],
}

print(student["name"])                  # Аня — доступ по ключу
student["age"] = 18                     # изменение
student["city"] = "Калининград"          # новый ключ добавляется так же — через присваивание
print(len(student))                     # 4
```

Основные приёмы:

| Приём | Пример | Что делает |
|---|---|---|
| получить значение | `student["name"]` | `KeyError`, если ключа нет |
| получить безопасно | `student.get("city", "не указан")` | вернёт значение по умолчанию, если ключа нет |
| проверить ключ | `"age" in student` | `True` / `False` |
| удалить | `del student["city"]` или `student.pop("city")` | удалить пару |
| все ключи / значения / пары | `student.keys()`, `.values()`, `.items()` | для обхода |
| обновить пачкой | `student.update({"age": 18})` | слить с другим словарём |

Обход словаря — по парам:

```python
for key, value in student.items():
    print(f"{key}: {value}")
```

> [!important] Словарь незаменим для подсчётов
> Частая задача — «сколько раз встречается каждое значение». Словарь решает её в три строки:
>
> ```python
> text = "мама мыла раму"
> counts = {}
> for word in text.split():
>     counts[word] = counts.get(word, 0) + 1
> print(counts)      # {'мама': 1, 'мыла': 1, 'раму': 1}
> ```
>
> `counts.get(word, 0)` читается как «сколько уже насчитали, а если слова не было — ноль».

# Множество (set): только уникальные

**Множество** — неупорядоченный набор уникальных значений. Главные задачи: убрать дубликаты
и быстро проверить «есть ли уже такое».

```python
visits = [101, 102, 101, 103, 102]
unique = set(visits)               # {101, 102, 103} — повторы исчезли
print(len(unique))                 # 3

tags = {"python", "учёба"}
tags.add("код")                    # добавить
tags.discard("учёба")              # убрать (без ошибки, если такого нет)
print("python" in tags)            # True — проверка очень быстрая
```

Операции над множествами — как в математике:

```python
group_a = {"Аня", "Борис", "Вера"}
group_b = {"Борис", "Вера", "Глеб"}

print(group_a | group_b)           # объединение: все, кто есть хотя бы в одной группе
print(group_a & group_b)           # пересечение: кто есть в обеих
print(group_a - group_b)           # разность: кто есть только в первой
```

> [!note] Когда множество лучше списка
> Если важно «есть ли элемент» и порядок не нужен — множество быстрее и само убирает дубликаты.
> Если важен порядок или возможны повторы — нужен список.

# Что чем хранить

| Нужно | Коллекция | Пример |
|---|---|---|
| значения по порядку, менять можно | **список** `list` | оценки, товары, строки таблицы |
| данные, которые не должны меняться | **кортеж** `tuple` | координаты, цвет, размеры окна |
| данные с именами (ключ → значение) | **словарь** `dict` | карточка студента, настройки, подсчёты |
| только уникальные значения, без порядка | **множество** `set` | список городов, теги, «кто уже проголосовал» |
| текст | **строка** `str` | сообщения, имена, содержимое файла |

# Как это делают в проекте

**Привычка 1. Выбирать коллекцию по задаче, а не «список по привычке».** Если данные
«с именами» — бери словарь: код станет короче и понятнее, чем список с индексами.

**Привычка 2. Помнить, что присваивание не копирует.** Перед изменением проверь, не изменишь
ли ты чужой список: `second = first[:]`, когда нужна копия.

**Привычка 3. Не изменять коллекцию во время обхода.** Удаление элементов прямо в цикле
по этому же списку приводит к «перескокам»: часть элементов просто не проверяется. Собери
новый список (или включение) и замени старый после цикла.

**Привычка 4. Использовать `get` и `in` вместо «надеюсь, ключ есть».** `dict[key]` падает
с `KeyError`; `dict.get(key, default)` и `key in dict` такой ситуации не допускают.

**Привычка 5. Включения — для простых случаев.** Одно выражение плюс, может быть, одно
условие. Сложная логика в включении читается хуже цикла.

# Ключевые термины

| Термин | Определение |
|---|---|
| **Коллекция** | значение, содержащее много элементов: список, кортеж, словарь, множество |
| **Последовательность** | коллекция с порядком и индексами: строка, кортеж, список |
| **Индекс** | номер элемента, начинается с нуля |
| **Срез** | часть последовательности: `items[1:4:2]` |
| **Кортеж (`tuple`)** | неизменяемая последовательность |
| **Список (`list`)** | изменяемая последовательность |
| **Словарь (`dict`)** | набор пар «ключ → значение» |
| **Множество (`set`)** | набор уникальных значений без порядка |
| **Списковое включение** | построение списка одной строкой: `[x * 2 for x in items]` |
| **`zip`** | соединяет несколько последовательностей в пары «по порядку» |
| **Ссылка на объект** | два имени могут указывать на одну коллекцию; копия создаётся явно |
| **`KeyError`** | обращение к несуществующему ключу словаря |
| **`IndexError`** | обращение по индексу вне границ последовательности |

# Типичные заблуждения

- ❌ **«`second = first` копирует список».** Нет: это второе имя для того же списка. Копия —
  `first[:]`, `list(first)` или `first.copy()`.
- ❌ **«Последний элемент — `items[len(items)]`».** Это выход за границы. Последний —
  `items[len(items) - 1]` или просто `items[-1]`.
- ❌ **«`sort()` вернёт отсортированный список».** Он сортирует на месте и возвращает `None`.
  Новый список даёт `sorted(...)`.
- ❌ **«Кортеж — просто список со скобками».** Главное отличие — неизменяемость: кортеж можно
  использовать ключом словаря и элементом множества, список — нет.
- ❌ **«Словарь — это список, где индексы строки».** Доступ к ключу и к индексу различаются:
  у словаря нет порядка по номерам, зато есть быстрый поиск по имени и свои методы.
- ❌ **«Множество сохраняет порядок добавления».** Не сохраняет: это неупорядоченная
  коллекция. Нужен порядок — список.
- ❌ **«В списке не может быть повторов».** Может, сколько угодно; уникальность — свойство
  множества.
- ❌ **«Вложенные списки копируются срезом полностью».** Срез копирует только верхний уровень;
  вложенные списки остаются общими.

# Проверь себя

1. Чем кортеж отличается от списка и когда выбирают кортеж?
2. Что выведет `items[-1]` и что произойдёт при `items[len(items)]`?
3. Почему `second = first` опасно, если потом менять `second`?
4. Как посчитать, сколько раз каждое слово встречается в тексте?
5. Чем список отличается от множества на примере списка городов?
6. Что делает `scores.sort()` и что делает `sorted(scores)`?
7. Как пройти циклом сразу по двум спискам — именам и оценкам?

> [!example]- Ответы
> 1. Кортеж **неизменяемый**: элементы нельзя заменить, добавить, удалить. Его выбирают для
>    данных, которые не должны меняться (координаты, цвет, размеры), а также когда нужен
>    хешируемый набор — например, ключ словаря или элемент множества.
> 2. `items[-1]` даст последний элемент. `items[len(items)]` — `IndexError`: индексы идут
>    от 0 до `len(items) - 1`, последний индекс на единицу меньше длины.
> 3. Потому что это не копия, а второе имя того же списка: изменение через `second` изменит
>    и `first`. Нужна независимая копия — `first[:]`, `list(first)` или `first.copy()`.
> 4. Завести пустой словарь и на каждом слове делать
>    `counts[word] = counts.get(word, 0) + 1`. `get(word, 0)` вернёт текущий счётчик или 0,
>    если слово встретилось впервые.
> 5. Список хранит все значения в порядке добавления, включая повторы. Множество оставит
>    только уникальные и потеряет порядок, зато проверка «есть ли такой город» в нём быстрее.
> 6. `scores.sort()` сортирует список «на месте» и возвращает `None` (результат нельзя
>    присвоить). `sorted(scores)` возвращает **новый** отсортированный список, а исходный
>    не меняет.
> 7. `for name, score in zip(names, scores):` — `zip` соединит элементы по порядку, и на каждом
>    шаге цикла в переменных окажется пара «имя, оценка».
