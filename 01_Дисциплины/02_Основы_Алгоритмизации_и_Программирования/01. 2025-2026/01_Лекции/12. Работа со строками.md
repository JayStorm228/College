# 12. Работа со строками

> [!abstract] О чём эта лекция
> Строка — самая частая форма данных: пользователь вводит текст, файл содержит текст, интернет
> отдаёт текст. Эта лекция про то, как текст читать по частям, искать в нём, менять, разбивать
> на слова и собирать обратно, проверять и форматировать.
>
> **Зачем это нужно.** Строки ведут себя не как списки, и на этом построены две ловушки:
> строку **нельзя изменить** по индексу, а результат метода получают только через присваивание
> (`text.upper()` сам текст не меняет). Плюс разбиение и сборка (`split` / `join`) — основа
> почти всех задач про текст, от подсчёта слов до разбора файла.
>
> **Что ты должен уметь после лекции:** взять символ и срез; привести регистр, обрезать пробелы,
> разбить строку на части и склеить; найти и заменить подстроку; проверить, из чего состоит
> символ; отформатировать вывод; собрать текст из кусков правильно и быстро.
>
> **Куда идти дальше:** [[13. Вложенные последовательности]] — следующий шаг по данным.

# Строка как последовательность

**Строка (`str`)** — упорядоченная последовательность символов, записанная в кавычках. Строки
ведут себя как последовательности из [[11. Кортежи, списки, словари]]: их можно измерять,
индексировать, резать срезами и обходить циклом.

```python
word = "программа"

print(len(word))          # 9 — количество символов
print(word[0])            # п — первый
print(word[-1])           # а — последний
print(word[0:4])          # прог — срез
print(word[::-1])         # аммаргорп — разворот
print("грамм" in word)    # True — проверка подстроки
```

> [!warning] Строка неизменяема
> Заменить символ по индексу нельзя:
>
> ```python
> word = "кот"
> # word[0] = "б"        # TypeError: 'str' object does not support item assignment
> ```
>
> Изменить строку — значит собрать новую:
>
> ```python
> word = "кот"
> word = "б" + word[1:]     # "бот"
> word = word.replace("б", "к")  # снова "кот"
> ```

**Про кодировки.** Строки в Python 3 — это **Unicode**: в них лежат не байты, а символы, поэтому
русский, кириллица и эмодзи работают одинаково. Таблица ASCII (128 символов) — историческая
часть Unicode; её крайние значения полезно знать: коды 0–31 — управляющие (перевод строки,
табуляция), 32 — пробел, 65–90 — латинские заглавные, 97–122 — строчные.

```python
print(ord("A"))     # 65 — код символа
print(chr(65))      # A — символ по коду
```

# Методы строк: регистр, пробелы, поиск, замена

Метод — действие, которое выполняют «через точку»: `text.upper()`. Важно помнить: строки
неизменяемы, поэтому **все методы возвращают новую строку**, а исходную не трогают.

```python
text = "  Привет, Мир!  "

print(text.strip())          # "Привет, Мир!" — убрать пробелы по краям
print(text.lower())          # "  привет, мир!  "
print(text.upper())          # "  ПРИВЕТ, МИР!  "
print(text.capitalize())     # "  привет, мир!  " — первая буква заглавная, остальные строчные
print(text.title())          # "  Привет, Мир!  " — каждое слово с заглавной
```

Основные методы и их смысл:

| Метод | Что делает |
|---|---|
| `strip()`, `lstrip()`, `rstrip()` | убирают пробелы (и переводы строк) по краям / слева / справа |
| `split(sep)` | разбивает строку на список частей; без аргумента — по пробелам |
| `splitlines()` | разбивает текст по переводам строк: `"а\nб".splitlines()` → `['а', 'б']` |
| `join(seq)` | собирает строку из коллекции: `" ".join(words)` |
| `replace(old, new)` | заменяет все вхождения подстроки |
| `find(sub)`, `rfind(sub)` | индекс первого (последнего) вхождения; `-1`, если не найдено |
| `index(sub)` | то же, но выбрасывает `ValueError`, если не найдено |
| `count(sub)` | сколько раз встречается подстрока |
| `startswith(prefix)`, `endswith(suffix)` | начинается / заканчивается на… |
| `isdigit()`, `isalpha()`, `isspace()` | состоит ли вся строка из цифр / букв / пробельных символов |

Пример со вводом: пользователь часто набирает лишние пробелы и разный регистр.

```python
answer = input("Продолжить? (да/нет): ").strip().lower()

if answer == "да":
    print("Продолжаем")
else:
    print("Выходим")
```

Обрати внимание: методы вызываются цепочкой — `input(...)` возвращает строку, `.strip()` убирает
пробелы и возвращает новую строку, `.lower()` приводит регистр. Так и пишут.

# Разбить и собрать: `split` и `join`

Разбиение текста на слова:

```python
sentence = "мама мыла раму"
words = sentence.split()          # ['мама', 'мыла', 'раму']
print(len(words))                 # 3 — количество слов

csv_line = "Аня;17;Калининград"
fields = csv_line.split(";")      # ['Аня', '17', 'Калининград']
```

Наряду со `split` есть `splitlines()` — он разрезает текст по **переводам строк** и не оставляет
в конце каждой части лишний значок:

```python
text = "первая строка\nвторая строка"
print(text.splitlines())      # ['первая строка', 'вторая строка']
```

`\n` — **перевод строки**: невидимый значок, которым разделяются строки в текстовых файлах.
Именно его `print()` добавляет в конце каждого вывода (а `end=` из [[05. Язык Python - идентификаторы, операторы, типы данных]]
этот значок заменяет). `splitlines()` пригодится, когда файл прочитан целиком одной строкой, —
об этом в [[15. Работа с файлами]].

Сборка обратно:

```python
words = ["мама", "мыла", "раму"]
sentence = " ".join(words)        # "мама мыла раму"
path = "/".join(["data", "2025", "report.txt"])   # data/2025/report.txt
```

> [!important] Склеивать текст в цикле через `+=` — ошибка
> Каждое `text += word` создаёт **новую** строку и копирует туда всё содержимое. На большом
> тексте это заметно медленно. Правильно: собрать куски в список, а в конце склеить `join`.
>
> ```python
> # плохо: десять тысяч раз создаётся новая строка
> result = ""
> for word in words:
>     result += word
>
> # хорошо: строку строим один раз
> result = "".join(words)
> ```

# Форматирование вывода

f-строки уже знакомы по [[07. Линейный алгоритм]]; здесь — минимум, которым пользуются чаще
всего:

| Запись | Что получится | Зачем |
|---|---|---|
| `f"{value:.2f}"` | `3.14` | 2 знака после запятой |
| `f"{value:>8}"` | `     123` | выравнивание по правому краю в поле шириной 8 |
| `f"{value:<8}"` | `123     ` | по левому краю |
| `f"{value:^8}"` | `  123   ` | по центру |
| `f"{value:0>5}"` | `00123` | заполнение нулями (номера, коды) |
| `f"{value:,}"` | `1,234,567` | разряды через запятую |
| `f"{value:+.1f}"` | `+3.1` | всегда показывать знак |

```python
for name, score in [("Аня", 5), ("Борис", 4)]:
    print(f"{name:<10}{score:^5}")
```

```text
Аня         5
Борис       4
```

Так выводят таблицы без «разъезжающихся» столбцов.

# Типичные задачи на строки

```python
text = "У лукоморья дуб зелёный"

# количество слов
print(len(text.split()))

# разворот строки
print(text[::-1])

# проверка на палиндром (без учёта регистра и пробелов)
cleaned = "".join(text.lower().split())
print(cleaned == cleaned[::-1])

# сколько раз встречается буква
print(text.lower().count("у"))

# заменить все вхождения
print(text.replace("дуб", "клён"))
```

> [!tip] Порядок работы с текстом
> 1. **Нормализовать** — привести регистр (`lower`), убрать лишние пробелы (`strip`, `split`).
> 2. **Разбить** на части (`split`), чтобы была понятная коллекция.
> 3. **Обработать** части циклом или включением.
> 4. **Собрать** ответ (`join`, `f`-строки).
>
> Почти любая задача на текст раскладывается на эти четыре шага.

# Как это делают в проекте

**Привычка 1. Нормализовать ввод сразу.** `input(...).strip()` и `.lower()`, если регистр
не важен: пользователь напишет «Да», «да» и « ДА » — программа должна понимать все варианты.

**Привычка 2. Собирать строку через `join`, а не через `+=` в цикле.** Это и быстрее,
и читается как «склеить элементы списка таким-то разделителем».

**Привычка 3. Пользоваться `startswith` / `endswith` вместо срезов.** `name.endswith(".txt")`
понятнее, чем `name[-4:] == ".txt"`, и не ошибается на коротких строках.

**Привычка 4. Проверять содержимое методами, а не самодельными проверками.**
`text.isdigit()` вместо сравнения каждого символа с цифрами: короче и работает с Unicode.

**Привычка 5. Помнить о неизменяемости.** `text.upper()` без присваивания — почти всегда
забытая строка: результат просто потерялся.

# Ключевые термины

| Термин | Определение |
|---|---|
| **Строка (`str`)** | неизменяемая последовательность символов |
| **Неизменяемость** | строку нельзя изменить по индексу; методы возвращают новую строку |
| **Индекс и срез** | обращение к символу и части строки: `text[0]`, `text[1:4]` |
| **Unicode** | стандарт кодирования символов; строки Python 3 — Unicode |
| **ASCII** | таблица кодов 0–127; историческая часть Unicode |
| **`ord` / `chr`** | код символа / символ по коду |
| **`split` / `join`** | разбить строку на части / собрать из частей |
| **`splitlines`** | разбить текст по переводам строк (`\n`) |
| **`strip`** | убрать пробельные символы по краям |
| **Метод строки** | действие через точку, возвращает новую строку |
| **f-строка** | строка с подстановкой и форматированием значений |
| **Нормализация** | приведение текста к единому виду: регистр, лишние пробелы |

# Типичные заблуждения

- ❌ **«Строку можно изменить по индексу».** Нельзя: `text[0] = "б"` — `TypeError`.
  Строку собирают заново: срез плюс новая часть, `replace`, `join`.
- ❌ **«`text.upper()` меняет `text`».** Методы возвращают **новую** строку. Без присваивания
  результат теряется.
- ❌ **«`find` выбрасывает ошибку, если не нашёл».** `find` возвращает `-1`. Ошибку выбрасывает
  `index` — и это разные инструменты: `find` удобен для проверки, `index` — когда отсутствие
  подстроки считается ошибкой.
- ❌ **«`split()` и `split(" ")` — одно и то же».** `split()` (без аргумента) разбивает
  по любым пробельным символам и не оставляет пустых кусков; `split(" ")` разбивает строго
  по одиночному пробелу — при двух пробелах рядом получится пустая строка в результате.
- ❌ **«Склеивать строки через `+=` в цикле — нормально».** Каждый раз создаётся новая строка
  и копируется всё накопленное. Правильный способ — собрать список и сделать `join`.
- ❌ **«`len(text)` и `len(text.split())` — то же самое».** Первое — число символов,
  второе — число слов.
- ❌ **«Русские буквы — вне ASCII, значит не работают».** Строки Python 3 — Unicode:
  русский текст и срезы по нему работают без дополнительных настроек.
- ❌ **«Сравнение строк не чувствительно к регистру».** Чувствительно: `"Да" == "да"` — `False`.
  Для сравнения нормализуют регистр.

# Проверь себя

1. Почему строку называют неизменяемой последовательностью и что это значит на практике?
2. Что выведет `"программа"[0:4]` и `"программа"[::-1]`?
3. Чем `find` отличается от `index`?
4. Почему `split()` без аргумента предпочтительнее `split(" ")` при разборе предложения?
5. Как правильно собрать строку из большого числа кусков и почему нельзя `+=` в цикле?
6. Как сравнить введённый ответ «да», «Да» и « ДА » так, чтобы все варианты подошли?
7. Чем `splitlines()` отличается от `split()`?

> [!example]- Ответы
> 1. Строку нельзя изменить «на месте»: `text[0] = "б"` — ошибка `TypeError`. Любое изменение
>    означает, что методы возвращают новую строку: `text.upper()`, `text.replace(...)`,
>    `"б" + text[1:]`.
> 2. `"прог"` — срез с индекса 0 до 4 (не включая). `"аммаргорп"` — строка перевёрнута:
>    срез с шагом `-1` идёт с конца к началу.
> 3. `find(sub)` возвращает `-1`, если подстрока не найдена, — удобно для проверки.
>    `index(sub)` в этой ситуации выбрасывает `ValueError` — удобно, когда отсутствие подстроки
>    действительно считается ошибкой.
> 4. `split()` разбивает по любым пробельным символам и «съедает» кратные пробелы: в тексте
>    с двумя пробелами подряд пустых слов не появится. `split(" ")` разбивает строго
>    по одиночному пробелу и оставит пустые элементы.
> 5. Собрать куски в список и в конце выполнить `"".join(parts)`. Склейка через `+=` создаёт
>    новую строку на каждой операции и копирует всё накопленное: на большом тексте это
>    квадратично по времени.
> 6. Нормализовать ввод: `answer = input("...").strip().lower()` — тогда все три варианта
>    превратятся в `"да"` и сравнение `answer == "да"` сработает.
> 7. `split()` делит строку по пробелам (или другому разделителю), `splitlines()` — по переводам
>    строк `\n`. Второй нужен, когда читаешь текст, разбитый на строки: пустых кусков он
>    не оставляет.
