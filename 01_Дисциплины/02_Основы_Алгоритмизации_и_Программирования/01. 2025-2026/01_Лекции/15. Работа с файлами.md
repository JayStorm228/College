# Pathlib - модуль для упрощения работы с путями и файлами
- `"assets/data.txt"` - такая запись является относительным путём.
- В функцию `open()` можно передавать не только само название файла. Она открывает файл по указанному пути. 
- Если в `src/main.py` вызвать `open("data.txt")`, то мы получим ошибку: файл не найден
## Понятие Current Working Directory
- Каталог, относительно которого интерпретируются относительные пути
- Обычно совпадает с текущей папкой, где находится скрипт.
- При переносе скрипта/запуска из другой папки, CWD меняется, и указанный путь может не обработаться.
## Понятие абсолютного пути
- Путь до файла начиная от корня диска
- Пример: `C:\\Users\\TheRisingStorm\\python\\file.txt`
- В строках с путями необходимо экранирование обратных слешей для корректной обработки пути.

## Да, но...
- Идея передавать абсолютный путь в open() - уже хороший подход. Но можно лучше.
- При таком подходе:
	1. Вручную собирается строки путей
	2. Разные разделители на разных ОС
	3. Работа с путями превращается в ручную обработку родительских/дочерних папок
- Pathlib решает эту проблему.
	1. Путь - объект со своими методами
	2. Оператор / перезаписан для склеивания путей.
```python
from pathlib import Path
CWD = Path.cwd() # ну или Path.(__file__).resolve().parent
DataPath = CWD / "data"

```
## Методы объекта пути
1. `path.open()`
```python
from pathlib import Path     # импортируется класс Path, а не модуль path
CWD = Path.cwd()
DataPath = CWD / "data"
filename = "result.txt"
encoding = "utf-8"

with (DataPath/filename).open("r", encoding=encoding) as f:
	text = f.read()
with (DataPath/filename).open("w", encoding=encoding) as f:
	f.write("text")
```
2. `path.read_text()` - чтение файла в одну строчку
3. `path.read_bytes()` - чтение бинарника
4. `path.write_text()` - запись в файл в одну строчку
5. `path.write_bytes()` - запись в бинарник
6. `path.exists()`
7. `path.is_file()`
8. `path.is_dir()`
9. `path.mkdir()`
10. `path.touch()`

## JSON-файлы. Модуль json.
- JSON - текстовый формат.
```python
import json

data = {
	"name": "TheRisingStorm",
	"scores": (1, 2, 3),
}
json_str = json.dumps(data)
data2 = json.loads(json_str)
```
- Работа с файлами
```python
from pathlib import Path
import json

data = {
	"name": "TheRisingStorm",
	"scores": (1, 2, 3),
}
encoding = "utf-8"
file = Path("data.json")
with file.open("w", encoding=encoding) as f:
	f.write(json.dumps(data, indent=2, ensure_ascii=False))
with file.open("r", encoding=encoding) as f:
	dictionary = f.read()
	loaded = json.loads(dictionary)
```
- Полезные параметры `json.dumps()`:
	1. `indent=2` - количество отступов в файле
	2. `ensure_ascii=False` - допуск кириллицы в данных. Или других не-аски символов
	3. `default=str` - для `datetime`: `str(object)`
- Ограничение: не работает с `set()`, `lambda`
# Pickle - бинарные файлы .pk1
- Примечание - не использовать сторонние .pk1 ради безопасности.
## Основной функционал
```python
from pathlib import Path     # импортируется класс Path, а не модуль path
import pickle as pk

data = {
	"players":[ {"name":"TheRisingStorm", "level":42},
	{"name":"SuppaiLemon", "level":42} ],
	"settings": set([1,2 ])
}
path = Path("save.pk1")
with path.open("wb") as f:
	pk.dump(data, f)
with path.open("rb") as f:
	loaded = pk.load(f)      # load() читает из файла, loads() — из bytes
```
## Дополнительные приёмы
1. `path.write_bytes(pk.dumps(data))`
2. `pickle.loads(path.read_bytes())`
# Shelve
## Основной функционал
```python
import shelve
from pathlib import Path

path = Path("save")
with shelve.open(str(path)) as db:
	# writing
	db["player_001"] = {"name":"TheRisingStorm", "xp":1500}
	db["player_002"] = {"name": "SuppaiLemon", "xp":1200}
	# reading
	print(db["player_002"]["name"])
	# deleting
	del db["player_001"]
```
## Особенности
1. Ключи - только строки
2. Автосохранение при изменении
3. Загружает только нужные ключи
## Режимы работы shelve.open("db", flag=...)
1. flag = "c"
2. flag = "n"
3. flag = "r"
