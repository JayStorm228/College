# Понятие Кортежа - Tuple
- Кортеж - один из способов представления последовательности значений через запятую
- Кортеж - неизменяемая последовательность
Синтаксис:
```python
tup = 1,2,3
tup = 1,
tup = tuple()
tup = (
"Never",
"Gonna",
"Give",
"You",
"Up",
)
```
## Индексация 
- Индекс - порядковый номер элемента, начиная с нуля
- позволяет обращаться к элементу итерируемого объекта
Синтаксис:
```python
a = (1, 2, 3)
print(a[0])
```
# Типизация кортежей
## Приёмы работы с кортежами
1. Нахождение количества значений кортежа
2. Сумма элементов кортежа
3. Сумма произведений
4. Поиск максимального/минимального значения
5. Конкатенация
6. Обмен значений
7. Срезы
```python
tup: tuple[int] = tuple(i for i in range(100))  # именно tuple(...), иначе будет генератор
tup_slice1 = tup[0:25:2]
```

# Понятие словаря - Dictionary
- Словари - массив с индексацией по произвольному объекту
Синтаксис:
```python
dictionary: dict[str, int] = {
	"key1": 1,
	"key2": 2,
}
dictionary["key3"] = 3
```
## Типизация словарей
## Правила создания словарей
1. Уникальный ключ
2. У словарей свои методы
3. Ключ - неизменяемое значение
4. Значения могут быть любыми
