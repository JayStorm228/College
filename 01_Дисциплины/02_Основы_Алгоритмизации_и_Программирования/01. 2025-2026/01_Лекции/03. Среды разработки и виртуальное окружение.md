# Ввод и вывод данных
- Функция `input(text)` используется для ввода данных из консоли
- Возвращает тип данных `str`
- Принимает на вход текст, который выводится на экран перед вводом
- функция `print()`используется для вывода данных на консоль
- Принимает любые данные на вход
Пример использования:
```python
x = input("Enter your name: ")
print(f"Hello, {name}")
```
# Исключения
- Класс внутренних прерываний: `class Exceptions`(???)
## Основные типы исключений:
### 1. IOError
### 2. IndexError
### 3. NameError
### 4. SyntaxError
### 5. TypeError
### 6. ZeroDivisionError

## Пример синтаксиса обработки исключений
```python
try:
	result = 10 / 2          # код, в котором может возникнуть ошибка
except ZeroDivisionError:
	result = None            # что делать при конкретной ошибке
else:
	print("Ошибок не было")   # выполняется, только если исключения не было
finally:
	print("Блок finally выполняется всегда")  # очистка ресурсов
```
