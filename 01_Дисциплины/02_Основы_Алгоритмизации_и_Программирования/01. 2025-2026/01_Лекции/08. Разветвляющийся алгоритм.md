# Понятие разветвляющегося алгоритма
- Последовательность выполняемых команд меняется в зависимости от условий
- Условие - логическое выражение, которое принимает значения `True` / `False`
Простой условный оператор:
```text
if <условие>:
	<тело: что делать, если условие истинно>
else:
	<тело: что делать иначе>
```
Составной условный оператор:
```text
if <условие 1>:
	<команды ветки 1>
elif <условие 2>:
	<команды ветки 2>
else:
	<команды, если ни одно условие не выполнено>
```
Многозначное ветвление:
```text
if <условие>:
	<тело>
	<тело>
	...
else:
	<тело>
	<тело>
	...
```
