# 09. Циклический алгоритм - цикл for

> [!abstract] О чём эта лекция
> Цикл со счётчиком из [[04. Циклический алгоритм — общий вид]] в коде — это `for`.
> Программа перестаёт быть «одно действие» и становится «действие, повторённое много раз»:
> таблицы значений, суммы, подсчёты, обход текста, вложенные циклы.
>
> **Зачем это нужно.** Цикл — самая мощная конструкция языка: одна короткая запись заменяет
> сотни строк. И самая частая причина неверных ответов: счёт начинают с нуля или с единицы
> не подумав, берут не тот конец `range`, забывают про начальное значение накопления.
> Всё это уже разбиралось на схемах — теперь на коде.
>
> **Что ты должен уметь после лекции:** записать цикл со счётчиком через `for` и `range`;
> посчитать, сколько раз выполнится тело; собрать сумму, произведение, количество и максимум;
> обойти строку по символам и текст по строкам; написать вложенный цикл; вовремя выйти
> из цикла через `break`.
>
> **Куда идти дальше:** [[10. Циклический алгоритм - цикл while]] — повторение по условию.

> [!tip] Что нужно знать заранее
> [[04. Циклический алгоритм — общий вид]] (виды циклов, границы, накопление),
> [[07. Линейный алгоритм]], [[08. Разветвляющийся алгоритм]] — цикл внутри тела почти всегда
> работает вместе с условием.

# Цикл `for`

```python
for i in range(1, 6):
    print(i)
```

Что произойдёт: `i` по очереди примет значения 1, 2, 3, 4, 5, и для каждого выполнится тело
цикла — строка `print(i)`. На экране будет:

```text
1
2
3
4
5
```

Разбор записи:

| Часть | Что означает |
|---|---|
| `for` | «для каждого значения из…» |
| `i` | переменная-счётчик: имя, которое выбирают по смыслу |
| `in` | «из последовательности…» |
| `range(1, 6)` | последовательность чисел |
| `:` | конец заголовка цикла |
| отступ в 4 пробела | **тело цикла** — то, что повторяется |

`for` работает с любой последовательностью, не только с числами:

```python
for letter in "код":
    print(letter)          # к, о, д — по одному символу

for line in text.splitlines():
    print(line)            # по строкам текста
```

`text` — это многострочный текст: в нём строки разделены значком `\n` (перевод строки),
а `splitlines()` разрезает его на отдельные строки. Подробно о тексте — в лекции
[[12. Работа со строками]].

# `range`: границы и шаг

`range()` создаёт последовательность чисел и имеет три формы:

| Запись | Значения | Сколько чисел |
|---|---|---|
| `range(5)` | 0, 1, 2, 3, 4 | 5 |
| `range(1, 6)` | 1, 2, 3, 4, 5 | 5 |
| `range(1, 10, 2)` | 1, 3, 5, 7, 9 | 5 |
| `range(10, 0, -1)` | 10, 9, …, 1 | 10 |

Правило, которое надо помнить твёрдо: **правый конец не входит**.

- `range(1, 6)` — числа от 1 **до 5**, потому что 6 — граница, а не участник;
- `range(5)` — то же, что `range(0, 5)`: начало по умолчанию 0, шаг 1.

> [!important] Как посчитать число повторений
> Формула: `(конец − начало) / шаг + 1`, с поправкой на то, что конец не входит.
> `range(1, 6)` → `(6 − 1) / 1 = 5` повторений. `range(0, 10, 2)` → `(10 − 0) / 2 = 5`.
> Если границы стоят «наоборот» (`range(5, 1)` при шаге `+1`), цикл не выполнится ни разу —
> это не ошибка, а нормальное поведение.

# Накопление в цикле

Четыре классические задачи и их начальные значения — правило из блока А работает в коде
буквально.

**Сумма** начинается с нуля:

```python
total = 0
for number in range(1, 101):
    total += number
print(f"Сумма чисел от 1 до 100: {total}")     # 5050
```

**Произведение** — с единицы:

```python
factorial = 1
for number in range(1, 6):
    factorial *= number
print(f"5! = {factorial}")                      # 120
```

**Количество** подходящих значений — с нуля:

```python
count = 0
for number in range(1, 21):
    if number % 3 == 0:
        count += 1
print(f"Чисел, делящихся на 3: {count}")
```

**Максимум** — с первого значения, а не с нуля:

```python
count = int(input("Сколько чисел? "))

maximum = int(input("Число 1: "))               # первое число — точка отсчёта
for i in range(2, count + 1):
    number = int(input(f"Число {i}: "))
    if number > maximum:
        maximum = number

print(f"Максимум: {maximum}")
```

Такой цикл начинается с 2 — первое число уже прочитано до цикла. Это тот самый приём
из [[04. Задачи. Циклический алгоритм]]: сравнение идёт с «лучшим из уже введённых».

# Табулирование: таблица значений

Классическая учебная задача — вывести значения функции на отрезке:

```python
import math

for x in range(0, 6):
    y = 2 * x + 1
    print(f"x = {x:>3}, y = {y:>3}")
```

```text
x =   0, y =   1
x =   1, y =   3
```

`{x:>3}` — формат выравнивания по правому краю шириной 3 — так столбцы не «разъезжаются».

С дробным шагом цикл по `range` не подходит (он работает с целыми). В таких задачах идут
по числу шагов и считают значение по формуле:

```python
import math

start, end, step = 0.0, 3.14, 0.5
steps = int((end - start) / step) + 1

for i in range(steps):
    angle = start + i * step        # угол считаем умножением, а не накоплением шага
    print(f"угол = {angle:.2f}, sin = {math.sin(angle):.4f}")
```

> [!note] Почему угол считается умножением
> Накопление шага (`angle += 0.1`) добавляет ошибку округления на каждом шаге, и результат
> «уплывает»: вместо `0.3` получается `0.30000000000000004`. Умножение ошибку не накапливает.

# Вложенные циклы

Цикл внутри цикла: внешний делает один шаг — внутренний за это время проходит **все** свои.

```python
for row in range(1, 4):             # три строки
    for star in range(1, 6):        # пять звёздочек в каждой
        print("*", end="")          # end="" — без перехода на новую строку
    print()                         # переход на новую строку после строки звёздочек
```

```text
*****
*****
*****
```

Сколько раз выполнится `print("*", end="")`? `3 × 5 = 15` — внутренний цикл проходит целиком
на каждом шаге внешнего. Так обходят таблицы и матрицы: внешний счётчик — строки, внутренний —
столбцы (подробнее — [[13. Вложенные последовательности]]).

# `break` и `continue`

Два оператора управляют ходом цикла:

```python
for i in range(1, 11):
    if i == 5:
        break          # прервать цикл полностью
    if i % 2 == 0:
        continue       # пропустить эту итерацию и перейти к следующей
    print(i)           # выведет 1, 3
```

- **`break`** — досрочный выход: дальше не проверяется ни одно значение.
  Это тот самый «выход по событию» из [[04. Задачи. Циклический алгоритм]];
- **`continue`** — «это значение не подходит, идём дальше», без выхода из цикла.

> [!warning] Пользуйся `break` осознанно
> Если можно записать условие прямо в заголовке цикла — записывай условие. `break` нужен,
> когда условие выхода зависит от вычислений внутри тела (например, «нашли»). Помни: после
> `break` управление уходит на строку **после** цикла, и остаток тела не выполняется.

# Нумерация при обходе: `enumerate`

Когда при обходе нужен и номер, и элемент, руками счётчик не заводят:

```python
for index, letter in enumerate("код", start=1):
    print(f"{index}-я буква: {letter}")
```

`enumerate` отдаёт пары «номер, значение». Второй приём того же рода — `zip`, он идёт по двум
последовательностям сразу; о нём — в лекции [[11. Кортежи, списки, словари]], где разбираются
списки.

> [!tip] Это база, а не «продвинутое»
> `enumerate` — обычный инструмент, которым пользуются каждый день: нужен номер — `enumerate`.
> Он избавляет от лишнего счётчика и ошибок с индексами.

# Как это делают в проекте

**Привычка 1. Считать число повторений до запуска.** «Сколько раз выполнится тело?» — вопрос,
который задают себе перед запуском, а не после. С формулой из этой лекции ответ находится за пару
секунд и сразу выдаёт ошибку в границах.

**Привычка 2. Именовать счётчик по смыслу.** `for i in range(...)` годится для простого перебора;
если счётчик считает дни, учеников или попытки — пусть так и называется: `for day in ...`,
`for attempt in ...`. Имя объясняет, что перебирается.

**Привычка 3. Не менять то, что обходишь.** Удаление элементов списка прямо внутри цикла
по этому списку приводит к «перескокам». Сначала обходит и собирает то, что нужно (обычно
в новый список), и только потом меняет.

**Привычка 4. Помнить про начальное значение накопления.** Сумма — 0, произведение — 1,
максимум — первое значение. Это правило из блока А, и оно не меняется от того, что теперь
всё записано кодом.

# Ключевые термины

| Термин | Определение |
|---|---|
| **Цикл `for`** | цикл, который перебирает значения последовательности |
| **Тело цикла** | строки с отступом после заголовка — то, что повторяется |
| **Итерация** | одно выполнение тела цикла |
| **`range(start, stop, step)`** | последовательность чисел; правый конец не входит |
| **Счётчик** | переменная цикла (`i`, `number`, `day`), меняется автоматически |
| **Накопление** | сбор результата в переменной: `total += number` |
| **Переменная-флаг** | переменная-признак события: `found = True` — «нашли» |
| **`break`** | досрочный выход из цикла |
| **`continue`** | пропуск текущей итерации |
| **Вложенный цикл** | цикл внутри цикла; внутренний выполняется целиком на каждом шаге внешнего |
| **`enumerate`** | нумерация элементов при обходе |
| **`zip`** | обход двух последовательностей одновременно |

# Типичные заблуждения

- ❌ **«`range(1, 6)` — это до 6 включительно».** Правый конец не входит: значения 1–5.
- ❌ **«`range(5)` — это от 1 до 5».** От 0 до 4: начало по умолчанию 0.
- ❌ **«Максимум начинают с нуля».** Если все числа отрицательные, ответом станет 0 — значение,
  которого не было среди данных.
- ❌ **«Пропуск шага — не важно».** `range(0, 10, 3)` даёт 0, 3, 6, 9 — четыре числа, а не три;
  шаг считается по границам, а не «на глазок».
- ❌ **«`break` после цикла что-то продолжает».** `break` заканчивает цикл сразу: остаток тела
  и все оставшиеся значения пропускаются.
- ❌ **«Дробный шаг в `range` сработает».** `range` работает только с целыми. Дробный шаг —
  через количество шагов и умножение (`start + i * step`).
- ❌ **«Вложенные циклы — это два цикла подряд».** Внутренний выполняется целиком на каждом шаге
  внешнего: для 3 и 5 это 15 раз, а не 8.

# Проверь себя

1. Сколько раз выполнится тело `for i in range(2, 11, 3)` и какие значения примет `i`?
2. Почему сумму начинают с нуля, а произведение — с единицы?
3. Как найти максимум, если заранее известно только количество чисел?
4. Чем `break` отличается от `continue`?
5. Сколько раз выполнится внутреннее действие в двух вложенных циклах по 4 шага?
6. Почему при дробном шаге значение считают умножением, а не прибавлением шага?

> [!example]- Ответы
> 1. Три раза: `i` примет значения 2, 5, 8. `11` — граница и в последовательность не входит;
>    2 + 3 = 5, 5 + 3 = 8, 8 + 3 = 11 — стоп.
> 2. К нулю можно прибавлять без последствий, и сумма пустого набора равна нулю. Произведение
>    с нуля обнулилось бы: `0 * a = 0`. Единица — нейтральное значение для умножения.
> 3. Прочитать первое число до цикла и сделать его текущим максимумом, а остальные сравнивать
>    с ним, обновляя при «больше». Начинать с нуля нельзя: среди отрицательных чисел максимумом
>    окажется 0, которого во вводе не было.
> 4. `break` заканчивает цикл полностью, `continue` только пропускает текущую итерацию
>    и переходит к следующей.
> 5. 16 раз: внутренний цикл проходит все 4 шага на каждом из 4 шагов внешнего: `4 × 4 = 16`.
> 6. Каждое сложение дробного шага добавляет ошибку округления, и накопленная погрешность
>    «уводит» значение (0.1 + 0.1 + 0.1 даёт не ровно 0.3). Умножение `start + i * step`
>    ошибку не накапливает.
