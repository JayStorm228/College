- Класс - шаблон, описывающий, какие данные будут у объекта и что он сможет делать
- Объект - конкретная структура, выстроенная по шаблону
- Атрибуты - переменные внутри объекта, хранящие его данные
- Методы - функции внутри класса, которые определяют поведение объекта и работают с его атрибутами
```python
class Car:
	def __init__(self, brand:str, color:str):
		self.brand = brand
		self.color = color
		self.is_moving = False
	def start_engine(self):
		self.is_moving = True
		print(f"{self.brand!r} поехала!")
def main():
	my_car = Car(brand="Tesla", color="Red")
	print(my_car.color)
	my_car.start_engine()
if __name__ == "__main__":
	main()
```
# Наследование, Полиморфизм и Специальные методы
- Наследование - создание нового класса на основе имеющегося класса.
- Дочерний класс получает все атрибуты/методы родителя
- Полиморфизм - возможность объектов разных классов иметь методы с одинаковым названием, но разной логикой.
- Специальные методы - начинаются и заканчиваются двойным нижним подчёркиванием. Позволяют объектам взаимодействовать со встроенными функциями языка
```python
class Animal:
	def __init__(self, name):
		self.name = name
	def speak(self):
		pass
class Dog(Animal):
	def speak():
		return f"{self.name!r} говорит \"Гав!\""
class Cat(Animal):
	def speak():
		return f"{self.name!r} говорит \"Мяу!\""
def main():
	animals = [Dog("Шарик"), Cat("Леся")]
	for w in animals:
		print(w.speak())
if __name__ == "__main__":
	main()
```
## Ключевой инструмент - super()
- встроенная функция, которая вызывает объект-прокси, позволяющий вызывать методы родительского класса в дочернем
- Используется для расширения наследуемых методов
```python
class Book:
	def __init__(self, title, author):
		self.title = title
		self.author = author
class EBook(Book):
	def __init__(self, title, author, file_size)
		super().__init__(title, author)
		self.file_size = file_size
```

# Атрибуты класса. Декораторы @classmethod, @staticmethod
- Атрибуты класса - переменные, объявленные внутри класса, но вне его функций
- Изменение атрибута класса отобразится во всех его объектах
- @classmethod - декоратор для методов, привязанных к самому классу. Вместо self принимают cls - ссылку на сам класс, а не на его инстанс
- Используется часто для создания объекта на основе данных из json структур, а не через инициализацию
- @staticmethod - декоратор для методов, обозначающий простую функцию внутри класса. Не может изменять состояние объектов
- Часто используется для вспомогательных утилит класса
- Инкапсуляция - механизм скрытия внутренних деталей реализации. 
- В Python реализуется через соглашения:
	1. `__name` - Приватный атрибут. Python физически затрудняет доступ извне класса
	2. `_name` - Защищённый атрибут. Буквально: "Не трогай меня вне класса, пожалуйста"
## Обычная функция или @staticmethod?
- статический метод:
	- Логическая связь с классом
	- Удобство обнаружения и инкапсуляция
		- Например валидация формата данных
	- Гибкость вызова
		- Вызов как через имя класса, так и через объект
- Обычная функция:
	- Если она универсальна и используется во многих частях проекта.

- Дексриптор - любой объект, который реализует хотя бы один из специальных методов протокола: 
	- `__get__`
	- `__set__`
	- `__delete__`
- Дескрипторы хранятся в атрибутах класса, а не в экземплярах
- Позволяют перехватывать и настраивать логику доступа к данным
- @property - встроенная реализация дескриптор, и позволяет превратить метод в атрибут, доступный только для чтения или добавить логику при его изменении
