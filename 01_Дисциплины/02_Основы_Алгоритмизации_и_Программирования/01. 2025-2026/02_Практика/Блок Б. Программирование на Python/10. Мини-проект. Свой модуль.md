# 10. Мини-проект. Свой модуль

> [!abstract] Что за работа
> Третий мини-проект блока Б. Здесь впервые получается **настоящая структура проекта**:
> не один файл с программой, а два файла с разными ролями — модуль с функциями
> и программа, которая эти функции использует. Данные берутся из файла, а результат
> сохраняется в отдельный файл.
>
> Готового решения нет. Под спойлером — **пример-аналог из другой темы**: такой же проект,
> но про погоду, а не про оценки.
>
> **Когда делать:** после лекций 14–15, когда пройдены функции, модули, файлы, `pathlib`
> и JSON.

# Что должно получиться

Папка проекта из трёх файлов (плюс два, которые программа создаст сама):

```text
grades/
├── grades.py        ← модуль: функции для работы с записями
├── main.py          ← программа: читает файл, печатает отчёт, сохраняет JSON
└── grades.csv       ← данные (делаешь сам по образцу ниже)
```

`grades.csv` — обычный текст, одна запись в строке, поля через точку с запятой:

```text
Математика;4
Физика;5
История;3
Информатика;5
Литература;4
```

Что должна делать программа `main.py`:

1. читает `grades.csv` из **своей** папки (не из текущего каталога терминала);
2. печатает: сколько записей, средний балл (два знака после запятой), лучший предмет
   с баллом, список предметов с баллом не ниже 4 и сколько пятёрок;
3. сохраняет в `report.json` сводку из четырёх ключей: `count`, `average`,
   `best_subject`, `best_score`;
4. если файла с данными нет — печатает понятное сообщение и **не падает**.

Так это выглядит (формулировки — твои, важны числа и сохранённый файл):

```text
Записей: 5
Средний балл: 4.20
Лучший предмет: Физика — 5
Балл не ниже 4: Математика, Физика, Информатика, Литература
Пятёрок: 2
Отчёт сохранён: report.json
```

# Требования

| # | Требование | Что тренируется |
|---|---|---|
| 1 | Функции живут в `grades.py`, а не в `main.py` | модули и импорт из [[14. Функции и модули]] |
| 2 | В модуле минимум четыре функции: чтение файла, средний балл, лучший предмет, отбор по баллу | декомпозиция: одна функция — одна работа |
| 3 | Функции **не читают ввод и не печатают**: данные приходят аргументами, результат уходит через `return` | «чистая» функция, которую легко проверить |
| 4 | Путь к файлу строится от `Path(__file__)`, а не строкой `"grades.csv"` | путь не зависит от того, откуда запущено |
| 5 | Все файлы открываются с `encoding="utf-8"` | русские буквы не превращаются в «кракозябры» |
| 6 | `main()` и `if __name__ == "__main__":` в `main.py` | точка входа из [[14. Функции и модули]] |
| 7 | Обработан `FileNotFoundError`: сообщение и аккуратный выход | ошибки работы с файлами из [[15. Работа с файлами]] |
| 8 | Результат сохранён в `report.json`: `json.dumps(..., ensure_ascii=False, indent=2)` | чтение человеком и повторный запуск |
| 9 | Есть docstring у модуля и у каждой функции | про `"""..."""` — [[14. Функции и модули]] |
| 10 | Программа одинаково работает и из своей папки, и из другой | проверка, что путь построен верно |

# Как идти к результату

1. **Создай папку и данные.** Внутри проекта — `grades/`. Набери `grades.csv` руками: пять
   строк, как в образце. Пока никакого кода.
2. **Напиши первый вариант в одном файле.** Пусть программа читает файл и печатает
   количество записей. Так проверяется самое хрупкое место — путь к файлу. Запусти из папки
   проекта **и** из родительской папки (в терминале: `python3 grades/main.py`) — результат
   должен быть одинаковым.
3. **Раздели на два файла.** Создай пустой `grades.py`, перенеси туда функцию чтения,
   а в `main.py` оставь только импорт и вызов. Запусти: если появилось
   `ModuleNotFoundError`, значит файлы лежат не в одной папке — это тот случай, о котором
   говорит [[14. Функции и модули]].
4. **Добавь расчёты.** В модуле — функции среднего балла и лучшего предмета. Помни про две
   ловушки: делить на количество нельзя при пустом списке (верни `None`), а лучший предмет
   сравнивается по полю `score`, а не по всему словарю сразу.
5. **Добавь отбор.** Функция, которая возвращает **список** предметов с баллом не ниже
   заданного: `min_score` приходит аргументом, а не задаётся внутри. Проверь на `4`:
   должно получиться четыре предмета.
6. **Добавь отчёт.** Посчитай сводку в `main.py` и запиши её в `report.json` через `json`
   с `ensure_ascii=False`. Открой файл в VS Code и посмотри, что получилось: он должен
   читаться человеком.
7. **Добавь защиту от отсутствия файла.** Оберни чтение в `try` / `except FileNotFoundError`
   и напечатай, какого файла не хватает. Проверь специально: переименуй `grades.csv`,
   запусти, верни имя обратно.
8. **Причеши.** Docstring у модуля и функций, пустые строки между функциями (PEP 8),
   отчёт по разделам.

> [!example]- Пример-аналог из другой темы: дневник погоды
> **Задача другая:** не оценки, а температуры по дням. Устройство то же: папка проекта,
> модуль с чистыми функциями, `main.py` с точкой входа, данные в файле, сводка в JSON,
> обработанное отсутствие файла. Ответа на твой проект здесь нет.
>
> **`weather.py`**
>
> ```python
> """Разбор дневника погоды: свои функции."""
>
>
> def read_days(path):
>     """Читает строки «дата;температура» и возвращает список словарей."""
>     days = []
>     with path.open("r", encoding="utf-8") as file:
>         for line in file:
>             line = line.strip()
>             if line == "":
>                 continue
>             date, temperature = line.split(";")
>             days.append({"date": date, "temperature": float(temperature)})
>     return days
>
>
> def average_temperature(days):
>     """Средняя температура; None, если записей нет."""
>     if len(days) == 0:
>         return None
>     total = 0.0
>     for day in days:
>         total += day["temperature"]
>     return total / len(days)
>
>
> def coldest_day(days):
>     """Самая холодная запись; None, если записей нет."""
>     if len(days) == 0:
>         return None
>     best = days[0]
>     for day in days:
>         if day["temperature"] < best["temperature"]:
>             best = day
>     return best
> ```
>
> **`main.py`**
>
> ```python
> """Программа: читает дневник погоды, печатает итог и сохраняет сводку в JSON."""
>
> import json
> from pathlib import Path
>
> from weather import average_temperature, coldest_day, read_days
>
> BASE_DIR = Path(__file__).resolve().parent
>
>
> def main():
>     """Точка входа: файл ищется рядом с программой, а не в текущем каталоге."""
>     data_path = BASE_DIR / "days.csv"
>     try:
>         days = read_days(data_path)
>     except FileNotFoundError:
>         print(f"Нет файла {data_path.name}: положите его рядом с программой")
>         return
>
>     average = average_temperature(days)
>     if average is None:
>         print("Записей нет")
>         return
>
>     cold = coldest_day(days)
>     print(f"Записей: {len(days)}")
>     print(f"Средняя температура: {average:.1f}")
>     print(f"Самая холодная: {cold['date']} — {cold['temperature']:.1f}")
>
>     summary = {"days": len(days), "average": round(average, 1), "coldest": cold}
>     (BASE_DIR / "summary.json").write_text(
>         json.dumps(summary, ensure_ascii=False, indent=2), encoding="utf-8"
>     )
>     print("Сводка сохранена в summary.json")
>
>
> if __name__ == "__main__":
>     main()
> ```
>
> **Данные `days.csv`:**
>
> ```text
> 2026-01-10;-3.5
> 2026-01-11;-8.0
> 2026-01-12;1.5
> 2026-01-13;-1.0
> ```
>
> **Пример запуска:**
>
> ```text
> Записей: 4
> Средняя температура: -2.8
> Самая холодная: 2026-01-11 — -8.0
> Сводка сохранена в summary.json
> ```
>
> **Получившийся `summary.json`:**
>
> ```json
> {
>   "days": 4,
>   "average": -2.8,
>   "coldest": {
>     "date": "2026-01-11",
>     "temperature": -8.0
>   }
> }
> ```
>
> **Что здесь стоит перенять.**
>
> - В модуле **нет ни одного `print` и ни одного `input`**: он только считает. Печать —
>   работа `main.py`. Поэтому функции можно вызвать и проверить по отдельности.
> - `BASE_DIR` считается один раз в начале `main.py` и дальше используется как основа
>   для всех путей: `BASE_DIR / "days.csv"`, `BASE_DIR / "summary.json"`.
> - Строка разбирается сразу: `line.split(";")` даёт две части, и они превращаются
>   в словарь `{"date": ..., "temperature": ...}`. Пустые строки пропускаются — файл,
>   где в конце остался лишний перевод строки, читается без ошибок.
> - Пустой список — не ошибка: `average_temperature` возвращает `None`, а `main.py`
>   решает, что печатать. Функция ничего не «знает» про печать.
> - Отсутствие файла — **ожидаемая** ситуация: `try` / `except FileNotFoundError` вокруг
>   одного вызова, сообщение с именем файла, аккуратный `return` вместо аварии.
> - Запуск из другой папки ничего не ломает: `Path(__file__)` указывает на сам файл
>   программы, а не на текущий каталог.
>
> **Чего в примере нет:** проверки, что температура — это число (файл с буквами уронит
> программу), сортировки записей, чтения нескольких файлов. Такие же границы будут
> и в твоём проекте.

# Как проверить свою работу

Проверяй на своих данных, набранных из образца:

| # | Что проверяю | Ожидаемое |
|---|---|---|
| 1 | Количество записей | `5` |
| 2 | Средний балл | `4.20` |
| 3 | Лучший предмет | `Физика — 5` |
| 4 | Балл не ниже 4 | `Математика, Физика, Информатика, Литература` — ровно четыре |
| 5 | Пятёрок | `2` |
| 6 | `report.json` | содержит `count`, `average`, `best_subject`, `best_score`; русский текст читается |
| 7 | Запуск из другой папки | `python3 grades/main.py` из родительской папки даёт то же самое |
| 8 | Нет файла данных | сообщение и выход, без «красного» traceback |
| 9 | Пустой файл данных | `average` не считается; программа сообщает, что записей нет |
| 10 | Функция с нулём внутри | `average_score([])` возвращает `None`, а не падает |

Проверки 9 и 10 — про границы: пустой список записей и пустой файл. Их удобно делать
специально: закомментируй строки в `grades.csv` (или создай пустой файл) и посмотри,
что скажет программа.

> [!tip] Если застрял
> - **`ModuleNotFoundError: No module named 'grades'`.** `main.py` и `grades.py` должны
>   лежать в одной папке, и запускать нужно из неё. В VS Code открой папкой именно
>   `grades/`, а не весь курс — про это в [[06. Среды разработки и виртуальное окружение]].
> - **`FileNotFoundError` при верном имени файла.** Почти всегда путь считается
>   от текущего каталога, а не от файла программы. Проверь, что путь собран
>   через `Path(__file__).resolve().parent`, и напечатай его: `print(data_path)`,
>   `print(data_path.exists())`.
> - **`json.decoder.JSONDecodeError` при чтении.** Значит, в файле не JSON: `json.dumps`
>   сохранял словарь, а ты записал туда `str(словарь)`. Всегда записывай результат `dumps`.
> - **Средний балл `4.2` вместо `4.20`.** Это формат вывода: `f"{average:.2f}"`.
> - **Лучший предмет выбирается неверно.** Смотри, что сравниваешь: `record["score"]`,
>   а не `record` целиком. Начальным значением бери **первую запись**, а не `0`
>   и не пустой словарь.
> - **В файле «кракозябры».** Не указано `encoding="utf-8"` при записи.
> - **Совсем не идёт** — сделай минимальную версию: `main.py` читает файл и печатает
>   первые две строки. Работает — добавляй по одной функции, каждый раз запуская.

# Что сдать

1. Папку проекта: `grades.py`, `main.py`, `grades.csv` (и `report.json`, который
   получился после запуска).
2. **Доказательство работы из другой папки:** скриншот или две строки терминала,
   где запуск `python3 grades/main.py` из родительского каталога даёт тот же отчёт.
3. Отчёт о границах (3–5 пунктов): что произошло без файла данных, с пустым файлом,
   что вернула функция среднего на пустом списке — и что осталось не предусмотрено
   (например, «строка без точки с запятой уронит чтение»).

# Частые ошибки

| Ошибка | Как выглядит | Как правильно |
|---|---|---|
| Всё в одном файле | «модуль» — это `main.py` с четырьмя функциями | функции в `grades.py`, импорт в `main.py` |
| Функция печатает результат | нельзя ни переиспользовать, ни проверить | `return`, а печать — в `main` |
| Путь строкой | работает у тебя, не работает у другого | `Path(__file__).resolve().parent / "grades.csv"` |
| Забыта кодировка | `UnicodeDecodeError` или «кракозябры» | `encoding="utf-8"` везде |
| Деление на пустом списке | `ZeroDivisionError` | проверить длину, вернуть `None` |
| Сводка через `str(...)` | в файле непонятная строка вместо JSON | `json.dumps(summary, ensure_ascii=False, indent=2)` |
| `input()` внутри функции чтения | функцию нельзя запустить на тестовых данных | путь приходит аргументом |
| Нет `main()` | код выполняется даже при импорте модуля | `if __name__ == "__main__": main()` |
