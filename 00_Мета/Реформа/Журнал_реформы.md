- **Цель:** устранить главную терминологическую неоднозначность (двойная нумерация 01–07 vs 01–24,
  R0 §4 A2): зафиксировать однозначное соответствие дисциплин репозитория и генерального плана
  и создать единый словарь терминов для всех последующих сессий (RF-01). Подготовка, не миграция.
- **Исследованные документы:** `R0_Аудит_состояния_репозитория` (§1–§17), `РЕФОРМА_BACKLOG`
  (RF-01…RF-16), этот журнал, генеральный план `МОДЕРНИЗАЦИЯ/02` (v1.0: §2 статусы, §8 Блок D,
  §12 про C++, §22–26 маршруты и граф, §28–31), `МОДЕРНИЗАЦИЯ/01` (§2 «дисциплина — не маршрут»),
  `МОДЕРНИЗАЦИЯ/03` (§2 потоки, §9 сырьё), `00_Контекст` (§2.3 «Дисциплина = курс»), `Соглашения`
  (§1 YAML, §5 именование, §9 приоритет дисциплин, §12 уровни курсов), `Реестр_дисциплин`
  (срез по 7 дисциплинам + «Курсы базы»), `Дорожная карта` (09.02.07), `Курсы — обзор`,
  оглавления `00_Курс`/`00. …` дисциплин и курсов (разделы «Связи с другими дисциплинами»,
  «Опора на дисциплину 02»), `Передача_работы` (решения владельца: граница 06 — 03.10.2026,
  вариант A для C++, Р7/Р8). **Стратегическим документом ГП признан `МОДЕРНИЗАЦИЯ/02`**
  (единственный документ, претендующий на роль плана; Дорожная карта — траектория, не план).
- **Созданные файлы:** `00_Мета/Реформа/Карта_соответствия_дисциплин.md` (мастер-таблица:
  7 РЕПО + 24 ГП + К1–К5 + ВЕБ + 9 мета-сущностей; типы отношений A/B/C разделены по §2/§4/§5;
  гуманитарный блок §6; «Курс ≠ дисциплина» §7; споры Q1–Q6 §8),
  `00_Мета/Реформа/Словарь_реформы.md` (27 терминов: определение/не-означает/пример;
  правила обращения и именования: `ГП-NN`, `РЕПО-NN`, `КN`, `ВЕБ`, резерв `СП-`/`Т-`;
  рабочая версия границы «дисциплина/курс», согласованная с Контекстом §2.3 и МОДЕРНИЗАЦИЯ/01 §2).
- **Изменённые файлы:** `РЕФОРМА_BACKLOG` (RF-01 → `частично выполнена / требует решения
  владельца` с результатом R0.2; RF-06 расширен на фрагмент `02_Курсы/Веб/`; добавлены
  RF-17/RF-18/RF-19), этот журнал.
- **Найденные неоднозначности:**
  1. **Q1 (главная):** организационное соответствие РЕПО-03 — название ≈ ГП-15, содержимое
     ООA/CASE/UML ≈ ГП-14 (частично подтверждено) + ГП-13 (гипотеза), «кода» в папке нет;
  2. **Q2:** гуманитарный блок РЕПО-04/05/07 вне ГП-24 — решение владельца (варианты A/B/C в карте §6);
  3. **Q3:** ГП §2 «Изучается сейчас» для ГП-17/18/19 при 0 материалов в репозитории;
  4. **Q6:** C++ преподаётся в колледже (К5 ждёт «тем с пар»), но к какому предмету колледжа — неизвестно;
  5. **новое, внутреннее в ГП:** схема в тексте ГП §6 ({22,23}→{07,04,13,19}) расходится с графом
     ГП §26 (рёбер 22→04, 23→07, 22/23→13 в графе нет) — ГП не правился, зафиксировано для RF-08;
  6. **формальное:** дата версии ГП v1.0 (07.10.2026) позже даты R0-аудита (06.10.2026), на который
     опирается ГП — зафиксировано для RF-08, без интерпретации.
- **Принятые правила:** (1) в документах реформы голые номера дисциплин запрещены — только
  `ГП-NN` / `РЕПО-NN` / `КN` / `ВЕБ` (регистр канонически заглавный; `репо-02` из R0-аудита
  приравнивается к `РЕПО-02`); (2) три типа отношений (A-организационное, B-содержательное
  пересечение, C-профессиональная связь) не смешиваются — в разных разделах карты; (3) курсу
  не присваивается ГП-номер «ради симметрии» — курс относится к ГП только пересечением (тип B);
  (4) рабочая граница «дисциплина = единица программы, курс = спроектированная последовательность»;
  правило Контекста «Дисциплина = курс» читается как «каждая дисциплина спроектирована как курс»;
  (5) статусы соответствия: `подтверждено` / `частично подтверждено` / `рабочая гипотеза` /
  `требует проверки` / `вне ГП-24 — решение владельца` / `материалов нет` / `не назначается`
  (фиксированный словарь в карте, шапка §-статусов); (6) гуманитарный блок — только
  «вне ГП-24 / требует решения владельца», без решений о включении/исключении; (7) новые
  идентификаторы типов сущностей — только с регистрацией префикса в словаре (зарезервированы
  `СП-` (R6) и `Т-` (R3.2)).
