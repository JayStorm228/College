## Р1 · Правило курсов ^rulecrs

**Оценка:** блокирует перекладку папок и «отформатировать курсы». Владелец сам пишет, что точный принцип, возможно, дорисуется после заполнения базы. Поэтому в [[Соглашения]] не записано: на ревью подтверждается черновик ниже.

Слиты три формулировки ежедневника: правило создания курсов (🔺), отформатировать курсы по правилу (🔺), разложить курсы по направлениям. Это один проход, не три стройки.

Черновик, если ревью без правок:

| Вид | Зависимости | Пример |
|---|---|---|
| Дисциплина | программа колледжа | 01–07. Новые разделы — только по решению или по прикреплённой основе |
| Курс начальный | нет другого курса. Опора — дисциплина или «с нуля», если в колледже темы нет | HTML после П4. Инженерные практики: опора — дисциплина 02, блок Python, не другой курс |
| Курс продвинутый | список курсов в оглавлении | NumPy, Pydantic, Matplotlib опираются на курс 1. NumPy не должен требовать Pydantic |
| Мини-тема | папка, одна лекция и одна практика | `.env`, dataclass, пока Git не разросся. Это же Р5 |

Порядок для читателя — только в дорожной карте П1, не в разрозненных «что дальше». Параллельно можно то, чего нет в зависимостях друг друга.

**Не делать до записи правила в [[Соглашения]]:** не переименовывать дерево курсов, не «форматировать все курсы».
