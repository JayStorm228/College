# 7. Как выгрузить в `main`

`main` — прямой предок ветки, слияние — **fast-forward без конфликтов**.

```bash
git fetch origin main arena/01a0dabe-college
git checkout main
git merge --ff-only arena/01a0dabe-college
git push origin main
# или через PR: arena/01a0dabe-college → main (ветка уже запушена)
```

Проверка перед сливом:
```bash
git fetch origin main && git merge-base --is-ancestor origin/main HEAD && echo "fast-forward возможен" || echo "нужен merge"
```

После слива новые материалы доступны в `main`; дальнейшая работа — в новой ветке от `main` (Django-мост, pandas и т.д.).
