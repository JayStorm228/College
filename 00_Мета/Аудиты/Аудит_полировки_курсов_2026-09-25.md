## Ловушка отката `.git` — проверено и задокументировано

В песочнице `.git` может откатиться к старому клону (`6284155`). Тогда `git status` покажет «всё чисто», а `push` отклонится с `non-fast-forward`, хотя ветка выглядит своей. Признак — `merge-base --is-ancestor refs/remotes/origin/<ветка> HEAD` отвечает «НЕ предок».

**Лечение** (проверено 26.09.2026, описано в [[Передача_работы]] §7):

```bash
git fetch origin "refs/heads/<ветка>:refs/remotes/origin/<ветка>"
git reset --mixed refs/remotes/origin/<ветка>
git status --porcelain; git diff --stat   # проверить, что в diff только ожидаемое
git add -A && git commit -m "..." && git push origin <ветка>
```

В этой сессии откат уже случился (ветка `arena/01a0dabe-college` была усечена до 1 коммита, `grafted`). Лечилось так:

```bash

git checkout arena/01a0dabe-college
git reset --hard origin/arena/01a0d29d-college   # 3a3b44e
git push origin arena/01a0dabe-college           # ветка создана на удалённом, готова к работе
```
