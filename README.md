# College — учебная база

Obsidian-хранилище с конспектами и курсами. Собрано как единый учебный ресурс: от первых алгоритмов на схемах до веб-приложения на Django плюс курсы вне программы колледжа.

> Если открываешь базу впервые — начни с **«Как пользоваться»** ниже. Если вернулся после перерыва — сразу в нужный курс или практику.

## Что внутри

| Раздел | Что это | Где искать |
|---|---|---|
| **Дисциплина 01** | Технология разработки ПО: жизненный цикл, командная работа, код и техдолг | `01_Дисциплины/01_Технология_Разработки_ПО/` |
| **Дисциплина 02** | Основы алгоритмизации и программирования — **курс с нуля до Django**: 16 лекций, 47 задач в 7 практиках, 5 мини-проектов | `01_Дисциплины/02_Основы_Алгоритмизации_и_Программирования/00_Курс.md` |
| **Курсы 1–4** | Инженерный модуль вне программы: 1) Инженерные практики Python, 2) NumPy, 3) Pydantic, 4) Matplotlib (каждый — лекции + практики + мини-проект) | `02_Курсы/00. Курсы — обзор.md` |
| **Остальные дисциплины** | 03, 04, 05, 06, 07 — конспекты в разной степени готовности | `01_Дисциплины/` |

Каждый курс и каждая дисциплина читаются **самостоятельно**: понятие определяется в той же заметке, примеры запускаются, есть «Проверь себя» с ответами и «Связи с другими темами».

## Как пользоваться

1. **Открой как Obsidian-хранилище** — папку `College`. Плагины: Dataview, Templater, Tasks, Calendar (настроены, ставить отдельно не нужно).
2. **Точка входа по дисциплине 02** — `00_Курс.md` внутри `01_Дисциплины/02_...`: порядок прохождения, уровни, оглавление, карта понятий, где практиковаться дальше.
3. **Точка входа по курсам** — `02_Курсы/00. Курсы — обзор.md`: карта курсов, что после чего проходить, как они связаны между собой и с дисциплиной 02.
4. **Практика:** в каждой лекции — раздел «Практика» (куда идти) и «Опора на дисциплину 02» (откуда тема пришла). Сначала пробуешь сам, потом открываешь разбор под спойлером.
5. **Мини-проекты** — без готового решения: требования, план шагов, пример-аналог из другой темы и чек-лист самопроверки.

> База самодостаточна: внешние учебники, тетради и старые архивы с кодом для прохождения не нужны. Весь учебный код и разборы уже встроены в лекции и практики. Исторический архив `CollegeProgramming` (если встретишь упоминание) — это наследие, вынесенное в отдельный репозиторий на GitHub; в базе остались только знания и приёмы из него.

## Структура папок

```
College/
├── 00_Мета/               — правила, аудиты, бэклог, журнал изменений, скрипты
├── 01_Дисциплины/          — учебный материал по предметам
│   └── 02_Основы_Алгоритмизации_и_Программирования/
│       ├── 00_Курс.md
│       ├── 01. 2025-2026/01_Лекции/   — 16 лекций
│       ├── 01. 2025-2026/02_Практика/ — задачи и мини-проекты
│       └── 02. 2026-2027/01_Лекции/   — Django (пополняется)
├── 02_Курсы/               — 4 курса вне программы
├── Шаблоны/                — шаблоны лекции/практики/курса
├── Вложения/               — изображения
└── Диаграммы/              — draw.io
```

## Проверки и выгрузка

```bash
python3 00_Мета/проверка_базы.py                 # вся база: YAML, заголовки, задачи, ссылки, код
python3 00_Мета/проверка_базы.py --subject 02    # только дисциплина 02
python3 00_Мета/проверка_базы.py --subject NumPy # только курс
python3 00_Мета/экспорт_в_notebooklm.py          # сборка _Экспорт/ для NotebookLM (в git не попадает)
```

Проверка — одна команда; «проверено» в журнале означает реально прогнанную команду.

## Для себя на будущее (если забудешь)

- **Где правила оформления?** — `00_Мета/Соглашения.md` (YAML, заголовки, ссылки, задачи).
- **Где что осталось доделать?** — `00_Мета/Бэклог.md` (ближайшая работа + задачи по дисциплинам).
- **Что и когда менялось?** — `00_Мета/Журнал_изменений.md`.
- **Состояние дисциплин и курсов?** — `00_Мета/Реестр_дисциплин.md`.
- **Полный контекст и порядок работы?** — `00_Мета/00_Контекст.md`.
- **Технические детали, ветки, чек-листы для агентов?** — `00_Мета/Передача_работы.md` (не для чтения студентом, только для продолжения работы над базой).

База задумана как один связный ресурс: каждая заметка ссылается на связанные, все ссылки проверяются скриптом.
