# College — учебная база по направлению «Информационные системы и программирование»

Obsidian-хранилище со всеми предметами направления: конспекты лекций, практические работы, разборы задач и отдельные курсы за пределами программы колледжа. Дисциплины собраны в один связный ресурс: каждая тема определяется в своей заметке, а ссылки ведут на смежные темы, в том числе в других предметах.

> Впервые в базе — начни с раздела **«С чего начать»**. Вернулся после перерыва — открой `00_Курс.md` нужной дисциплины: там порядок тем, карта понятий и подготовка к экзамену.

## Курсы вне программы колледжа

Папка `02_Курсы/` — материал, не привязанный к учебному плану. Курсы опираются на дисциплины, ссылаются на конкретные лекции и делятся на начальные, продвинутые и компактные мини-темы. Обзор и зависимости — [`Курсы — обзор.md`](02_Курсы/Курсы%20%E2%80%94%20обзор.md). Полная профессиональная траектория — [дорожная карта (Markdown)](02_Курсы/Дорожная%20карта.md) и [HTML-версия](02_Курсы/Дорожная%20карта.html).

| Курс | Уровень | О чём |
|---|---|---|
| 1. Инженерные практики Python | Продвинутый | Ошибки, типизация, тесты, Git, структура проекта, отладка, читаемость |
| 2. NumPy | Продвинутый | Массивы, векторизация, маски, статистика |
| 3. Pydantic | Продвинутый | Модели, валидация, сериализация, настройки приложения |

Начальный HTML/CSS/веб-курс ещё предстоит собрать. Полный курс C++ гарантированно нужен, но его архитектуру владелец выбирает по `00_Мета/Варианты_курса_C++.md`; до этого курс не строится. Rust и внешний курс Git остаются личными задачами владельца.

## С чего начать

1. **Открой папку `College` как Obsidian-хранилище.** Плагины уже настроены и лежат в репозитории: Dataview, Templater, Tasks, Calendar, Kanban, Advanced Tables, draw.io, url-into-selection, edit-history. Ставить их отдельно не нужно.
2. **Выбери дисциплину** из таблицы выше и открой её `00_Курс.md` (там, где он уже есть).
3. **Читай по порядку тем.** Каждая лекция самодостаточна: понятие определяется в той же заметке, примеры запускаются, в конце есть «Связи с другими темами».
4. **Практикуйся.** Если для темы есть практическая работа, ссылка на неё указана в лекции или оглавлении дисциплины. Сначала пробуй сам, потом открывай разбор под спойлером.
5. **Нужны правила оформления или свежий срез состояния** — см. «Служебная папка» ниже.

> Дисциплина 02 и курсы `02_Курсы/` устроены как полноценные учебные курсы с нуля; остальные дисциплины собираются по мере появления материала с пар. Подробности, чего в каких предметах ещё не хватает, — в Реестре и Бэклоге.

## Структура папок

```
College/
├── 00_Мета/          — правила, контекст, бэклог, реестр, аудиты, журнал изменений, скрипты
├── 01_Дисциплины/    — учебные предметы направления (01–07)
├── 02_Курсы/         — курсы вне программы колледжа
├── Шаблоны/          — шаблоны лекции, практики, курса
├── Вложения/         — изображения
├── Диаграммы/        — схемы draw.io
└── Ежедневник/       — заметки по дням (входящие задачи, разбираются в бэклог)
```

Внутри дисциплины `00_Курс.md` — точка входа, если оглавление уже создано; тематические папки содержат лекции, практические работы и другие материалы предмета. Следуй порядку из оглавления и ссылкам между заметками. Разделы дисциплины 02 называются по содержанию (`01. Алгоритмы и Python`, `02. Django`); учебный год записывается в YAML, а не в имени папки.

## Проверки и выгрузка

```bash
python3 00_Мета/проверка_базы.py                 # вся база: YAML, заголовки, задачи, ссылки, код
python3 00_Мета/проверка_базы.py --subject 02    # только дисциплина 02
python3 00_Мета/проверка_базы.py --subject NumPy # только курс
python3 00_Мета/экспорт_в_notebooklm.py          # сборка _Экспорт/ для NotebookLM (в git не попадает)
```

Проверка — одна команда; «проверено» в журнале означает реально прогнанную команду.

База выгружается в NotebookLM, где по конспектам генерируются тесты и карточки для самопроверки. Поэтому в конспектах нет блоков «Проверь себя» без ответов, а каждое понятие определено в самой заметке (исключение — учебные курсы, где такие блоки идут с ответами под спойлером).

База задумана как один связный ресурс: каждая заметка ссылается на связанные, а ссылки проверяются скриптом.
