# College — учебная база конспектов

Obsidian-vault с конспектами, практиками и курсами по программе колледжа (Python, алгоритмы,
разработка ПО) плюс курсы вне программы — NumPy, Pydantic, Matplotlib.

> [!tip] С чего начать
> 1. [[00_Контекст]] — как устроена база, по каким правилам пишется, порядок работы в сессии.
> 2. [[Передача_работы]] — **состояние работы прямо сейчас**: где остановились,
>    что решено владельцем, что осталось, чек-лист продолжения курсов и технические ловушки.
> 3. [[Бэклог]] — незакрытые задачи, [[Соглашения]] — контракт оформления заметок.

## Структура

| Папка | Что внутри |
|---|---|
| `00_Мета/` | Контекст, соглашения, реестр дисциплин, бэклог, журнал изменений, аудиты, скрипты проверки и выгрузки |
| `01_Дисциплины/` | Учебный материал по дисциплинам; дисциплина 02 «Основы алгоритмизации и программирования» собрана целиком (16 лекций, практики двух блоков, 5 мини-проектов) |
| `02_Курсы/` | Курсы, не привязанные к колледжу: 1. Инженерные практики Python · 2. NumPy · 3. Pydantic · 4. Matplotlib |
| `Шаблоны/` | Templater-шаблоны лекции, практики и курса |
| `Вложения/`, `Диаграммы/` | Изображения и экспорт draw.io |
| `Ежедневник/` | Рабочие заметки |

## Основные команды

```bash
python3 00_Мета/проверка_базы.py                    # вся база: YAML, заголовки, задачи, ссылки, код
python3 00_Мета/проверка_базы.py --subject 02       # только дисциплина 02
python3 00_Мета/проверка_базы.py --subject NumPy    # только один курс
python3 00_Мета/экспорт_в_notebooklm.py             # выгрузка в _Экспорт/ (в git не попадает)
```

Проверка запускается **до** сдачи материала: «проверено» в журнале означает реально прогнанную
команду, а не обещание. Выгрузка в NotebookLM — файл на дисциплину и **отдельный файл на каждый курс**;
правила и ограничения — [[Выгрузка_в_NotebookLM]].

## Продолжение работы

Работа идёт в ветке, состояние фиксируется в [[Передача_работы]]: брать оттуда
«Что осталось», следовать чек-листу, после каждой порции правок — прогон проверки,
обновление мета ([[Реестр_дисциплин]], [[Бэклог]], [[Журнал_изменений]])
и коммит в рабочую ветку.
