# 01. Мини-проект. Конвертер единиц с проверкой ввода

> [!abstract] Задача проекта
> Создать консольный конвертер температур: переводить градусы Цельсия в Фаренгейты и обратно,
> проверять ввод/режим и объяснять, какие значения допустимы. Проект собирает навыки блоков
> 01–05 и представляет собой первую программу с небольшим пользовательским сценарием.

## Что должно получиться

```text
Temperature converter
1 — Celsius to Fahrenheit
2 — Fahrenheit to Celsius
Choose conversion: 1
Enter value: 20
Result: 20 C = 68 F
```

## Требования

1. Программа сообщает доступные преобразования.
2. Режим должен быть ровно `1` или `2`.
3. Температура читается как `double`, чтобы принимать дробные градусы.
4. Формулы:
   - `F = C × 9 / 5 + 32`;
   - `C = (F − 32) × 5 / 9`.
5. Невалидный режим, нечисловой ввод или ошибка потока приводят к сообщению и ненулевому
   коду завершения.
6. Результат снабжён исходной и целевой единицами.
7. Не используется `windows.h`, `system("pause")` или платформенный API.

## Как идти

### Этап 1. Подготовка проекта

Собери папку проекта `unit-converter` на выбор: C++ Console Project в Microsoft Visual Studio
или `converter.cpp` для g++ в Ubuntu. В Visual Studio проверь `/std:c++20`; в WSL команда будет
такая:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic -g converter.cpp -o converter
./converter
```

### Этап 2. Сначала точная формула

Запиши вход, вычисление и выход на бумаге. Проверь единицы измерения и тип каждого операнда.
В формулах используй `9.0 / 5.0`, чтобы не зависеть от целочисленного деления.

### Этап 3. Добавить управление и проверку

Прочитай режим и значение. До расчёта:

- проверь успешность извлечения в поток;
- проверь допустимость режима;
- рассмотри абсолютный ноль как предметное ограничение: `C >= -273.15`; температура
  Фаренгейта не должна быть ниже соответствующего предела.

Если режим — не один из двух, не делай conversion. Если ввод нечисловой, сообщи пользователю,
что именно ожидалось. Для первой версии достаточно одного запроса; повторный ввод добавишь после
изучения циклов и правил обработки потока.

### Этап 4. Создать тестовую таблицу

| Режим | Вход | Ожидаемый результат |
|---|---:|---:|
| C → F | 0 | 32 F |
| C → F | 100 | 212 F |
| F → C | 32 | 0 C |
| F → C | 212 | 100 C |
| Любой | неверный режим `3` | понятный отказ |
| Любой | `abc` вместо числа | сообщение об ошибке ввода |
| C → F | `20abc` после лекции 16 | строгий разбор строки отвергает хвост `abc` |
| Любой | `nan` или `inf` после лекции 07 | отказ, если поток их прочитал; иначе ошибка извлечения |
| C → F | `1e308` после лекции 07 | не выдавать бесконечный результат как корректный перевод |
| C → F | значение ниже -273.15 | отказ по предметному правилу |
| F → C | значение ниже -459.67 | отказ по предметному правилу |

Для `double` сравнивай приближённо; если округляешь отображение, укажи число знаков и не
меняй хранимый результат без необходимости.

## Этап после лекции 07 — вынести формулы и проверить конечность

Когда пройдёшь функции, выдели две функции с говорящими именами:

```cpp
double celsius_to_fahrenheit(double celsius);
double fahrenheit_to_celsius(double fahrenheit);
```

Тогда формулы можно проверить отдельно от ввода/вывода. Подключи `<cmath>` и используй
`std::isfinite` для входа и вычисленного результата: конечное, но чрезмерно большое `double`
может переполниться при умножении. Отклони `NaN`/бесконечность, если вводящий поток или проверка
конечности их обнаружила. В следующем этапе не копируй проверку меню внутрь функций преобразования.

## Этап после лекции 16 — надёжный повторный ввод

Когда изучишь обработку ошибок ввода, можешь читать целую строку и разрешить пользователю
повторить ввод до корректного значения. До этого не добавляй сложный потоковый сброс из
случайного примера.
