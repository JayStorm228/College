# 02. Мини-проект. Консольный анализатор результатов

> [!abstract] Задача проекта
> Принять набор оценок, проверить их диапазон, сохранить в `std::vector`, вычислить краткую
> сводку и сообщить, сколько результатов достигли заданного порога. Проект собирает блоки 05–08:
> ветвления, циклы, функции, строки и последовательности данных.

## Что должно получиться

```text
How many scores (0..500)? 5
Enter 5 scores from 0 to 100:
70 60 0 100 85
Count: 5
Minimum: 0
Maximum: 100
Average: 63
Scores >= 60: 4
```

При количестве `0` программа сообщает `No scores`; среднее/минимум/максимум не вычисляются.

## Требования

- Количество вводимых оценок — целое от 0 до 500.
- Каждая оценка — целая от 0 до 100 включительно.
- Невалидный ввод или оценка останавливают обработку с ясным сообщением.
- Набор хранится в `std::vector<int>`.
- Для среднего, минимума/максимума и подсчёта порога есть отдельные функции.
- Порог считается от 60 включительно.
- Пустой набор не делится на ноль и не получает выдуманный минимум.

## Рекомендуемая структура

```text
results-analyzer/
└── main.cpp
```

На этом этапе достаточно одного файла: сначала алгоритм и тесты, разделение на модули появится
в следующем проекте.

## План реализации

1. Прочитай и проверь `count`.
2. Создай пустой `std::vector<int> scores`.
3. В `for` прочитай ровно `count` значений; каждую проверяй до добавления.
4. Если vector пуст, выведи отдельное сообщение и заверши программу успешно.
5. Напиши функции:
   - `double average_score(const std::vector<int>& scores)`;
   - `int minimum_score(const std::vector<int>& scores)`;
   - `int maximum_score(const std::vector<int>& scores)`;
   - `int count_at_least(const std::vector<int>& scores, int threshold)`.
6. Для функций min/max/average запиши предусловие «vector не пуст»; `main` обеспечивает его.
7. Сначала пройди элементы обычным циклом; после блока 13 можно сравнить реализацию со STL.
8. Проведи тесты ниже, затем попробуй добавить форматирование отчёта с названием группы.

## Каркас функций

```cpp
#include <vector>

double average_score(const std::vector<int>& scores) {
    // Предусловие: scores не пуст.
    long long total{};
    for (const int score : scores) {
        total += score;
    }
    return static_cast<double>(total) / static_cast<double>(scores.size());
}
```

Для минимума и максимума инициализируй кандидата первым элементом, не `0` и не случайным
большим числом. Для подсчёта порога начни с нуля.

## Матрица тестов

| Количество | Оценки | Проверяемое поведение |
|---:|---|---|
| 0 | — | пустой набор, без min/max/average |
| 1 | `75` | все три статистики равны 75; порог сработал |
| 3 | `0 60 100` | границы допустимого диапазона и включительный порог |
| 5 | `70 60 0 100 85` | обычная сводка из примера |
| 1 | `-1` | отказ до сохранения |
| 1 | `101` | отказ выше максимума |
| 1 | `abc` | сообщение о нечисловом вводе |
| 501 | — | отказ по пределу количества |

## Развитие проекта

- Добавь средний балл в отдельную `const double` с понятным именем.
- Выведи число успешных результатов и процент, проверяя пустой набор.
- Добавь текстовое имя группы через `std::getline`; если смешиваешь с `>>`, сначала прочитай
  ввод в ясном порядке и объясни остаточный перевод строки.
- После лекции 13 замени некоторые ручные проходы `std::ranges::count_if`/`std::minmax_element`;
  сравни читаемость и требования алгоритмов.

## Критерии приёмки

- ☐ Валидация происходит до добавления оценки в контейнер.
- ☐ Сводка работает для нуля, одного и нескольких элементов.
- ☐ Функции получают данные параметрами и возвращают значения.
- ☐ Пустой набор корректно обрабатывается в `main`.
- ☐ Пройдена матрица тестов; ошибочные данные не попадают в расчёт.
- ☐ Вывод содержит единицы/смысл полей, а не неясные сокращения.

## Что сдать

Исходный код, вход/вывод для минимум четырёх тестов и короткое пояснение инварианта прохода,
который вычисляет сумму и минимальное/максимальное значения.
