# 31. Практика. Читаем диагностику и локализуем ошибку

> [!abstract] Цель практики
> Отличить ошибки сборки от ошибок исполнения, использовать отладчик как измерительный
> инструмент и документировать воспроизводимый дефект.

## Часть A. Классификация ★☆☆

Для каждого симптома запиши предполагаемый этап и первый вопрос:

1. `fatal error: vector: No such file or directory`.
2. `expected ';' before 'return'`.
3. `undefined reference to ...`.
4. Программа выводит `0`, хотя ожидалось `5`.
5. Программа читает `values[values.size()]`.

> [!example]- Самопроверка
> 1 — заголовок/набор инструментов; 2 — синтаксис при компиляции; 3 — компоновка;
> 4 — логическая ошибка/инициализация/вход; 5 — выход за границу и UB. В каждом случае сначала
> нужно воспроизвести проблему и прочитать контекст, не гадать по одному симптому.

## Часть B. Трассировка с отладчиком ★★☆

Создай программу:

```cpp
#include <iostream>
#include <vector>

int main() {
    const std::vector<int> values{3, 5, 8};
    int total{};
    for (const int value : values) {
        total += value;
    }
    std::cout << total << '\n';
}
```

1. Собери с `-g`.
2. В gdb остановись в `main`.
3. Используй `next`, чтобы пройти цикл по итерациям.
4. Напечатай значения `value` и `total` в подходящих точках.
5. Продолжи до завершения.
6. Повтори с breakpoint на строке сложения.

Запиши, чем `next` отличается от `step`.

## Часть C. Найти логическую ошибку ★★☆

Ниже цикл должен считать сумму чисел от 1 до 4, но `total` выводится неправильно:

```cpp
int total{};
for (int value{1}; value < 4; ++value) {
    total += value;
}
```

Поставь breakpoint у условия/тела, проверь последние значения и исправь границу. Добавь ручной
тест `n=1` и `n=0`, чтобы ошибка не вернулась.

## Часть D. Windows Debugger ★★★

В Visual Studio открой похожий код:

- поставь breakpoint слева от строки `total += value`;
- `F5` запусти, `F10` пройди строку;
- посмотри `Locals`/`Watch`;
- `F11` зайди в функцию, если она есть;
- сравни с gdb: какие понятия одинаковы, а названия интерфейса различны?

## Отчёт о дефекте

Используй шаблон:

```text

Проверка гипотезы:
Исправление:
Регрессионный тест:
```
