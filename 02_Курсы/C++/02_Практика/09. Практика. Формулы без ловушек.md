# 09. Практика. Формулы без ловушек

> [!abstract] Цель практики
> Прежде чем считать, определить тип каждого операнда, поставить осмысленные скобки и защитить
> операцию от недопустимого делителя. Сначала читаем выражения, затем пишем формулу.

## Задача 1 ★☆☆. Предсказать, не запуская

Для `int a{7}; int b{2};` определи результат и тип:

```cpp
const int q1{a / b};
const double q2{a / b};
const double q3{static_cast<double>(a) / b};
const int r{a % b};
```

Запиши, в каком выражении теряется дробная часть и почему присвоение `q2` её не возвращает.

> [!example]- Разбор
> `q1 == 3`, `q2 == 3.0`, `q3 == 3.5`, `r == 1`. Тип результата задаётся операцией над
> операндами до присваивания переменной. Чтобы получить дробное деление, преобразуй операнд
> до `/` или используй исходные значения `double`.

## Задача 2 ★★☆. Безопасное среднее

Даны `int total{17}; int count{4};`. Программа должна вывести `4.25`, а при `count == 0`
сообщить, что среднее не определено.

1. Сначала преобразуй `total` в `double`.
2. Проверь `count != 0` **до** деления.
3. Используй ветвление `if/else`.
4. Запусти для `count = 4`, `1`, `0`.

> [!example]- Разбор
> ```cpp
> #include <iostream>
>
> int main() {
>     const int total{17};
>     const int count{4};
>     if (count != 0) {
>         const double average{static_cast<double>(total) / count};
>         std::cout << "Average: " << average << '\n';
>     } else {
>         std::cout << "Average is undefined for an empty count.\n";
>     }
> }
> ```
> Для входов программа сейчас использует константы; меняй `count`, пересобирай и проверяй.
> При `count==0` выполняется только ветка `else`, поэтому деление не вычисляется.

## Задача 3 ★★☆. Площадь круга

Для радиуса `r` площадь равна `πr²`. Напиши программу с `std::numbers::pi` из `<numbers>`:

- используй `double radius{}`;
- проверь, что радиус неотрицателен;
- вычисли площадь через два умножения;
- не используй `4 / 3`, `pow` или приблизительное значение π вручную.

Тесты: `0`, `1`, `2`, `-1`. Для радиуса 1 площадь примерно `3.14159`.

## Задача 4 ★★★. Проверить формулу

Пусть цена `unit_price` и количество `quantity` заданы отдельно. Напиши цену за `quantity`
единиц, не теряя дробную часть в количестве. Затем добавь скидку `discount_rate` в пределах
от 0 до 1. Сначала проверяй ставку, затем вычисляй `total * (1 - discount_rate)`.

Продумай тесты для ставки 0, 0.25, 1 и значения вне диапазона. Все денежные округления
явно оставь за рамками: сформулируй, какое правило нужно было бы согласовать отдельно.

## Короткий отчёт

- Чем `4.0 / 3.0` отличается от `4 / 3`?
- Какие из тестов проверяют граничные случаи?
