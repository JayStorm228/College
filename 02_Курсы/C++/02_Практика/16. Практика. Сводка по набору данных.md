# 16. Практика. Сводка по набору данных

> [!abstract] Цель практики
> По небольшой коллекции вычислить количество, сумму, минимум, максимум и среднее; корректно
> обработать пустой набор и проверить границы без магических начальных значений.

## Условие

Даны измерения в миллиметрах:

```cpp
const std::vector<double> measurements{12.5, 10.0, 18.5, 14.0};
```

Создай программу, которая выводит:

- число измерений;
- сумму;
- минимальное и максимальное значение;
- среднее;
- сколько измерений не меньше 12.0 мм.

## Лабораторные шаги

1. Подключи `<iostream>` и `<vector>`.
2. Выведи `measurements.size()`.
3. Проверь пустой вектор прежде, чем обращаться к `measurements[0]` или вычислять среднее.
4. Инициализируй `minimum` и `maximum` первым допустимым значением, не числом `999999`.
5. Пройди значения через range-based `for`.
6. Обновляй сумму/минимум/максимум/счётчик порога.
7. Вычисли среднее только для непустого набора; преобразуй размер к `double` явно.
8. Повтори для пустого набора и для одного значения `{7.0}`.

> [!example]- Возможный разбор
> ```cpp
> double total{};
> double minimum{measurements[0]};
> double maximum{measurements[0]};
> int at_least_twelve{};
> for (const double value : measurements) {
>     total += value;
>     if (value < minimum) minimum = value;
>     if (value > maximum) maximum = value;
>     if (value >= 12.0) ++at_least_twelve;
> }
> const double average{total / static_cast<double>(measurements.size())};
> ```
> Для заданных данных: `count=4`, `total=55`, `minimum=10`, `maximum=18.5`, среднее `13.75`,
> порогу соответствуют три значения.

## Самостоятельное усложнение

- Добавь отдельный `std::vector<double>` с пустыми данными и не допускай деления на ноль.
- Преобразуй счётчик значений выше 15.0 в процент от общего числа.
- Объясни, что должна означать доля для пустого набора: `0%`, «не определена» или ошибка? Выбери
  и запиши контракт.
- Придумай тест, где минимум и максимум совпадают.

## Проверка корректности

| Данные | Ожидаемое наблюдение |
|---|---|
| `{}` | нет минимума/максимума/среднего; нет индексации |
| `{7.0}` | min=max=avg=7.0 |
| `{4.0, 4.0, 4.0}` | все измерения равны |
| `{12.5, 10.0, 18.5, 14.0}` | значения совпадают с разбором выше |
