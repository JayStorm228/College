# 15. Практика. Безопасная работа с коллекциями

> [!abstract] Цель практики
> Научиться выбирать между строкой, `vector` и `array`, обходить элементы без ошибки на один
> индекс и осознанно использовать проверяемый `at()`.

## Задача 1 ★☆☆. Размер и индекс

Для `std::vector<int> values{4, 8, 15};` заполни:

- `values.size()` — …;
- допустимые индексы — …;
- `values[2]` — …;
- `values[3]` — … (существует ли?);
- есть ли допустимый индекс у пустого `vector`?

> [!example]- Самопроверка
> Размер равен 3; индексы — 0, 1, 2; `values[2]` равен 15; позиции 3 нет. Для пустого
> vector индекса нет. Разыменовывать/читать позицию за границей нельзя.

## Задача 2 ★★☆. Безопасный обход

Создай vector оценок, выведи каждый элемент двумя способами:

1. range-based `for` с `const int score`;
2. индексный `for` с `std::size_t index` и условием `index < scores.size()`.

Проверь пустую коллекцию. Затем временно измени `<` на `<=`, объясни дополнительную итерацию
и немедленно исправь условие.

## Задача 3 ★★☆. Нужный контейнер

Выбери структуру и объясни выбор:

| Данные | Выбор |
|---|---|
| 12 дней недели по одному измерению в каждом | … |
| Неизвестное число результатов, добавляемых при чтении | … |
| Полное имя человека с пробелом | … |
| Три координаты, фиксированный размер | … |

Ожидаемый выбор: `std::array`, `std::vector`, `std::string`, `std::array` (размерность известна).

## Задача 4 ★★★. Проверить двусмысленную инициализацию

Собери маленькую программу с:

```cpp
std::vector<int> first(5);
std::vector<int> second{5};
std::vector<int> third{2, 4, 6};
```

Напечатай `size()` и элементы каждого контейнера. Убедись, что `first` — пять нулей,
`second` — один элемент `5`, а `third` — три перечисленных значения.

## Задача 5 ★★★. Поиск текста

Создай `std::string text{"C++20 course"}`. Проверь `.empty()`, `.size()` и `.find("20")`.
Выведи, найдено ли вхождение, используя `std::string::npos`; не считай, что размер обязательно
равен количеству видимых Unicode-букв.
