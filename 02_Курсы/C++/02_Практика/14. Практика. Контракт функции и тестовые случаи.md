# 14. Практика. Контракт функции и тестовые случаи

> [!abstract] Цель практики
> Самостоятельно задать поведение функции: что она принимает, что возвращает, при каких
> условиях результат осмыслен и какие тесты показывают границы этого контракта.

## Задача 1 ★☆☆. Високосный год

Напиши `bool is_leap_year(int year)`, которая возвращает, делится ли год на 4, но годы,
делящиеся на 100, не високосные, если они также не делятся на 400.

Подбери тесты для `2000`, `1900`, `2024`, `2023`. Напиши контракт: допускаются ли нулевой
и отрицательные номера лет? Если условие этого не говорит — запиши допущение, не выдавай его
за факт задачи.

> [!example]- Разбор
> ```cpp
> bool is_leap_year(int year) {
>     return year % 400 == 0 || (year % 4 == 0 && year % 100 != 0);
> }
> ```
> Проверка: 2000 — true; 1900 — false; 2024 — true; 2023 — false. Выражение использует
> короткое замыкание; здесь нет опасного деления. Контракт должен отдельно уточнить диапазон `year`.

## Задача 2 ★★☆. Среднее непустого vector

Напиши функцию `mean`, принимающую `const std::vector<double>&`. Что делать при пустом наборе?
Выбери и объясни один вариант интерфейса:

- предусловие «vector не пуст»;
- вернуть `std::optional<double>` (если уже изучал/хочешь прочитать документацию);
- передать результат/ошибку отдельным способом.

Для основного решения курса используй простое предусловие и проверяй пустоту в `main` до вызова.
Проверь `{}`, `{7.0}`, `{1.0, 3.0}`.

## Задача 3 ★★☆. Чистая проверка диапазона

Напиши `bool is_in_range(int value, int minimum, int maximum)`, где обе границы включены.
Контракт требует `minimum <= maximum`. Проверь:

| Вызов | Ожидание |
|---|---|
| `is_in_range(5, 1, 10)` | true |
| `is_in_range(1, 1, 10)` | true |
| `is_in_range(10, 1, 10)` | true |
| `is_in_range(0, 1, 10)` | false |
| `is_in_range(1, 10, 1)` | нарушение предусловия — решение надо оговорить |

## Задача 4 ★★★. Набор тестов для шара

Для площади и объёма шара перечисли:

- обычное положительное значение;
- нулевой радиус;
- отрицательное значение;
- заранее известный результат при `r=1`;
- допустимую погрешность сравнения для `double`.

Добавь комментарий к каждой функции, описывающий предусловие и постусловие.

## Чек-лист

- ☐ Функция имеет узкую ответственность и говорящие имена.
- ☐ Предусловие не скрыто в случайном тесте.
- ☐ Функция возвращает вычисление, не печатает его без нужды.
- ☐ Есть обычный и граничный тест.
- ☐ Значения `double` не сравниваются с точной десятичной константой без допуска.
