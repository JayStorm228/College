# 13. Практика. Выделяем вычисления в функции

> [!abstract] Цель практики
> Переписать вычисления из `main` в функции с понятными параметрами и результатом. Для каждого
> вызова видеть различие между параметром и аргументом, а затем проверить функцию известными числами.

## Задача 1 ★☆☆. Функция удвоения

Создай функцию `double_value`, которая принимает `int` и возвращает удвоенный `int`.
Вызови её для 0, 7 и -4. Запиши тип параметра, аргумент каждого вызова и возвращаемый тип.

> [!example]- Разбор
> ```cpp
> int double_value(int value) {
>     return value * 2;
> }
> ```
> В вызове `double_value(7)` число `7` — аргумент; параметр `value` получает его значение.
> Вызов выражается результатом `14`.

## Задача 2 ★★☆. Геометрические функции

Напиши функции:

```cpp
double rectangle_area(double width, double height);
double circle_area(double radius);
```

Требования:

- функции только вычисляют и возвращают значение — никакого `std::cout` внутри;
- круг использует `std::numbers::pi` из `<numbers>`;
- вызовы и печать расположены в `main`;
- предпосылка: размеры неотрицательные, они задаются константами задачи.

Проверь: `rectangle_area(3, 4) == 12`, `circle_area(1)` близка к π.

### Лабораторные шаги

1. Напиши объявления функций выше `main`.
2. Добавь определения (можно поставить их до `main` или ниже объявлений).
3. В `main` объяви `const double area{...}` для каждого результата.
4. Скомпилируй с `-std=c++20` и нужными заголовками.
5. Измени радиус, вызови функцию повторно и сравни новую строку вывода.

> [!example]- Полный разбор для `circle_area`
> ```cpp
> #include <iostream>
> #include <numbers>
>
> double circle_area(double radius);
>
> int main() {
>     const double area{circle_area(1.0)};
>     std::cout << area << '\n';
>     return 0;
> }
>
> double circle_area(double radius) {
>     return std::numbers::pi * radius * radius;
> }
> ```
> Объявление перед `main` позволяет вызвать функцию до определения; аргумент `1.0` — `double`.

## Задача 3 ★★★. Разделить ответственность

Есть план программы:

1. спросить радиус;
2. вычислить площадь и объём;
3. вывести два результата.

Распредели работу: что относится к `main`, какие вычисления оформить функциями, какие параметры
и типы результата им нужны. Не вызывай ввод/вывод из математических функций.

## Контрольные вопросы

- Почему у функции типа `double` нужен результат типа, совместимого с `double`?
- Чем объявление отличается от определения?
- Почему `4.0 / 3.0` нужно в формуле шара?
