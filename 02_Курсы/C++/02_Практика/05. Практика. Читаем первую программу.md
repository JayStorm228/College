# 05. Практика. Читаем первую программу

> [!abstract] Цель практики
> Не просто запустить приветствие, а объяснить каждую конструкцию, найти зависимость и
> безопасно изменить вывод. Практика начинается с чтения, затем переходит к редактированию.

## Задание 1. Поставь пометки у строк

```cpp
#include <iostream>
#include <string>

int main() {
    std::string course{"C++"};
    std::cout << "Welcome to " << course << "!\n";
    return 0;
}
```

Для каждой строки укажи:

1. Заголовок/функция/объявление переменной/вывод/завершение?
2. Какой тип у `course`?
3. Почему перед `cout` и `string` стоит `std::`?
4. Какой символ появляется в конце вывода?
5. Что перестанет работать, если удалить `#include <string>`?
6. Какая часть программы является точкой входа?

### Пример ответа

- Строка 1 подключает объявления стандартного вывода.
- Строка 2 нужна для `std::string`.
- `course` — переменная-строка со значением `"C++"`.
- `<<` передаёт в поток фрагменты вывода по порядку.

## Задание 2. Отследить вывод без запуска

Заполни таблицу вывода:

| Выражение | Что выводится? |
|---|---|
| `"Welcome to "` | … |
| `course` | … |
| `"!\n"` | … |
| Всё выражение целиком | … |

После этого собери программу командой g++ из курса и сравни ожидание с терминалом.

## Задание 3. Отредактировать без смены смысла

Измени программу так, чтобы она вывела:

```text
I am learning C++.
This is my first program.
```

Для второго варианта собери предложение из нескольких частей через `<<`, а не записывай
весь ответ одной строкой. Сравни оба решения: какое проще менять, когда появится имя?

> [!example]- Самопроверка
> В `main` выполнение начинается сверху. `<iostream>` нужен `std::cout`, `<string>` —
> `std::string`. `std` — пространство имён стандартной библиотеки. `\n` создаёт перевод строки;
> из-за него следующая часть появляется с новой строки. После изменения нужно сохранить именно
> `.cpp`, затем заново собрать и запустить бинарный файл.

## Задание 4. Найди и классифицируй дефекты

Не запускай сломанный код сразу; сначала попробуй объяснить причину:

```cpp
#include <iostream>

int main() {
    std::cout << "Hello\n"
    return 0;
}
```

1. Какого знака не хватает?
2. На каком этапе это обнаружит компилятор?
3. Почему сообщение может указывать на следующую строку, хотя ошибка выше?
4. Исправь, собери и проверь результат.

## Контроль

- ☐ Могу объяснить, почему подключены оба заголовка.
- ☐ Могу показать точку входа и тело функции.
- ☐ Могу объяснить цепочку `<<`.
- ☐ Могу отличить исходный текст от ранее собранной программы.
- ☐ После правки я пересобираю программу, а не запускаю старую версию.
