# 23. Практика. Наблюдаем за объектами безопасно

> [!abstract] Цель практики
> Отличить копию от ссылки и указателя, проследить время жизни объекта и научиться проверять
> `nullptr`, не разыменовывая чужой или уже уничтоженный объект.

## Задача 1 ★☆☆. Копия или тот же объект?

```cpp
int original{5};
int copy{original};
int& alias{original};
copy = 8;
alias = 9;
```

Запиши значения `original`, `copy`, `alias` после каждой строки. Объясни, почему `copy` и `alias`
поводят себя по-разному.

> [!example]- Самопроверка
> Сначала все имена дают 5. После `copy=8` исходный остаётся 5. После `alias=9` меняется
> объект `original`, поэтому `original==9`, `alias==9`, `copy==8`.

## Задача 2 ★★☆. Передать большое значение только для чтения

Напиши:

```cpp
void print_label(const std::string& label);
```

Создай строку с пробелом, вызови функцию и попробуй присвоить `label = "new"` внутри неё.
Объясни диагностику. Сравни с передачей `std::string` по значению: когда копия полезна,
а когда `const&` уменьшает лишнюю работу?

## Задача 3 ★★☆. Nullable-наблюдатель

Напиши функцию, принимающую `const int* value`:

- если `value == nullptr`, выведи `No value`;
- иначе прочитай `*value`;
- в `main` вызови её с адресом живой переменной и с `nullptr`.

Перед разыменованием всегда проверяй допустимость указателя.

> [!example]- Возможный разбор
> ```cpp
> void print_optional(const int* value) {
>     if (value == nullptr) {
>         std::cout << "No value\n";
>     } else {
>         std::cout << *value << '\n';
>     }
> }
> ```
> `nullptr` разрешён как значение указателя, но не как объект для чтения.

## Задача 4 ★★★. Найти риск времени жизни

Для каждого фрагмента отметь безопасен ли он и почему:

```cpp
int* saved{};
{
    int local{12};
    saved = &local;
}
// saved теперь хранит адрес, но local больше не существует.
```

```cpp
std::string make_message() {
    std::string text{"done"};
    return text;
}
```

Первый фрагмент опасен при чтении `*saved`; второй безопасно возвращает значение.
Не дописывай разыменование висячего указателя «чтобы посмотреть, что выйдет».

## Задание 5 ★★★. Контракт параметра

Выбери для каждой функции тип параметра и обоснуй:

- `print(const std::string&)` — читать строку без изменения;
- `append(std::string&)` — менять строку вызывающего кода;
- `area(double)` — передать маленькое числовое значение;
- `find_first(const std::vector<int>&)` — просмотреть большой набор без копирования.

## Критерии

- ☐ Отличаю копию от ссылки.
- ☐ Знаю, что reference должен быть привязан к живому объекту.
- ☐ `nullptr` проверяется до разыменования.
- ☐ Не храню адрес локальной переменной после выхода из блока.
- ☐ Возвращаю новый объект по значению, если вызывающая сторона должна им владеть.
