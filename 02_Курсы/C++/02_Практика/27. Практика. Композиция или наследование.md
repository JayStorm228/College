# 27. Практика. Композиция или наследование

> [!abstract] Цель практики
> Выбрать между «является» и «содержит», проверить substitutability (подстановку) и не
> превращать переиспользование пары полей в искусственную иерархию.

## Задача 1 ★☆☆. Поставить отношение

Для каждой пары выбери «наследование», «композиция» или «ни то ни другое» и объясни:

| Типы | Предварительная оценка |
|---|---|
| `Circle` и `Shape` | … |
| `Car` и `Engine` | … |
| `Invoice` и `Customer` | … |
| `Square` и `Rectangle` | … — обсуди ограничения setter-ов |
| `FileReport` и `Report` | … |

Не считай таблицу готовым ответом: аргументируй контракт. Например, замену `Rectangle` на
`Square` может сломать API, который независимо меняет ширину и высоту.

## Задача 2 ★★☆. Смоделировать композицию

Создай простые типы:

```cpp
struct Engine {
    int horsepower{};
};

struct Car {
    std::string model{};
    Engine engine{};
};
```

Подключи `<string>`, создай объект и выведи модель и мощность. Объясни, почему `Car` содержит
двигатель, но не наследуется от `Engine`.

## Задача 3 ★★☆. Проверить общий контракт

Для фигур нужно вычислять площадь. Сформулируй общий базовый интерфейс `Shape` с публичным
виртуальным `area() const`. Какие обещания должна дать любая фигура? Какие сведения не должны
входить в базовый класс, если ими пользуется только `Circle`?

## Задача 4 ★★★. Код-ревью иерархии

Разработчик создал `class Bird : public Vehicle` только потому, что у обоих есть поле `name`.
Напиши review-комментарий:

- какой смысл выражает public inheritance;
- корректна ли подстановка птицы вместо транспортного средства;
- какая альтернатива уберёт дублирование без ложного отношения;
- какие требования нужно спросить у автора.

> [!example]- Ожидаемый ход рассуждения
> Одинаковое поле `name` не доказывает, что Bird является Vehicle. Лучше общий небольшой
> компонент/тип значения или отдельная функция, если предметная связь этого требует. Сначала
> уточнить предметную область и контракт, не проектировать по совпадению названий.

## Задача 5 ★★★. Выбрать структуру без угадывания

Программа обрабатывает разные форматы отчёта (`TextReport`, `HtmlReport`) и вызывает одинаковую
операцию `render()`. Сравни два дизайна: общий runtime-интерфейс с virtual и `switch` по enum.
Для каждого назови ситуацию, где он уместен, и один недостаток.
