# 04. Практика. Собери и проверь программу в терминале

> [!abstract] Цель практики
> Самостоятельно пройти путь от папки до проверенного запуска, не копируя лабораторную
> команду механически. После каждой попытки объяснить, какая стадия выполнялась и что означает
> результат.

## Условие

Создай папку `~/cpp-course/hello-lab`. Напиши `welcome.cpp`, которая печатает две строки:

```text
C++20 is ready.
The program was built with g++.
```

Не копируй эту строку вывода в файл: программа должна вывести её при запуске.

## Уровень 1 ★☆☆ — основная сборка

1. Создай папку через Bash и перейди в неё.
2. Создай файл `.cpp` и прочитай его через `cat`.
3. Собери программу командами с флагами курса и именем результата `welcome`.
4. Запусти `./welcome`.
5. Запиши точную команду и ожидаемый вывод.

## Уровень 2 ★★☆ — объектный файл

1. Собери `welcome.cpp` с `-c` в `welcome.o`.
2. Убедись через `ls`, что объектный файл создан.
3. Скомпонуй `welcome.o` в `welcome_from_object`.
4. Запусти результат и сравни с предыдущим.
5. Объясни, почему поменялось имя исполняемого файла, но не исходник.

## Уровень 3 ★★★ — диагностика

В копии файла создай два дефекта по одному:

- пропусти закрывающую кавычку в строке;
- вызови `std::cout`, не подключив `<iostream>`.

Для каждого дефекта:

1. Сохрани точный текст ошибки и номер строки.
2. Классифицируй этап: поиск заголовка, компиляция или компоновка.
3. Исправь только один дефект.
4. Снова собери и запусти программу.
5. Не подавляй предупреждения и не меняй системные настройки.

## Стартовый каркас

```cpp
#include <iostream>

int main() {
    // Выведи первую строку.
    // Выведи вторую строку.
    return 0;
}
```

## Критерии готовности

- ☐ Терминал находится в рабочей папке проекта (`pwd`).
- ☐ Исходник существует, сохранён и просмотрен.
- ☐ Команда компиляции включает `-std=c++20 -Wall -Wextra -Wpedantic -g`.
- ☐ Имя выходного файла задано через `-o`.
- ☐ Запуск выполнен отдельно от сборки через `./welcome`.
- ☐ Для `.o` отдельно выполнена компоновка.
- ☐ У ошибок записан этап и первопричина.

> [!example]- Самопроверка идеи
> Здесь нужны две команды: g++ сначала превращает `welcome.cpp` в исполняемый файл, затем
> Bash запускает этот файл. При `-c` компоновки нет; отдельная команда связывает `.o`.
> Пропущенный заголовок обычно обнаруживается до/во время компиляции, а пропущенное определение
> функции или отсутствие нужного объектного файла — на стадии компоновки.
