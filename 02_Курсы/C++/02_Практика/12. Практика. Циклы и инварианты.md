# 12. Практика. Циклы и инварианты

> [!abstract] Цель практики
> Самостоятельно спроектировать цикл, который завершается и вычисляет нужный результат.
> Задания идут от простой последовательности к работе с накопителем и вложенными повторами.

## Задача 1 ★☆☆. Обратный отсчёт

Прочитай положительное целое число `start` и выведи отсчёт до 1. В этой первой версии считаем,
что введённые данные корректны; проверку невалидного потока добавим в блок об ошибках.

Пример: `start = 4` → `4 3 2 1`.

- Выбери `while` или `for` и объясни выбор.
- Напиши условие остановки.
- Проверь `start = 1`.

## Задача 2 ★★☆. Сумма последовательности

Прочитай `n >= 0` и посчитай сумму целых чисел от 1 до `n` включительно; для `n = 0` сумма
равна 0.

1. Инициализируй `total` осмысленным нулём.
2. Определи инвариант: что содержит `total` перед обработкой очередного числа?
3. Проверь `n = 0`, `1`, `5`.
4. Обсуди, почему при огромном `n` выбранный целый тип может быть недостаточен.

> [!example]- Разбор
> ```cpp
> int n{5};
> int total{};
> for (int value{1}; value <= n; ++value) {
>     total += value;
> }
> std::cout << total << '\n';
> ```
> Инвариант перед итерацией со значением `value`: `total` — сумма `1..value-1`. После добавления
> `value` и увеличения счётчика свойство сохраняется. Для `n=0` первая проверка `1 <= 0` ложна,
> поэтому остаётся пустая сумма `0`.

## Задача 3 ★★☆. Среднее до маркера

Пользователь вводит целые числа, а `0` означает конец; ноль не входит в данные. Подсчитай
количество и сумму введённых ненулевых значений. Если чисел не было, напечатай «No data»,
иначе — сумму и среднее.

- Используй `while`.
- Обновляй счётчик и сумму только для настоящих данных.
- Защити деление на ноль.
- Тесты: `4 6 0`, `0`, `-2 2 0`.

Для простоты считаем, что все введённые токены — целые; отказ потока появится в блоке 16.

## Задача 4 ★★★. Нарисовать рамку

Прочитай `width` и `height` (оба не меньше 1) и выведи прямоугольник из `*`. Используй два
вложенных `for`. Например, `width=4`, `height=2`:

```text
****
****
```

Проверь минимальный размер `1 x 1`. Затем измени алгоритм, чтобы печатались пустые рамки,
и объясни, какие условия теперь проверяются внутри цикла.

## Критерии готовности

- ☐ В каждом цикле очевидно, что меняется.
- ☐ Понятно, почему условие в конце станет ложным.
- ☐ Ноль/минимальный вход не пропущен.
- ☐ Деление выполняется только для положительного количества элементов.
- ☐ Для накопителя выбрана достаточная ширина по ограничениям задачи.
