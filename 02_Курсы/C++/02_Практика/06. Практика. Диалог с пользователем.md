# 06. Практика. Диалог с пользователем

> [!abstract] Цель практики
> Написать первую интерактивную программу, которая читает строку полностью, включая пробелы,
> и использует её в ответе. Отдельно проследить, где заканчивается ввод и начинается вывод.

## Задание

Создай `dialog.cpp`. Программа должна:

1. Попросить пользователя написать название его любимой книги/игры/города.
2. Прочитать всю строку, в том числе пробелы, через `std::getline`.
3. Напечатать: `You chose: <введённая строка>`.
4. Добавить пустую строку перед ответом, чтобы было видно, где закончился ввод.

Пример работы:

```text
Your choice: The Lord of the Rings

You chose: The Lord of the Rings
```

## Лабораторные шаги

1. Подключи `<iostream>` и `<string>` — ровно те заголовки, чьи сущности используешь.
2. Внутри `main` объяви `std::string choice{}`.
3. Напечатай приглашение без перевода строки, чтобы курсор остался в той же строке.
4. Вызови 
```
   std::getline(std::cin, choice)
```
5. Выведи пустую строку и собери ответ цепочкой `std::cout << ...`.
6. Добавь `return 0;`, сохрани файл, собери g++ и проверь ввод с пробелами.

## Стартовый каркас

```cpp
#include <iostream>
#include <string>

int main() {
    std::string choice{};
    // TODO: prompt, read full line, print response
    return 0;
}
```

> [!example]- Возможный разбор
> ```cpp
> #include <iostream>
> #include <string>
>
> int main() {
>     std::string choice{};
>     std::cout << "Your choice: ";
>     std::getline(std::cin, choice);
>     std::cout << '\n' << "You chose: " << choice << '\n';
>     return 0;
> }
> ```
> Проверка: введи `The Lord of the Rings`. Если выводится только `The`, вместо `getline`
> ты, вероятно, использовал форматированное чтение `std::cin >> choice`.

## Самостоятельный вызов

Измени программу, не добавляя новых библиотек:

- попроси два раза ввести отдельные строки `first` и `second`;
- выведи их в том же порядке, но на отдельных строках;
- после этого измени вывод так, чтобы они были в одной строке через ` | `.

Не читай пробелы через `cin >>`; каждая из двух строк должна сохранять введённый текст целиком.

## Проверка

- ☐ В коде есть `<string>` и `<iostream>`.
- ☐ Объект строки инициализирован.
- ☐ Пробелы во входе сохраняются.
- ☐ После изменения программа пересобрана.
- ☐ Для пустого ввода программа не аварийно завершилась (пустая строка — допустимое значение в этой задаче).
