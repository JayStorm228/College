# 11. Практика. Прослеживаем цикл по шагам

> [!abstract] Цель практики
> До запуска предсказывать, сколько раз сработает тело цикла, какие значения будут у счётчика
> и накопителя, и когда программа остановится. Затем сверить ручную трассировку с компилятором.

## Задача 1 ★☆☆. Таблица состояний

```cpp
int value{2};
int total{};
while (value <= 6) {
    total += value;
    value += 2;
}
```

Заполни таблицу:

| Перед проверкой | Условие | `total` после тела | `value` после тела |
|---:|---|---:|---:|
| … | … | … | … |

Укажи значение `total` после завершения и последнюю проверку, которая была ложной.

> [!example]- Разбор
> Проходы дают пары `(value,total)`: после первой итерации `(4,2)`, второй `(6,6)`, третьей
> `(8,12)`. Последняя проверка — `8 <= 6`, она ложная. Итого три итерации и `total == 12`.

## Задача 2 ★★☆. Найди ошибку на один шаг

Требуется вывести целые числа от 0 до `limit - 1`, ровно `limit` чисел.

```cpp
for (int index{}; index <= limit; ++index) {
    std::cout << index << '\n';
}
```

1. Для `limit = 0`, `1`, `3` запиши точный вывод.
2. Найди, почему цикл выводит лишнее значение.
3. Исправь условие и повтори таблицу.
4. Проверь, что при `limit = 0` тело выполняется ноль раз.

## Задача 3 ★★☆. `continue` и `break`

```cpp
for (int value{1}; value <= 8; ++value) {
    if (value == 3) {
        continue;
    }
    if (value == 6) {
        break;
    }
    std::cout << value << ' ';
}
```

Проследи 1–8: какие числа будут напечатаны, когда срабатывает `continue`, когда — `break`,
какое следующее значение счётчика уже не будет проверено?

## Задача 4 ★★★. Вложенный цикл

Для `row` от 1 до 3 и `column` от 1 до 2 посчитай количество выполнений внутреннего тела.
Нарисуй таблицу всех пар. Затем поменяй циклы местами и объясни, почему набор пар тот же,
а порядок обхода меняется.

## Лабораторные шаги

1. Сделай ручную трассировку в таблице.
2. Создай минимальный `.cpp` с `iostream`.
3. Собери с `-Wall -Wextra -Wpedantic` и запусти.
4. Сравни фактический вывод с прогнозом.
5. Если не совпало — отметь первую строку, где состояние стало отличаться.

## Что запомнить

Перед запуском любого цикла можно ответить на четыре вопроса: начальное значение? условие?
изменение? значение после последней успешной итерации? Если на один ответ нет, цикл ещё не
объяснён.
