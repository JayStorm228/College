# 01. Практика. Первое знакомство с Visual Studio

> [!abstract] Цель практики
> Подготовить Microsoft Visual Studio на Windows и создать именно консольный C++-проект.
> В этой лабораторной **не используем Visual Studio Code** и не объявляем кнопку Build
> объяснением сборки: сначала мы отдельно соберём программу через g++ в Ubuntu/WSL.

## Перед началом

Потребуется Windows 10/11 и доступ к установке приложений. Проверь текущий маршрут на
[официальной странице Microsoft](https://learn.microsoft.com/en-us/cpp/build/vscpp-step-0-installation?view=msvc-170): названия компонентов и установщик могут меняться.

> [!warning] Не устанавливай случайные пакеты по видео
> В этом курсе нужен полный Microsoft Visual Studio с рабочей нагрузкой для C++, а не VS Code
> с расширением. Не устанавливай «ускорители сборки», неизвестные SDK и дополнительные
> компиляторы без понятной причины.

## Лабораторная часть

### Шаг 1. Проверить установленную среду

1. Открой меню Пуск и найди **Visual Studio Installer**.
2. Если Visual Studio ещё нет, скачай актуальный Community Installer с
   [официальной страницы загрузки](https://visualstudio.microsoft.com/downloads/). Прочитай
   действующие условия использования Community.
3. Если IDE уже установлена, нажми **Modify** у своей версии.
4. Проверь галочку **Desktop development with C++** (разработка классических приложений на C++).
5. В списке компонентов убедись, что включены MSVC C++ build tools и Windows SDK. Не нужно
   ставить весь список опциональных компонентов.
6. Установи или измени установку; дождись завершения и перезапусти IDE, если она просит.

### Шаг 2. Создать консольный C++-проект

1. Запусти Visual Studio → **Create a new project**.
2. Найди шаблон **Console App**, язык C++, платформа Windows. Не выбирай шаблон C#, Windows
   Forms, Empty Project или VS Code workspace.
3. Задай имя `CppPractice01`; запомни расположение папки.
4. Открой **Solution Explorer** и найди `.cpp`. Посмотри, в какой Solution/Project он находится.
5. Если Visual Studio сгенерировала пример кода, прочитай его, но не удаляй и не перестраивай
   файлы наугад.

### Шаг 3. Проверить стандарт и предупреждения

1. Выбери **Project → Properties**.
2. Проверь нужные Configuration/Platform в верхних списках окна (например, `All Configurations`
   и `x64`, если эти варианты есть).
3. Открой **C/C++ → Language → C++ Language Standard** и выбери стандарт ISO C++20
   (`/std:c++20`).
4. Открой **C/C++ → General → Warning Level** и проверь, что диагностика не выключена.
5. Нажми Apply/OK. В будущем при создании новой конфигурации повторно проверь, что её свойства
   тоже настроены.

Пока не нужно сравнивать результат Build с g++ — это будет после темы сборки. Цель этой
практики: среда установлена и проект готов к работе.

## Контрольный список

- ☐ Приложение называется **Visual Studio**, а не Visual Studio Code.
- ☐ Рабочая нагрузка `Desktop development with C++` установлена.
- ☐ В Solution Explorer виден консольный C++-проект и хотя бы один `.cpp`.
- ☐ Проект предназначен для Windows Console, а не другого вида приложения.
- ☐ Для проверенной конфигурации выбран C++20.
- ☐ Предупреждения компилятора не отключены.
- ☐ Я могу показать, где находятся имя Solution, имя Project и файл `.cpp`.

## Если что-то пошло не так

| Симптом | Что проверить |
|---|---|
| Шаблона C++ Console App нет | Рабочая нагрузка C++, применена ли установка; перезапусти Visual Studio. |
| Установка предлагает только VS Code | Вернись на официальный сайт Visual Studio, не ставь расширение вместо IDE. |
| Не нахожу C++20 в Properties | Проверь версию MSVC/свойств проекта и официальный список поддержки `/std`; обнови инструменты. |
| Свойство поменялось только для Debug | Выбери `All Configurations` или отдельно проверь Debug/Release. |
| После смены свойства не уверен, что выбрано | Открой окно снова и проверь конкретную Configuration/Platform. |

## Что показать преподавателю/проверяющему

Название проекта, окно Solution Explorer, страницу стандарта C++20 и перечень установленной
рабочей нагрузки. Пароль, ключи Windows и личные файлы в отчёт не включай.
