# 25. Практика. Подбираем алгоритм STL

> [!abstract] Цель практики
> Выполнить поиск, подсчёт, сумму и сортировку стандартными средствами; для каждого алгоритма
> указать нужный диапазон, результат «не найдено» и изменение исходной последовательности.

## Задача 1 ★☆☆. Найти элемент

Дан вектор:

```cpp
const std::vector<int> values{5, 8, 12, 8};
```

Используй `std::ranges::find`, чтобы найти первое `8`. Сначала проверь результат на равенство
`values.end()`, затем только разыменуй. Повтори поиск для `99`.

> [!example]- Разбор
> ```cpp
> const auto found{std::ranges::find(values, 8)};
> if (found != values.end()) {
>     std::cout << "Found: " << *found << '\n';
> } else {
>     std::cout << "Not found\n";
> }
> ```
> `end()` — граница после последнего элемента; её нельзя разыменовывать.

## Задача 2 ★★☆. Посчитать по предикату

Для оценок `{45, 60, 72, 90, 59}` найди число оценок не ниже 60 через `std::ranges::count_if`.
В лямбде `[](int score) { ... }` возвращай результат сравнения.

1. Запиши ожидаемое число вручную.
2. Запусти алгоритм.
3. Измени порог на 70 и проверь снова.
4. Подпиши лямбду словами: что она проверяет?

## Задача 3 ★★☆. Суммировать и посчитать среднее

Примени `std::accumulate` из `<numeric>` к `std::vector<double>`. Начальное значение должно быть
`0.0`, а не `0`, чтобы тип аккумулятора соответствовал вещественному результату.
Проверь пустой контейнер до деления на размер.

## Задача 4 ★★★. Отсортировать без потери исходных данных

Дан вектор рейтингов. Сохрани оригинал, создай копию и отсортируй копию по возрастанию через
`std::ranges::sort`. Проверь повторы и уже отсортированный список.

Ответь:

- Изменился ли исходный вектор?
- Что произойдёт, если вместо vector передать `std::list`?
- Почему `std::ranges::sort` не проверяет смысл диапазона/дубликаты?

## Полный образец

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
    const std::vector<int> scores{45, 60, 72, 90, 59};
    const auto passing{std::ranges::count_if(
        scores, [](int score) { return score >= 60; }
    )};
    const auto found{std::ranges::find(scores, 72)};
    const auto total{std::accumulate(scores.begin(), scores.end(), 0LL)};

    std::vector<int> sorted{scores};
    std::ranges::sort(sorted);

    std::cout << "Passing: " << passing << '\n';
    std::cout << "Total: " << total << '\n';
    if (found != scores.end()) {
        std::cout << "Found: " << *found << '\n';
    }
    std::cout << "Sorted: ";
    for (const int score : sorted) {
        std::cout << score << ' ';
    }
    std::cout << '\n';
}
```

## Что сдать

Код, ожидаемый и фактический вывод, таблицу алгоритмов: входная структура, операция, оценка
сложности, изменяет ли исходные данные, как сообщает отсутствие результата.
