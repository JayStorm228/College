# 10. Практика. Условия и проверка границ

> [!abstract] Цель практики
> Перевести словесное правило в булево выражение и проверить каждую границу. Для каждой задачи
> сначала опиши условие словами, потом реализуй ветви, затем выполни тестовую матрицу.

## Задача 1 ★☆☆. Включительный диапазон

Значение `score` допустимо от 1 до 100 включительно.

1. Запиши булево выражение `is_valid`.
2. Выведи его через `std::boolalpha`.
3. Проверь `0`, `1`, `50`, `100`, `101`.
4. Объясни, почему `1 <= score <= 100` не является правильной записью в C++.

> [!example]- Разбор
> `const bool is_valid{score >= 1 && score <= 100};`. Применяются два сравнения, соединённые
> `&&`. Границы 1 и 100 включены; 0 и 101 исключены. C++ вычислил бы `(1 <= score)` сначала,
> получил `bool`, а затем сравнил его с 100.

## Задача 2 ★★☆. Оценка по шкале

Напиши `if / else if / else`, которая по баллу от 0 до 100 выдаёт категорию:

| Балл | Категория |
|---:|---|
| 90–100 | excellent |
| 70–89 | good |
| 50–69 | pass |
| 0–49 | retry |
| Вне 0–100 | invalid |

Порядок условий важен. Прежде чем программировать, проверь, что каждый допустимый балл
принадлежит ровно одной категории.

> [!example]- Возможный разбор
> ```cpp
> if (score < 0 || score > 100) {
>     std::cout << "invalid\n";
> } else if (score >= 90) {
>     std::cout << "excellent\n";
> } else if (score >= 70) {
>     std::cout << "good\n";
> } else if (score >= 50) {
>     std::cout << "pass\n";
> } else {
>     std::cout << "retry\n";
> }
> ```
> Сначала исключаем недопустимый диапазон; в оставшихся ветках верхние границы уже следуют
> из предыдущих проверок. Каждую ветвь проверь на пороге и соседнем значении.

## Задача 3 ★★☆. Меню `switch`

Пользователь выбирает: `1` — добавить запись, `2` — показать отчёт, `0` — выйти.
Используй `switch`, добавь `default` и не забудь `break`. Проверь ввод `0`, `1`, `2`, `3`.

Затем намеренно убери один `break`. По выводу докажи, что произошло fall-through, и верни
корректную версию.

## Задача 4 ★★★. Проверки безопасности выражения

До вычисления скидки программа должна убедиться, что:

- сумма неотрицательна;
- число участников больше нуля;
- либо выбрана категория `student`, либо есть приглашение.

Назови условия отдельно, не собирай всю логику в одну нечитаемую строку. Покажи, где короткое
замыкание не даст выполнить деление при `participants == 0`.

| Балл 0–100 | 50 | 0 | 101 | -1, 100, 99 |
| Оценка категории «excellent» | 95 | 90 | 101 | 89, 90, 100 |

## Критерии

- ☐ Каждая ветвь имеет фигурные скобки.
- ☐ `=` не использован вместо `==`.
- ☐ Диапазон записан двумя сравнениями и `&&`.
- ☐ Защищённые операции выполняются только после проверки предпосылки.
- ☐ Проверены нижняя/верхняя границы и соседние значения.
