# 07. Функции — декомпозиция, параметры и результат

> [!abstract] О чём лекция
> Функция получает входные данные, выполняет одну понятную работу и может вернуть результат.
> Разберём параметры, аргументы, тип результата, `void`, объявления, определения и простые
> контракты. Отдельный пример посчитает площадь и объём шара.
>
> **Зачем это нужно.** Длинный `main` трудно проверить и переиспользовать. Функции дают задаче
> названные шаги, которые можно тестировать отдельно и вызывать из нескольких мест.
>
> **После лекции ты сможешь:** объявить и определить функцию, передать ей аргументы, вернуть
> значение, отделить вычисление от ввода/вывода, определить предусловие и вызвать `<cmath>`/
> `<numbers>` в корректном C++20-примере.

## Зачем нужна функция

Рассмотрим два смысла: «прочитать радиус», «вычислить объём сферы», «показать ответ». Это разные
действия. Вычисление можно выразить как отдельную функцию, чтобы применять его независимо от
способа ввода.

Функция — именованный блок кода. Вызов функции временно передаёт ей управление; после `return`
выполнение продолжается после вызова.

## Минимальная функция с параметром и результатом

```cpp
double rectangle_area(double width, double height) {
    return width * height;
}
```

Объявление в этой строке одновременно содержит **заголовок** и **определение** функции:

- `double` перед именем — тип возвращаемого результата;
- `rectangle_area` — имя;
- `(double width, double height)` — параметры, входные значения функции;
- тело между `{}` выполняет действие;
- `return` передаёт вызывающему коду результат и завершает функцию.

Вызов:

```cpp
const double area{rectangle_area(4.0, 2.5)};
```

`4.0` и `2.5` здесь — **аргументы**, фактические значения, передаваемые параметрам `width`
и `height`. Типы и число аргументов должны подходить параметрам.

## Функция `void`

Если функция выполняет действие и не возвращает вычисляемого значения, объявляют результат `void`:

```cpp
#include <iostream>

void print_welcome() {
    std::cout << "Welcome to the program\n";
}
```

В C++-функции с результатом `void` не требуется писать `return;` в конце, если она просто
доходит до закрывающей скобки. Можно написать `return;` для раннего завершения.

Для вычислений обычно удобнее вернуть значение, чем печатать ответ внутри функции: вызывающая
сторона сможет вывести его, проверить или передать другому вычислению.

## Объявление отдельно от определения

Если функция вызывается до её определения, компилятор должен заранее увидеть объявление:

```cpp
#include <iostream>

int double_value(int value);  // объявление: имя, параметры и тип результата

int main() {
    std::cout << double_value(21) << '\n';
    return 0;
}

int double_value(int value) {  // определение: тело функции
    return value * 2;
}
```

Объявление заканчивается `;`. Определение содержит тело. В небольшом уроке они могут быть
в одном `.cpp`; в блоке [[09. Заголовки и несколько файлов — объявления и сборка]] мы разместим
объявление в заголовке, определение — в исходном файле.

## Контракт функции

Функция полезнее, когда её обещание понятно. Простой **контракт** можно записать так:

- **предусловие**: что должно быть верно для входных данных;
- **постусловие**: какой результат функция гарантирует, если предусловие выполнено.

Например, вычисление площади прямоугольника предполагает неотрицательные ширину и высоту;
результат равен их произведению. Если наша функция обязана обрабатывать отрицательные значения,
в ней нужна явная политика ошибки, например `std::optional`/исключение в зависимости от задачи
(это будет отдельным продвинутым решением). Пока не прячь проверку за неясным числом.

## Математические функции и константы

Заголовок `<cmath>` содержит стандартные математические функции в пространстве имён `std`.
Для тригонометрии углы задаются в **радианах**, если документация конкретной функции не говорит
иначе.

| Функция | Назначение |
|---|---|
| `std::pow(x, n)` | Возвести `x` в степень `n`. |
| `std::sqrt(x)` | Квадратный корень из неотрицательного значения. |
| `std::abs(x)`, `std::fabs(x)` | Модуль целого или вещественного значения (выбирай подходящую перегрузку). |
| `std::sin(x)`, `std::cos(x)`, `std::tan(x)` | Тригонометрические функции угла `x` в радианах. |
| `std::atan2(y, x)` | Угол, соответствующий координатам `(x, y)`. |
| `std::log(x)`, `std::exp(x)` | Натуральный логарифм и экспонента. |

Константы C++20 объявлены в `<numbers>`: `std::numbers::pi` (π) и `std::numbers::e` (основание
натурального логарифма). Подключай заголовок явно, если используешь эти имена.

## Сфера: математическая библиотека и C++20

Для сферы с радиусом `r`:

- площадь поверхности `A = 4πr²`;
- объём `V = (4/3)πr³`.

Код с явными зависимостями:

```cpp
#include <cmath>
#include <numbers>

constexpr double sphere_surface_area(double radius) {
    return 4.0 * std::numbers::pi * radius * radius;
}

double sphere_volume(double radius) {
    return (4.0 / 3.0) * std::numbers::pi * std::pow(radius, 3);
}
```

- `<numbers>` — стандартный заголовок C++20 для констант, включая `std::numbers::pi`.
- `<cmath>` нужен для `std::pow`.
- `4.0 / 3.0` — вещественное деление. Запись `4 / 3` выполнила бы целочисленное деление и
  дала `1`, что испортило бы формулу.
- `std::pow(radius, 3)` доступен, но для степени 3 запись `radius * radius * radius` часто
  яснее и не требует `<cmath>`. Оба варианта можно встретить.
- `constexpr` здесь допустим: тело состоит из операций, пригодных для вычисления во время
  компиляции. Если функция получает обычный `double` при запуске, то и ответ вычислится тогда.

Предусловие — `radius >= 0`. Функции выше сами его не проверяют. Для учебного примера вызывающая
сторона гарантирует это; в настоящем интерфейсе сформулируй, как сообщить об отрицательном радиусе.

## Полная программа: ввод отдельно, формула отдельно

```cpp
#include <iostream>
#include <numbers>

constexpr double sphere_volume(double radius) {
    return (4.0 / 3.0) * std::numbers::pi * radius * radius * radius;
}

int main() {
    double radius{};
    std::cout << "Radius (non-negative): ";
    if (!(std::cin >> radius) || radius < 0.0) {
        std::cerr << "Please enter a non-negative number.\n";
        return 1;
    }

    const double volume{sphere_volume(radius)};
    std::cout << "Volume: " << volume << '\n';
    return 0;
}
```

`std::cerr` — поток стандартных диагностических сообщений; код завершения `1` обозначает
ошибочный путь для вызывающей среды. Эта проверка достаточна для примера, но не является полной
валидацией всех представимых/непредставимых вещественных значений. Ограничения введём постепенно.

## Параметры, локальные переменные и область видимости

Параметр `radius` существует внутри вызова функции. Локальная переменная `volume` существует
внутри `main`. Имя, объявленное внутри фигурных скобок, недоступно снаружи этих скобок.
Это **область видимости**.

Обычный параметр передаётся по значению: функция получает собственное значение параметра.
Присвоение `radius = 0;` внутри функции не заменит переменную аргумента вызывающей стороны.
Передача больших объектов и изменение данных по ссылке будут разобраны после темы времени жизни.

Не заводи глобальные изменяемые переменные, чтобы функция «сама нашла» данные. Передай нужные
значения параметрами: зависимости видны и проще тестируются.

## Возвращаемое значение и все пути

Если функция объявлена возвращающей `double`, любой путь нормального завершения должен вернуть
`double`. Например, `if` без `else` может оставить один путь без результата — компилятор
предупредит или выдаст диагностику. Не подставляй `return 0;` только чтобы замолчать сообщение:
проверь, какое значение по смыслу следует вернуть.

`return` завершает функцию немедленно. Код после безусловного `return` недостижим и обычно
означает ошибку в расположении проверки.

## Чистая функция — удобная функция для проверки

Функция, которая зависит только от аргументов, возвращает результат и не меняет внешний мир,
часто называется **чистой**. Например, `rectangle_area(width, height)` проще проверять, чем
функцию, которая внутри читает клавиатуру, печатает подсказку, меняет глобальные данные и
вычисляет площадь.

Чистота — не обязательная формальная категория языка, а полезный инженерный ориентир:
чем меньше скрытых зависимостей, тем проще понять и тестировать расчёт.

## Для тех, кто уже знает Python: `return`

> [!example]- Python-аналогия — можно пропустить
> **Предварительно:** объявление `def`, параметры и `return` из Python дисциплины 02.
> В обоих языках функция получает значения и может вернуть результат. В C++ типы параметров
> и результата указаны в объявлении, а вызывающий код проверяет совместимость на этапе
> компиляции. Аналогия не требуется для понимания функций в C++.

## Как это делают в проекте

Когда `main` становится длинным, ищи части, у которых есть отдельное имя в условии задачи:
`read_radius`, `sphere_volume`, `print_report`. Не дроби программу на функцию для каждой строки;
выбирай смысловую ответственность. Функция с одним понятным результатом проще протестировать,
переиспользовать и заменить, не затрагивая весь проект.

## Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «Параметр и аргумент — одно слово для одного понятия» | Параметр указан в определении; аргумент — значение в месте вызова. |
| «Функция обязательно должна печатать результат» | Обычно функция вычисляет и возвращает его; вывод остаётся на уровне интерфейса программы. |
| «Тип результата можно угадать по телу» | Тип возвращаемого значения входит в явный интерфейс функции. |
| «`4 / 3` в формуле объёма достаточно, потому что итог `double`» | Целочисленное деление даст `1`; используй `4.0 / 3.0`. |
| «Если отрицательный радиус не встречается в моём тесте, он невозможен» | Предусловие надо сформулировать и обеспечить входной проверкой или контрактом. |
| «`constexpr` означает, что функция всегда выполняется до запуска» | Она может вычисляться во время компиляции, когда аргументы подходят; иначе вызов возможен во время выполнения. |

## Ключевые термины

| Термин | Объяснение |
|---|---|
| Функция | Именованный блок кода, который можно вызвать. |
| Параметр | Имя и тип входа, объявленные в интерфейсе функции. |
| Аргумент | Фактическое значение, переданное при вызове. |
| Возвращаемый тип | Тип результата, указанного перед именем функции. |
| Объявление | Информация о функции без тела, достаточная для проверки вызова. |
| Определение | Полное описание функции, включая тело. |
| Область видимости | Часть программы, в которой имя доступно по правилам языка. |
| Предусловие | Требование к входу, необходимое для корректной работы. |
| Постусловие | Обещание о результате при выполненном предусловии. |
| Чистая функция | Функция без наблюдаемых побочных эффектов, результат которой зависит от аргументов. |
