# 03. Первая программа — main, ввод и вывод

> [!abstract] О чём лекция
> Учимся читать самый короткий настоящий C++-исходник. Разберём, где программа начинается,
> как подключается ввод/вывод, зачем у каждой команды есть точка с запятой и как передать
> компьютеру строку пользователя.
>
> **Зачем это нужно.** Без базового словаря `#include`, `main`, выражение и оператор кажутся
> случайными символами. Когда знаешь роли частей, ты можешь объяснить программу по строкам,
> а не запоминать «магическую формулу».
>
> **После лекции ты сможешь:** отличить исходный файл от программы, объяснить `main`, вывести
> текст, прочитать строку целиком, назвать назначение `std::` и собрать корректное приветствие.

## Программа — инструкция, а не рассказ

**Исходный код** — текст, в котором программист записал правила на языке C++. Компьютер
не угадывает смысл по намерению: он применяет формальные правила языка, переводит код в программу
и выполняет инструкции в установленном порядке.

Для первого примера достаточно четырёх понятий:

- **Литерал** — значение, записанное прямо в коде: например, `"Hello"` или `42`.
- **Выражение** вычисляет значение или выполняет действие.
- **Оператор (statement)** — законченная инструкция, часто оканчивающаяся `;`.
- **Функция** — именованная часть программы; выполнение обычного консольного приложения
  начинается в специальной функции `main`.

## Разбираем минимальную программу

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, world!\n";
    return 0;
}
```

Строка за строкой:

1. `#include <iostream>` просит препроцессор подключить объявления стандартного ввода/вывода.
   Мы подключили именно то, что используем.
2. `int main()` объявляет функцию `main`, возвращающую целое число `int`. Это стандартная
   точка входа обычного hosted-приложения.
3. `{` и `}` ограничивают тело функции. Отступы помогают человеку видеть структуру, но
   сами по себе не превращают строки в блоки, как в Python.
4. `std::cout` — стандартный поток вывода; `<<` передаёт ему значение.
5. `"Hello, world!\n"` — строковый литерал. `\n` внутри строки обозначает перевод строки.
6. `;` завершает выражение вывода.
7. `return 0;` сообщает вызывающей среде об успешном завершении `main`. В конце `main`
   можно опустить `return 0`, но пока пишем явно, чтобы увидеть роль возвращаемого значения.

Скомпилируй файл `hello.cpp` через команду из лекции [[02. Консоль и g++ — путь от исходника до запуска]],
затем запусти `./hello`. Ожидаемый вывод — одна строка `Hello, world!`.

## `std::cout` и последовательный вывод

`std::cout` — объект стандартной библиотеки, связанный с обычным выводом программы.
Несколько `<<` в одном выражении выводят значения слева направо:

```cpp
#include <iostream>

int main() {
    int count{3};
    std::cout << "Items: " << count << '\n';
    return 0;
}
```

`'\n'` — символ перевода строки; `"\n"` — строка из одного символа перевода строки.
Обе формы часто встречаются. Здесь значение `count` пока знакомо как число — объявлять переменную
подробно будем в лекции [[04. Данные и типы — значения, инициализация и преобразования]].

Не требуется писать отдельный `std::cout` для каждого фрагмента. Цепочка делает вывод
компактным, но не меняет смысл.

> [!note] `std::endl` и `\n`
> Оба варианта переводят строку, но `std::endl` дополнительно сбрасывает буфер вывода.
> Обычно пиши `\n` или `std::cout << '\n'`; `std::endl` нужен, когда важно немедленно
> передать накопленный текст наружу. В цикле частая принудительная очистка буфера может замедлить вывод.

## `std::cin`: прочитать слово и строку

Для ввода из стандартного потока используется `std::cin`. Оператор `>>` читает значение
в следующую переменную. Например, `std::cin >> name;` для строки остановится у пробела.
Если пользователь вводит `Pavel Arkhipov`, в `name` попадёт только `Pavel`.

Чтобы прочитать всю строку, включая пробелы, используем `std::getline`:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    std::cout << "Your name: ";
    std::getline(std::cin, name);
    std::cout << "Hello, " << name << "!\n";
    return 0;
}
```

Новые понятия:

- `#include <string>` подключает тип `std::string`.
- `std::string name;` создаёт переменную для текста.
- `std::getline(std::cin, name)` читает до нажатия Enter; пробел внутри строки сохраняется.
- `std::cin` и `std::cout` — разные потоки: первый приносит введённые данные, второй
  отправляет текст наружу.

### Если нужно смешать `>>` и `std::getline`

После `std::cin >> age` перевод строки, набранный после числа, остаётся во входном потоке.
Следующий `std::getline` может прочитать именно этот остаток и вернуть пустую строку. Если
извлечение числа прошло успешно, можно отбросить остаток текущей строки:

```cpp
#include <iostream>
#include <limits>
#include <string>

int main() {
    int age{};
    std::string full_name;

    if (!(std::cin >> age)) {
        return 1;  // подробную обработку сбоя потока изучим позже
    }

    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
    std::getline(std::cin, full_name);
    std::cout << age << ": " << full_name << '\n';
    return 0;
}
```

`std::cin.ignore` пропускает символы до заданного разделителя; `std::numeric_limits` и
`std::streamsize` задают достаточно большую границу, чтобы отбросить оставшуюся часть строки.
Для этого заголовок `<limits>` подключён явно. Важно: сначала надо убедиться, что `>>` успешно
прочитал `age`; если поток уже перешёл в состояние ошибки, порядок восстановления другой — он
разобран в лекции [[16. Ошибки, файлы и отладка — инженерный рабочий цикл]].

В старых примерах можно увидеть `std::cin.ignore(); std::cin.get();`: первый вызов убирает один
оставшийся символ, а второй ждёт ещё один ввод, чтобы окно консоли не закрылось. Это не нужно
обычной программе, запущенной из терминала или IDE, и ожидание Enter не является обработкой
данных. Для новых диалогов предпочитай ясный ввод и явную обработку состояния потока.

## Кириллица в консоли Windows: кодовые страницы

Кодировка файла с исходным текстом и кодовая страница консоли — связанные, но разные настройки.
В старом или специально настроенном Windows Console кириллический ввод/вывод может потребовать
явного выбора UTF-8. Функции `SetConsoleOutputCP` и `SetConsoleCP` относятся к Windows API из
`<windows.h>`, а не к стандарту C++; современный терминал может уже работать с UTF-8. Для
переносимой логики программы эти вызовы не нужны.

```cpp
#include <iostream>

#if defined(_WIN32)
#include <windows.h>
#endif

int main() {
#if defined(_WIN32)
    SetConsoleOutputCP(CP_UTF8);  // кодовая страница вывода консоли Windows
    SetConsoleCP(CP_UTF8);        // кодовая страница ввода консоли Windows
#endif

    std::cout << "Привет, мир!\n";
    return 0;
}
```

На Windows условие `_WIN32` позволяет подключить платформенный заголовок; на Linux этот блок
исключается препроцессором, и пример остаётся обычной программой C++. Если русский текст всё
ещё отображается неверно, проверь отдельно кодировку сохранённого `.cpp`, настройки компилятора
и терминал. При MSVC для UTF-8-исходника можно задать параметр `/utf-8`: он относится к кодировке
исходного и исполняемого текста программы, а не к кодовой странице консоли. Не добавляй
`windows.h` в общий код, если задача не требует именно Windows API.

## Почему пишем `std::`

`std` — пространство имён стандартной библиотеки. Запись `std::cout` означает «имя `cout`
из области имён `std`». Это предотвращает конфликты имён и показывает читателю, откуда пришло
обозначение.

В учебном курсе мы пишем `std::` явно. Строка `using namespace std;` в маленьком файле
кажется короче, но в большом проекте может незаметно столкнуть одинаковые имена. Особенно
плохо помещать `using namespace std;` в заголовок: он влияет на каждый файл, который подключит
этот заголовок.

## Ошибка — это данные для отладки

Если программа не компилируется, сравни сообщение с этапами из прошлой лекции. Например:

- `iostream: No such file` может означать проблему набора инструментов или окружения;
- `cout was not declared` может означать пропущенный заголовок или отсутствие `std::`;
- `expected ';'` указывает на синтаксическую ошибку рядом с названной строкой.

Сначала прочитай **первую** диагностику, проверь номер строки и контекст. Не добавляй заголовки
«на всякий случай»: выясни, какой символ должен быть объявлен и откуда он берётся.

## Как это делают в проекте

Функция `main` обычно отвечает за порядок верхнего уровня: получить вход, вызвать функции
бизнес-логики, показать результат и вернуть код завершения. Вычисления мы постепенно вынесем
из `main` в отдельные функции, а при росте программы — в собственные файлы.

Хорошая маленькая программа уже соблюдает несколько привычек:

1. Подключает конкретные заголовки (`<iostream>`, `<string>`), не скрывая зависимости.
2. Даёт переменной понятное имя (`name`, а не `x`).
3. Сохраняет читаемые отступы и фигурные скобки.
4. Не смешивает получение входных данных с тем, как данные вычисляются.

## Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «`main` — просто имя, которое можно заменить» | Для обычной программы это специальная точка входа, которую ожидает среда выполнения. |
| «`std::cout` — команда языка» | Это объект стандартной библиотеки; `#include <iostream>` делает нужные объявления доступными. |
| «`<<` в C++ означает только сдвиг битов» | В выражении с потоком он перегружен для передачи значения в поток; с целыми числами он может означать побитовый сдвиг. |
| «`cin >> name` прочитает полное имя» | Форматированный ввод строки останавливается у пробельного символа; для целой строки есть `getline`. |
| «Отступы заменяют `{}`» | В C++ блок задают фигурные скобки; отступы помогают людям. |
| «Если код напечатал слово, программа верна» | Вывод доказывает только, что этот запуск выполнил этот путь; остальные входы надо проверять. |

## Ключевые термины

| Термин | Объяснение |
|---|---|
| Исходный код | Текст программы, написанный на C++. |
| Литерал | Значение, прямо записанное в исходном коде. |
| Оператор | Законченная инструкция языка, часто завершающаяся `;`. |
| Функция `main` | Точка входа обычного консольного приложения. |
| Стандартная библиотека | Набор типов и функций, определённых стандартом C++. |
| Поток ввода `std::cin` | Источник данных, обычно связанных с клавиатурой. |
| Поток вывода `std::cout` | Направление обычного вывода программы. |
| `std::string` | Стандартный тип для хранения последовательности символов. |
| Пространство имён | Область, которая группирует имена и помогает избежать конфликтов. |
| `std::getline` | Функция, читающая строку до разделителя, обычно до Enter. |
