# 04. Данные и типы — значения, инициализация и преобразования

> [!abstract] О чём лекция
> Компьютер хранит значения в памяти; тип говорит программе, как интерпретировать значение
> и какие операции над ним допустимы. Разберём переменные, целые и дробные числа, логические
> значения, символы, строки, инициализацию и явные преобразования.
>
> **Зачем это нужно.** Неверный тип может испортить расчёт ещё до того, как появятся условия
> или циклы. Выбранный тип — часть смысла задачи, а не украшение объявления.
>
> **После лекции ты сможешь:** выбрать тип для простого значения, сразу инициализировать
> переменную, отличить целое от приближённого дробного числа, прочитать ввод без молчаливого
> преобразования и объяснить, почему `int{2.5}` запрещено.

## Значение, объект, переменная

**Значение** — данные, например число `25` или текст `"hello"`. **Объект** — область памяти,
в которой во время работы программы хранится значение некоторого типа. **Переменная** — имя,
через которое мы обращаемся к объекту.

Можно представить ячейку с подписью: имя — подпись, значение — содержимое, тип — договор о том,
какое содержимое допустимо и как его понимать. Это модель, а не буквальное обещание, что любой
объект занимает одну непрерывную ячейку или конкретное число байтов.

## Сначала тип, имя и инициализация

```cpp
#include <iostream>
#include <string>

int main() {
    int student_count{24};
    double distance_km{3.5};
    bool is_open{true};
    char grade{'A'};
    std::string course_name{"C++"};

    std::cout << course_name << ": " << student_count << " students\n";
    std::cout << "Distance: " << distance_km << " km\n";
    std::cout << std::boolalpha << "Open: " << is_open << '\n';
    std::cout << "Grade: " << grade << '\n';
    return 0;
}
```

`int student_count{24};` означает: создай объект типа `int`, назови его `student_count`
и сразу присвой ему значение `24`. `{}` — форма инициализации, которую будем использовать
по умолчанию: она не допускает некоторые опасные сужающие преобразования.

| Тип | Что обычно моделирует | Пример |
|---|---|---|
| `bool` | Истина/ложь | `bool is_ready{false};` |
| `char` | Кодовую единицу/символ базового набора | `char answer{'y'};` |
| `int` | Целое число обычного диапазона | `int attempts{3};` |
| `long long` | Более широкий стандартный целый тип | `long long population{8000000000LL};` |
| `float` | Приближённое вещественное значение одинарной точности | `float ratio{0.5f};` |
| `double` | Приближённое вещественное значение, обычно удобное для расчётов | `double temperature{21.5};` |
| `std::string` | Последовательность символов текста | `std::string title{"Report"};` |
| `void` | Отсутствие возвращаемого значения функции; не тип обычной переменной | `void print_report();` |

Суффикс `LL` в целочисленном литерале (`8000000000LL`) задаёт тип `long long`; суффикс `f`
у дробного литерала (`0.5f`) задаёт `float`. Дробный литерал без `f`, например `0.5`, имеет
tип `double`.

Точные размеры и диапазоны некоторых встроенных типов зависят от реализации и платформы.
Не обещай, что `int` всегда ровно 4 байта. Если нужен диапазон, проверяй `std::numeric_limits`
или выбирай тип с явно требуемой семантикой. Точные размеры `float` и `double` тоже задаются
реализацией; на обычных платформах `double` имеет больший диапазон/точность.

### Статическая типизация и имена

C++ — статически типизированный язык: тип переменной указывается при объявлении, а компилятор
проверяет допустимость операций до запуска. Например, `int count{3};` задаёт `count` целым
значением; строку нельзя случайно использовать в арифметическом выражении с `count`.
Это не гарантирует правильность алгоритма — только соблюдение части правил типов.

Имена объектов — **идентификаторы**. В начальных примерах используй латинские буквы, цифры
и подчёркивание; имя не должно начинаться с цифры и совпадать с ключевым словом вроде `int`
или `return`. Регистр важен: `score` и `Score` — разные имена. Не начинай собственные имена
с `_`: такие формы зарезервированы стандарту/реализации в ряде контекстов. Выбирай смысловое
имя (`student_count`, а не `x`).

## Почему переменные инициализируют сразу

> [!note] Контекст коротких примеров
> Два следующих блока — фрагменты тела `main`, а не отдельные файлы. Для сборки оберни строки
> в `int main() { ... }` и подключи `<iostream>`; для блока с `std::string` добавь также
> `<string>`. Первый блок намеренно читает неинициализированный `score`: не запускай его, а
> объясни, почему так писать нельзя.

Так нельзя делать в новом коде:

```cpp
int score;
std::cout << score << '\n';
```

Встроенный локальный `int` без инициализации не получает автоматически полезный ноль.
Использовать неопределённое/индетерминированное значение как обычное число — ошибка, а во многих
случаях это приводит к неопределённому поведению. Не называй это просто «мусором»: важный вывод
в том, что результат не является надёжным значением, на которое можно опираться.

Дай переменной начальное значение сразу:

```cpp
int score{};                 // ноль
int maximum_score{100};      // явно выбранный предел
std::string student_name{};  // пустая строка
```

Инициализация `{}` особенно удобна, когда нулевое значение — правильное начало. Если у типа
нужен другой осмысленный старт, укажи его явно.

## Целые числа и дробная часть

Целочисленные типы хранят целые значения. Они подходят для количества попыток, числа элементов
и счётчика. Не используй целое для величины, где важна дробная часть.

```cpp
#include <iostream>

int main() {
    int whole_part{7 / 2};
    double measured_part{7.0 / 2};
    std::cout << whole_part << '\n';      // 3
    std::cout << measured_part << '\n';  // 3.5
    return 0;
}
```

Если оба операнда целые, `7 / 2` выполняет целочисленное деление и отбрасывает дробную часть
к нулю. Если хотя бы один операнд — `double`, результат дробный. Ошибка часто возникает,
когда сначала делят два `int`, а потом присваивают результат в `double`: отброшенные данные
уже не вернуть.

### Диапазон — часть выбора типа

Стандартная библиотека помогает проверить пределы:

```cpp
#include <iostream>
#include <limits>

int main() {
    std::cout << std::numeric_limits<int>::lowest() << '\n';
    std::cout << std::numeric_limits<int>::max() << '\n';
    return 0;
}
```

Нельзя «на всякий случай» выбрать самый большой тип и забыть о переполнении. Нужно понять,
какие значения разрешены условием. Для денежных сумм в учебных задачах часто используют целое
число минимальных единиц (например, копеек), чтобы не накапливать ошибки двоичного `double`.
Денежные расчёты с налогами и округлением требуют отдельно описать правило округления.

## `double` — приближение, а не точная дробь

Большинство десятичных дробей нельзя точно представить конечным количеством двоичных разрядов.
Поэтому `0.1 + 0.2` может отличаться от математического `0.3` на крошечную величину.

```cpp
#include <iomanip>
#include <iostream>

int main() {
    double sum{0.1 + 0.2};
    std::cout << std::setprecision(17) << sum << '\n';
    return 0;
}
```

Вывод на обычной двоичной реализации показывает близкое значение, например `0.30000000000000004`.
Последние цифры могут зависеть от реализации и формата вывода.

Для физических расчётов `double` обычно удобен. Для равенства вычисленных дробей сравнивают
разницу с выбранной допустимой погрешностью, а не пишут без причины `result == 0.3`.

## Булевы значения, символы и строки

- `bool` хранит `true` или `false`; используй его, если смысл значения — условие.
- `char` хранит одну кодовую единицу. В UTF-8 одна видимая буква может состоять из нескольких
  байтов, поэтому `char` — не универсальный тип для целого Unicode-символа.
- `std::string` хранит строку. Для русских букв способ подсчёта `size()` может считать байты,
  а не пользовательские «буквы»; полноценная Unicode-обработка — отдельная тема.
- Символьный литерал записывается в одинарных кавычках (`'A'`), строковый — в двойных (`"A"`).

Используй простые ASCII-имена для переменных и исходного кода (`student_count`), а пользовательский
текст показывай отдельно. Это упрощает переносимость и поиск ошибок в начальном курсе.

## Константы и `const`

Если после создания значение не должно меняться, обозначь это:

```cpp
const int days_in_week{7};
```

`const` — ограничение в программе, а не физическая защита от всех способов изменить память.
Оно помогает компилятору и читателю проверить намерение.

`constexpr` используют для значения, которое возможно вычислить во время компиляции:

```cpp
constexpr double gravity{9.81};
```

Не превращай каждое число в отдельную константу автоматически. Константа помогает, если имя
объясняет смысл или одно значение используется в нескольких местах.

## Явное преобразование

Сужающее преобразование теряет часть информации или диапазона. Инициализация фигурными скобками
не даёт случайно превратить `2.5` в `2`:

```cpp
int whole{static_cast<int>(2.5)};  // намеренно отбрасывает дробную часть
```

`static_cast<int>` сообщает читателю и компилятору, что преобразование намеренное. Оно не
проверяет, что выбранный диапазон подходит условию; если это важно, проверку нужно написать
отдельно.

> [!warning] Преобразование — не проверка данных
> Ввод пользователя нужно сначала прочитать и проверить. Приведение типа само по себе не
> подтверждает, что значение допустимо для задачи.

## Для тех, кто уже знает Python: тип — не просто подсказка

> [!example]- Python-аналогия — можно пропустить
> **Предварительно:** переменные и простые типы из дисциплины 02, курс Python.
> Python связывает тип с объектом во время работы, а C++ объявляет тип переменной в исходнике.
> Поэтому `int count{3};` заранее ограничивает операции, которые компилятор разрешит для
> `count`. Основной путь курса раскрывает это понятие без Python.

## Как это делают в проекте

Перед объявлением переменной спроси себя: **что эта величина означает, каков допустимый
диапазон и нужна ли дробная часть?** Например, «количество книг» — не `double`, а «время в
секундах» обычно требует дробного представления. Затем сразу инициализируй значение и назови
его по смыслу.

## Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «`int` везде занимает один и тот же размер» | Стандарт задаёт отношения и минимумы, но не обещает один точный размер на каждой платформе. |
| «Неинициализированная переменная содержит случайное число, которое можно использовать» | Её значение не является надёжным исходным данным; инициализируй объект перед чтением. |
| «Если присвоить `7 / 2` в `double`, получится 3.5» | Целочисленное деление уже отбросило дробную часть; преобразование результата её не восстановит. |
| «`double` хранит любую десятичную дробь точно» | Большинство десятичных дробей представляется приближённо. |
| «`char` всегда означает одну букву на любом языке» | В UTF-8 один пользовательский символ может занимать несколько байтов. |
| «`static_cast` проверяет корректность значения» | Он задаёт преобразование; предметную проверку диапазона он не выполняет. |

## Ключевые термины

| Термин | Объяснение |
|---|---|
| Тип данных | Правила, которые задают допустимые значения и операции над ними. |
| Объект | Область хранения значения во время исполнения программы. |
| Инициализация | Присвоение начального значения при создании объекта. |
| Сужающее преобразование | Преобразование, способное потерять дробную часть или диапазон значений. |
| `const` | Квалификатор, запрещающий менять объект через данное имя после инициализации. |
| `constexpr` | Указание, что выражение может быть вычислено при компиляции, если это возможно. |
| Целочисленное деление | Деление целых операндов с отбрасыванием дробной части к нулю. |
| Двоичная плавающая точка | Приближённое представление дробных чисел в памяти. |
| Unicode | Стандарт кодирования текста; один видимый символ не обязан помещаться в один `char`. |
| `std::numeric_limits<T>` | Средство стандартной библиотеки узнать числовые пределы типа `T`. |
