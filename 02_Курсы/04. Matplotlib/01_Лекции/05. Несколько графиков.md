# 05. Несколько графиков

> [!abstract] О чём лекция
> Если линий стало больше пяти или у величин разный масштаб, один график перестаёт
> работать. Тогда строят **несколько областей** на одной фигуре: `plt.subplots(2, 2)`
> или две оси Y у одной области (`twinx`).
>
> Здесь — как обращаться к областям, как сделать общий заголовок и почему «двойная ось»
> требует осторожности.

# Сетка областей

```python
import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt

fig, axes = plt.subplots(2, 2, figsize=(8, 6), sharey=True)
weeks = ["1", "2", "3", "4"]

axes[0][0].plot(weeks, [3.5, 4.0, 4.5, 4.8], marker="o")
axes[0][0].set_title("Python")
axes[0][1].bar(weeks, [4.2, 4.0, 4.4, 4.6], color="tab:orange")
axes[0][1].set_title("Математика")
axes[1][0].scatter(weeks, [3.0, 3.5, 4.0, 4.2], color="tab:green")
axes[1][0].set_title("Физика")
axes[1][1].plot(weeks, [4.0, 4.1, 4.2, 4.5], marker="s", color="tab:red")
axes[1][1].set_title("Информатика")

for row in axes:
    for ax in row:
        ax.grid(True, linestyle=":", alpha=0.5)

fig.suptitle("Успеваемость по предметам")
fig.tight_layout()
fig.savefig("grid.png", dpi=100)
```

```text
тип: ndarray | форма: (2, 2)
```

| Что | Значение |
|---|---|
| `plt.subplots(2, 2)` | фигура и сетка 2×2; `axes` — массив NumPy формы (2, 2) |
| `axes[0][1]` | верхний ряд, вторая область |
| `plt.subplots(1, 3)` | форма `(3,)` — обращение `axes[0]`, `axes[1]`, `axes[2]` |
| `sharey=True` | общая ось Y: графики сравнимы, метки не дублируются |
| `fig.suptitle(...)` | общий заголовок всей фигуры |

Обход всех областей циклом — стандартный приём:

```python
for ax in axes.flat:
    ax.grid(True, linestyle=":", alpha=0.5)
    ax.set_xlabel("Неделя")
```

`axes.flat` разворачивает двумерный массив в последовательность, и один и тот же настрой
применяется ко всем графикам. Размер сетки при этом не важен.

# Пустая область

Если графиков меньше, чем ячеек, лишнюю убирают:

```python
fig3, axes3 = plt.subplots(2, 2)
axes3[0][0].plot([1, 2], [2, 3])
axes3[1][1].hist([1, 2, 2, 3], bins=3)
fig3.delaxes(axes3[0][1])
fig3.tight_layout()
```

```text
delaxes убирает пустую область
```

> [!note] Когда сетка хуже отдельных файлов
> Три-четыре тесно связанных графика — сетка. Шесть независимых картинок для отчёта —
> лучше отдельные файлы ([[07. Сохранение и качество]]): в тексте их можно поставить рядом,
> а одинаковые подписи не будут повторяться.

# Две оси Y: `twinx`

Величины разного масштаба (посещения — сотни, балл — от 3 до 5) можно совместить на одной
области с двумя осями:

```python
fig2, ax = plt.subplots(figsize=(7, 4))
ax.plot(weeks, [120, 150, 140, 180], marker="o", color="tab:blue")
ax.set_ylabel("посещения", color="tab:blue")
ax.tick_params(axis="y", labelcolor="tab:blue")

twin = ax.twinx()
twin.plot(weeks, [3.5, 4.0, 4.5, 4.8], marker="s", color="tab:red")
twin.set_ylabel("средний балл", color="tab:red")
twin.tick_params(axis="y", labelcolor="tab:red")
ax.set_title("Посещения и балл на одной картинке")
fig2.tight_layout()
fig2.savefig("twin.png", dpi=100)
```

| Приём | Зачем |
|---|---|
| `ax.twinx()` | вторая ось Y, привязанная к той же области X |
| цвет у подписей и меток | читатель понимает, какая ось к какой линии относится |
| `ax.twiny()` | то же для второй оси X (реже нужно) |

> [!warning] Двойные оси легко обманывают
> Двигая пределы второй оси, можно сделать так, что две несвязанные линии «встретятся»
> или «разойдутся». Правило: двойная ось уместна, когда у величин общий смысл по оси X
> (например, время) и она явно подписана цветом. Если сомневаетесь — делайте два графика
> друг под другом с общей осью X (`sharex=True`).

# Как это делают в проекте

1. **Один вопрос — одна область.** Разные вопросы не смешивают в одной сетке.
2. **`sharey=True`/`sharex=True`** там, где величины сравнимы: это честнее и компактнее.
3. **Общий заголовок через `suptitle`**, а не пять одинаковых заголовков.
4. **Настройки циклом по `axes.flat`** — одинаковые сетки и подписи во всех областях.
5. **Двойную ось — только осознанно** и с цветными подписями; иначе читатель запутается.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «`axes[0]` — всегда первая область» | Для сетки 2×2 это целая строка; нужен `axes[0][0]` |
| «twinx рисует второй график рядом» | Он добавляет вторую ось **в ту же** область |
| «Одинаковые заголовки в областях — нормально» | Одинаковые подписи дублируются; хватит общего заголовка и подписей осей |
| «`tight_layout` нужен только при сохранении» | Он нужен всегда, когда есть сетка: иначе подписи наезжают |
| «Чем больше панелей, тем лучше» | 6+ панелей в одной фигуре читаются хуже, чем 6 отдельных файлов |

# Проверь себя

1. Как обратиться к области в сетке 2×3?
2. Что делает `sharey=True`?
3. Как применить сетку ко всем областям сразу?
4. Когда `twinx` уместен, а когда опасен?
5. Что делать, если графиков меньше, чем ячеек сетки?

> [!success]- Ответы
> 1. `axes[строка][столбец]`, например `axes[1][2]` — нижний ряд, третий столбец.
> 2. Даёт областям общую ось Y: графики сравнимы, а метки не дублируются.
> 3. Циклом: `for ax in axes.flat: ax.grid(...)`.
> 4. Уместен при общем смысле по X и подписях цветом; опасен, когда масштабом осей можно подогнать вывод.
> 5. Убрать лишнюю область `fig.delaxes(ax)`, а не оставлять пустую рамку.
