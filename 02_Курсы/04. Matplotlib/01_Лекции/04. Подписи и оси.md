# 04. Подписи и оси

> [!abstract] О чём лекция
> Неподписанный график бесполезен: непонятно, что по осям, в каких единицах и что здесь важное. Подписи делают график самодостаточным — его можно понять без пояснительного текста.
>
> Здесь — заголовок, подписи осей, метки, пределы, поворот длинных подписей, аннотации со стрелками и вспомогательные линии. После лекции график можно отдать человеку, который не знает задачи, и он поймёт, что изображено.

# Заголовок и подписи осей

```python
import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt

months = ["сен", "окт", "ноя", "дек"]
visits = [120, 150, 140, 180]

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(months, visits, marker="o", color="tab:blue")
ax.set_title("Посещения занятий")
ax.set_xlabel("Месяц")
ax.set_ylabel("Человек")
fig.tight_layout()
fig.savefig("visits.png", dpi=100)
```

| Метод | Что делает | Где единицы |
|---|---|---|
| `ax.set_title("…")` | заголовок графика — «о чём» | без единиц |
| `ax.set_xlabel`, `ax.set_ylabel` | подписи осей — «что и в чём» | **сюда** пишут «Человек», «Температура, °C», «Балл» |
| `fig.suptitle("…")` | общий заголовок, когда графиков несколько | см. [[05. Несколько графиков]] |
| `ax.set_title("…", fontsize=13)` | размер шрифта заголовка | когда заголовок важнее подписей |

Правило: **единицы — в подписи оси, а не в заголовке.** «Посещения занятий» (заголовок) + «Человек» (ось Y) читается быстрее, чем «Посещения в человеках» в заголовке. Заголовок отвечает на вопрос «о чём график», ось — «в каких величинах».

Для нескольких графиков общий заголовок ставят на фигуру: `fig.suptitle("Успеваемость по предметам")`, а у каждой области — свой `ax.set_title("Python")`.

# Метки и пределы осей

Метки — то, что написано вдоль оси; пределы — откуда и докуда она тянется:

```python
ax.set_xticks(months)                 # задать метки X явно
ax.set_xticklabels(months, rotation=0)
ax.set_yticks([0, 50, 100, 150, 200]) # «круглые» значения Y
ax.set_ylim(0, 220)                    # оставить место над линией (220 > 180)
ax.set_xlim(-0.5, 3.5)                 # чуть шире, чтобы точки не липли к рамке
```

| Метод | Зачем | Пример |
|---|---|---|
| `set_xticks([...])` | задать метки явно | только месяцы, без лишних чисел |
| `set_yticks([...])` | «круглые» значения | 0, 50, 100, 150, 200 вместо 147.5 |
| `set_ylim(0, 220)` | пределы оси Y | 220 > 180, чтобы линия не упиралась в рамку |
| `set_xlim(...)` | то же для оси X | `-0.5, 3.5` для категорий |
| `tick_params` | поворот, размер меток | `rotation=45` для длинных подписей |

Если меток много и они длинные, их поворачивают — иначе они наезжают друг на друга:

```python
months = ["сентябрь", "октябрь", "ноябрь", "декабрь", "январь", "февраль"]
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(months, [120, 150, 140, 180, 160, 170], marker="o", color="tab:blue")
ax.set_title("Посещения по месяцам")
ax.tick_params(axis="x", rotation=45)
fig.tight_layout()
fig.savefig("rotation.png", dpi=100)
print("поворот подписей:", {label.get_rotation() for label in ax.get_xticklabels()})
```

```text
поворот подписей: {45.0}
```

Поворот на 45° плюс `tight_layout()` — самый надёжный способ не дать подписям наехать друг на друга. Альтернатива — `ax.set_xticklabels(months, rotation=45, ha="right")` с выравниванием по правому краю.

Числа на осях должны быть круглыми: `0, 50, 100, 150, 200` читаются, `147.5` на оси — нет. Оставь точное значение для аннотации.

# Аннотации: показать важное место

Аннотация — способ сказать читателю «смотри сюда» без пояснений в тексте:

```python
ax.annotate(
    "каникулы",
    xy=("ноя", 140),                    # куда указывает стрелка (точка данных)
    xytext=("окт", 190),                # где стоит текст
    arrowprops={"arrowstyle": "->", "color": "tab:red"},
    color="tab:red",
    fontsize=10,
    ha="center",
)
```

| Параметр | Смысл | Совет |
|---|---|---|
| `xy` | куда указывает стрелка (точка данных) | `("ноя", 140)` — ноябрь, 140 человек |
| `xytext` | где стоит текст | выбирай пустое место, не закрывая данные |
| `arrowprops` | вид стрелки и цвет | `"->"` — простая, `"-|>"` — с наконечником |
| `color` | цвет текста | в цвет стрелки, чтобы связать |
| `fontsize`, `ha` | размер и выравнивание | `ha="center"` для точки над столбцом |

Аннотация работает лучше подписи вне графика: она указывает прямо на данное, и читатель не гадает, к чему относится фраза.

Можно аннотировать максимум, минимум или выброс — главное, чтобы текст отвечал на вопрос «почему это важно», а не просто дублировал число (число и так на оси).

# Средняя линия и подпись в углу

Горизонтальная линия через весь график показывает средний уровень, норму или порог:

```python
avg = sum(visits) / len(visits)
ax.axhline(y=avg, color="gray", linestyle="--", linewidth=1, label=f"среднее {avg:.1f}")
ax.axvline(x=2, color="gray", linestyle=":", linewidth=1)  # вертикальная — «начало семестра»
ax.legend()
print(f"среднее по визитам: {avg:.1f}")
```

```text
среднее по визитам: 147.5
```

Точечная подпись в углу — способ добавить короткий вывод, не занимая легенду:

```python
best = max(zip(visits, months))  # (180, 'дек')
ax.text(0.02, 0.95, f"лучший месяц: {best[1]} ({best[0]})",
        transform=ax.transAxes, va="top", ha="left",
        bbox={"boxstyle": "round,pad=0.3", "facecolor": "white", "alpha":0.8})
```

- `axhline(y=…)` — горизонтальная линия через всё поле: удобно показать средний уровень или порог; `axvline(x=…)` — вертикальная (например, «начало семестра»).
- `ax.text(x, y, "…")` — просто текст в заданной точке осей (координаты данных) или фигуры.
- `transform=ax.transAxes` переводит координаты в **доли осей**: `(0, 0)` — левый нижний угол области, `(1, 1)` — правый верхний. Такой текст не «уезжает», если поменять пределы данных `set_ylim` — он остаётся в углу.

| Координаты | Что означают |
|---|---|
| `ax.text(0, 0, "…")` без `transform` | точка (0, 0) в данных — может оказаться вне графика |
| `ax.text(0.02, 0.95, "…", transform=ax.transAxes)` | 2 % от левого края, 95 % от низа — всегда в левом верхнем углу |
| `bbox={…}` | подложка под текст, чтобы читался на линии |

# Как это делают в проекте

Подписи — часть проверки «график понятен без контекста». В проекте их делают функцией и проверяют глазами и тестами.

1. **Функция не принимает «голый» график.** В `src/report/charts.py` заголовок и подписи осей — параметры функции, а не захардкоженные строки: так один и тот же код рисует «Посещения» и «Средний балл».

```python
from pathlib import Path

import matplotlib.pyplot as plt


def save_visits(months: list[str], visits: list[int], path: Path) -> Path:
    fig, ax = plt.subplots(figsize=(7, 4))
    ax.plot(months, visits, marker="o", color="tab:blue")
    ax.set_title("Посещения занятий")
    ax.set_xlabel("Месяц")
    ax.set_ylabel("Человек")
    ax.set_ylim(0, max(visits) * 1.2)  # «воздух» 20 % над максимумом — в одном месте
    avg = sum(visits) / len(visits)
    ax.axhline(avg, color="gray", linestyle="--", label=f"среднее {avg:.0f}")
    ax.legend()
    fig.tight_layout()
    fig.savefig(path, dpi=100)
    plt.close(fig)
    return path
```

2. **«Воздух» над графиком — правило, а не случайность.** `set_ylim(0, max*1.2)` оставляет 20 % места, чтобы линия и аннотации не липли к рамке.

3. **Длинные метки — сразу с поворотом и `tight_layout`.** В дисциплине 02 длинные строки резали, здесь их **поворачивают**: `ax.tick_params(axis="x", rotation=45)` — и только затем `tight_layout()`.

4. **Аннотации — по коду, а не на глаз.** Лучший месяц ищут `max(zip(visits, months))`, а не глазами: программа не ошибается, человек — да. Стрелка `xy` указывает на данную точку, `xytext` — в пустое место.

5. **Тест на подписи — через файл и размер, а не побайтово.** `tmp_path / "visits.png"` должен появиться и весить >10 КБ — значит, заголовок и оси не обрезаны `bbox_inches` и не пустые. Побайтовое сравнение ломается от шрифтов.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «Заголовок заменяет подписи осей» | Из заголовка не видно величин и единиц — нужны `xlabel`/`ylabel` |
| «`set_xticks` меняет данные» | Он меняет только метки; данные остаются как есть, просто ось подписывается иначе |
| «Длинные подписи надо сокращать до одной буквы» | Лучше повернуть на 45° и показать полностью — `tick_params(rotation=45)` |
| «Аннотацию ставят наугад, где красиво» | `xy` — точка данных, `xytext` — текст; без них стрелка уедет и будет врать |
| «Пределы осей Matplotlib подбирает правильно всегда» | Обычно да, но у столбцов и на узких данных проверяй вручную — иначе график «обрезан» |
