# 04. Подписи и оси

> [!abstract] О чём лекция
> Неподписанный график бесполезен: непонятно, что по осям, в каких единицах и что здесь
> важное. Здесь — заголовок, подписи осей, метки, пределы, поворот длинных подписей,
> аннотации со стрелками и вспомогательные линии.

# Заголовок и подписи осей

```python
import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt

months = ["сен", "окт", "ноя", "дек"]
visits = [120, 150, 140, 180]

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(months, visits, marker="o", color="tab:blue")
ax.set_title("Посещения занятий")
ax.set_xlabel("Месяц")
ax.set_ylabel("Человек")
```

| Метод | Что делает |
|---|---|
| `ax.set_title(...)` | заголовок графика |
| `ax.set_xlabel`, `ax.set_ylabel` | подписи осей; **сюда** пишут единицы измерения |
| `fig.suptitle(...)` | общий заголовок, когда графиков несколько ([[05. Несколько графиков]]) |
| `ax.set_xlabel("Месяц", fontsize=11)` | размер шрифта подписи |

Правило: единицы — в подписи оси («Человек», «Температура, °C», «Балл»), а не в заголовке.
Заголовок отвечает на вопрос «о чём график», ось — «в каких величинах».

# Метки и пределы осей

```python
ax.set_xticks(months)
ax.set_yticks([0, 50, 100, 150, 200])
ax.set_ylim(0, 220)
```

| Метод | Зачем |
|---|---|
| `set_xticks([...])` | задать метки явно: например, только месяцы, без лишних чисел |
| `set_yticks([...])` | «круглые» значения: 0, 50, 100, 150, 200 |
| `set_ylim(0, 220)` | пределы оси: оставить место над линией (220 > 180) |
| `set_xlim(...)` | то же для оси X |

Если меток много и они длинные, их поворачивают:

```python
months = ["сентябрь", "октябрь", "ноябрь", "декабрь", "январь", "февраль"]
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(months, [120, 150, 140, 180, 160, 170], marker="o")
ax.tick_params(axis="x", rotation=45)
fig.tight_layout()
fig.savefig("rotation.png", dpi=100)
```

```text
сохранено rotation.png
```

Поворот на 45° плюс `tight_layout()` — самый надёжный способ не дать подписям наехать
друг на друга.

# Аннотации: показать важное место

```python
ax.annotate(
    "каникулы",
    xy=("ноя", 140),
    xytext=("окт", 190),
    arrowprops={"arrowstyle": "->", "color": "tab:red"},
    color="tab:red",
)
```

| Параметр | Смысл |
|---|---|
| `xy` | куда указывает стрелка (точка данных) |
| `xytext` | где стоит текст |
| `arrowprops` | вид стрелки и цвет |
| `color` | цвет текста |

Аннотация — способ сказать читателю «смотри сюда» без пояснений в тексте.

# Средняя линия и подпись в углу

```python
ax.axhline(y=sum(visits) / len(visits), color="gray", linestyle="--", linewidth=1)
ax.text(0.02, 0.95, f"лучший месяц: {best[1]}", transform=ax.transAxes, va="top")
```

```text
среднее по визитам: 147.5
лучший месяц: (180, 'дек')
```

- `axhline(y=…)` — горизонтальная линия через всё поле: удобно показать средний уровень
  или порог; `axvline(x=…)` — вертикальная (например, «начало семестра»).
- `ax.text(...)` — просто текст в заданной точке.
- `transform=ax.transAxes` переводит координаты в **доли осей**: (0, 0) — левый нижний угол,
  (1, 1) — правый верхний. Такой текст не «уезжает», если поменять пределы данных.

# Как это делают в проекте

1. **Проверяют график без контекста.** Дайте картинку человеку, который не знает задачи:
   поймёт ли он, что по осям и в каких единицах? Если нет — добавьте подписи.
2. **Заголовок — фраза, а не название файла.** «Посещения занятий» лучше, чем «visits.png».
3. **Числа на осях — круглые.** 147.5 на оси не читается; оставьте его для аннотации
   или подписи значения.
4. **Не дублируют информацию.** Если все столбцы подписаны числами, ось можно оставить
   с редкими метками.
5. **Оставляют воздух.** `set_ylim(0, 220)` при максимуме 180 — так линия не липнет к рамке.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «Заголовок заменяет подписи осей» | Из заголовка не видно величин и единиц |
| «`set_xticks` меняет данные» | Он меняет только метки; данные остаются как есть |
| «Длинные подписи надо сокращать до одной буквы» | Лучше повернуть на 45° и показать полностью |
| «Аннотацию ставят наугад» | `xy` — точка данных, `xytext` — текст; без них стрелка уедет |
| «Пределы осей Matplotlib подбирает правильно всегда» | Обычно да, но у столбцов и «сложных» данных проверяйте вручную |

# Проверь себя

1. Где указывают единицы измерения — в заголовке или в подписи оси?
2. Что сделает `ax.set_yticks([0, 50, 100, 150, 200])`?
3. Как избежать наложения длинных подписей по оси X?
4. Чем `axhline` отличается от `ax.plot` с двумя точками?
5. Что даёт `transform=ax.transAxes`?

> [!success]- Ответы
> 1. В подписи оси: заголовок говорит «о чём», ось — «в чём».
> 2. Оставит на оси Y только эти пять меток.
> 3. Повернуть: `ax.tick_params(axis="x", rotation=45)` и вызвать `tight_layout()`.
> 4. `axhline` рисует линию через весь график по значению `y` — проще и не зависит от данных по X.
> 5. Координаты в долях осей: текст остаётся в углу при смене пределов.
