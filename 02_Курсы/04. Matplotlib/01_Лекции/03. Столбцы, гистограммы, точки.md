# 03. Столбцы, гистограммы, точки

> [!abstract] О чём лекция
> Линия показывает **изменение**, столбцы — **сравнение**, гистограмма — **распределение**,
> точки — **связь двух величин**. Выбрать правильный вид графика важнее, чем красиво
> его нарисовать.
>
> Здесь — `bar`, `hist`, `scatter` и подписи значений на столбцах.

# Столбцы: сравнение категорий

```python
import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt

subjects = ["Python", "Математика", "Физика"]
averages = [4.4, 4.1, 3.7]

fig, ax = plt.subplots()
bars = ax.bar(subjects, averages, color=["tab:green", "tab:blue", "tab:red"])
ax.set_title("Средний балл по предметам")
ax.set_ylim(0, 5)
ax.bar_label(bars, fmt="%.1f")
fig.savefig("bars.png", dpi=100)
```

| Приём | Зачем |
|---|---|
| `color=[…]` | разный цвет столбцов: акцент на конкретных предметах |
| `ax.set_ylim(0, 5)` | столбцы сравнивают величину — ось **обязана** начинаться с нуля |
| `ax.bar_label(bars, fmt="%.1f")` | числа прямо на столбцах: не нужно сверяться с осью |
| `ax.barh(...)` | горизонтальные столбцы: удобны, когда подписи длинные |

> [!warning] Столбцы без нуля на оси
> Обрезанная ось у столбцов — грубая ошибка: столбик «4.4» и «4.1» при оси от 4 до 5
> будут отличаться в 4 раза, хотя разница — 7 %. У столбцов ось значений всегда начинают
> с нуля, если нет отдельного предупреждения.

# Гистограмма: распределение

Гистограмма отвечает на вопрос «сколько значений попало в каждый интервал»:

```python
marks = [5, 5, 4, 5, 3, 4, 5, 2, 5, 4, 4, 5, 5, 3, 4]

fig2, ax2 = plt.subplots()
counts, edges, _ = ax2.hist(marks, bins=[1.5, 2.5, 3.5, 4.5, 5.5], color="tab:purple", rwidth=0.9)
ax2.set_title("Распределение оценок")
print("границы:", edges)
print("сколько в каждом интервале:", counts)
```

```text
границы: [1.5 2.5 3.5 4.5 5.5]
сколько в каждом интервале: [1. 2. 5. 7.]
```

Читается так: одна двойка, две тройки, пять четвёрок, семь пятёрок — 15 значений всего.
`hist` возвращает три вещи: **числа** по интервалам, **границы** и патчи (прямоугольники) —
первые две полезны, чтобы проверить себя.

| Настройка | Смысл |
|---|---|
| `bins=10` | 10 равных интервалов (по умолчанию — тоже число) |
| `bins=[1.5, 2.5, …]` | свои границы: удобно для целых оценок |
| `rwidth=0.9` | чуть уже столбиков, чтобы интервалы не сливались |

Число интервалов меняет картину: слишком мало — всё в одном столбце, слишком много —
«шум». Для учебных оценок границы по целым числам — самый честный вариант.

# Точки: связь двух величин

```python
fig3, ax3 = plt.subplots()
hours = [1, 2, 3, 4, 5, 6, 7, 8]
score = [2.5, 3.0, 3.4, 3.9, 4.1, 4.3, 4.4, 4.5]
ax3.scatter(hours, score, s=80, color="tab:orange", edgecolor="black")
ax3.set_title("Часы подготовки и балл")
```

| Параметр | Смысл |
|---|---|
| `s=80` | размер точки |
| `color`, `edgecolor` | заливка и обводка: обводка помогает на светлом фоне |
| `alpha=0.5` | прозрачность: спасает, когда точки накладываются |
| `c=values, cmap="viridis"` | цвет точки по третьей величине |

Диаграмма рассеяния показывает **связь**: если точки выстраиваются вверх — величины связаны.
Она не доказывает причину: «больше часов → выше балл» на таком графике выглядит правдоподобно,
но связи бывают и обратные, и случайные.

# Что чем рисовать

| Вопрос | График | Функция |
|---|---|---|
| как менялось во времени | линия | `plot` |
| что больше, что меньше | столбцы | `bar`, `barh` |
| как распределены значения | гистограмма | `hist` |
| связаны ли две величины | точки | `scatter` |
| доля целого | столбцы с нормировкой или круговая | `bar` (проценты), `pie` |

> [!note] Про круговые диаграммы
> `pie` существует, но читается хуже столбцов: сравнивать углы труднее, чем длины.
> Если задача — «показать доли», почти всегда лучше нормированные столбцы.

# Как это делают в проекте

1. **Вид графика выбирают по вопросу**, а не по привычке.
2. **Ось столбцов — от нуля**, у линии — по смыслу ([[02. Линии: настройка]]).
3. **Подписи значений** ставят там, где это экономит время читателя (`bar_label`).
4. **Проверяют числами.** `hist` возвращает counts и edges: распечатайте их и убедитесь,
   что сумма равна числу значений.
5. **Не рисуют «связь» по 8 точкам** как закономерность: для выводов нужны данные
   и статистика ([[00. NumPy]] — про средние, разброс и корреляции).

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «Столбцы и линия взаимозаменяемы» | Линия — про изменение, столбцы — про сравнение категорий |
| «Оценки лучше показывать линией» | Оценки 2–5 — это категории и распределение: столбцы или гистограмма |
| «Больше интервалов — точнее гистограмма» | Слишком много интервалов даёт шум и пустые столбцы |
| «Рассеяние доказывает причину» | Оно показывает связь; причину доказывают иначе |
| «Круговая диаграмма — универсальная» | Углы читаются хуже длин; для долей чаще лучше столбцы |

# Проверь себя

1. Какой график покажет, сколько учеников получили каждую оценку?
2. Почему у столбцов ось значений начинают с нуля?
3. Что возвращает `hist` и зачем это нужно?
4. Когда у диаграммы рассеяния ставят `alpha`?
5. Как показать динамику среднего балла по неделям?

> [!success]- Ответы
> 1. Гистограмма (`hist`) с границами по целым оценкам.
> 2. Столбцы сравнивают величины: обрезанная ось искажает соотношение.
> 3. Числа по интервалам, границы и патчи — чтобы проверить, что данные попали в нужные интервалы.
> 4. Когда точки накладываются друг на друга и «склеиваются» в пятно.
> 5. Линией (`plot`) по неделям — как в [[02. Линии: настройка]].
