# 07. Сохранение и качество

> [!abstract] О чём лекция
> График нужен не сам по себе, а в отчёте, презентации или программе. Здесь — как выбрать
> формат файла, разрешение и стиль, почему SVG с сотней тысяч точек весит сотни килобайт
> и как не испортить картинку при сохранении.

# Форматы: PNG, PDF, SVG

```python
fig.savefig("dpi72.png", dpi=72)
fig.savefig("dpi150.png", dpi=150)
fig.savefig("dpi100.png", dpi=100, bbox_inches="tight")
fig.savefig("picture.pdf")
fig.savefig("picture.svg")
```

```text
dpi72.png → (460, 345) пикселей, 15314 байт
dpi150.png → (960, 720) пикселей, 37254 байт
tight.png → (556, 434) пикселей, 22931 байт
picture.pdf → 10087 байт
picture.svg → 21326 байт
```

| Формат | Что это | Когда использовать |
|---|---|---|
| PNG | растровая картинка | скриншоты, веб, Word, чат |
| PDF | векторный документ | печать, отчёты, LaTeX |
| SVG | векторная графика | веб, презентации, дальнейшая правка |
| JPEG | растровый с потерями | не нужен: линии «мылятся» |

Векторные форматы (PDF, SVG) хранят **описание линий**, а не пиксели: их можно увеличить
без потери качества. Растровые (PNG) — сетку пикселей: при увеличении появляются ступеньки.

# Разрешение и размер

| Параметр | Что делает | Типичное значение |
|---|---|---|
| `figsize=(8, 4.5)` | форма и размер фигуры в дюймах | ширина 8–10 для отчёта |
| `dpi=100` | экран | по умолчанию |
| `dpi=150…300` | печать, вставка в документ | 150 для Word, 300 для печати |
| `bbox_inches="tight"` | обрезает белые поля | почти всегда |
| `transparent=True` | прозрачный фон вместо белого | для слайдов |

Изменение `dpi` не меняет компоновку: те же подписи, больше пикселей. А вот **уменьшение
`figsize`** может испортить картинку: подписи сожмутся и наедут.

# Большие данные и SVG

Векторный файл с десятками тысяч точек становится огромным:

```python
x = np.linspace(0, 10, 50_000)
y = np.sin(x) + rng.normal(0, 0.1, x.size)

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, y, linewidth=0.3)
fig.savefig("big.svg")

fig2, ax2 = plt.subplots(figsize=(8, 4))
ax2.plot(x, y, linewidth=0.3, rasterized=True)
fig2.savefig("big_raster.svg")
```

```text
big.svg 314033 байт
big_raster.svg 40564 байт
big.png 33933 байт
```

`rasterized=True` — параметр **линии**, а не `savefig`: при сохранении в векторный формат
эта линия превращается в растр, остальное (оси, подписи, сетка) остаётся векторным.
Файл уменьшился почти в 8 раз.

> [!warning] `rasterized` не принимает `savefig`
> Попытка `fig.savefig("big.svg", rasterized=True)` заканчивается ошибкой
> `TypeError: FigureCanvasSVG.print_svg() got an unexpected keyword argument 'rasterized'`.
> Параметр относится к artist — то есть к конкретной линии, набору точек или картинке.

# Стили

```python
print("доступные стили (первые 6):", plt.style.available[:6])
```

```text
доступные стили (первые 6): ['Solarize_Light2', 'bmh', 'classic', 'dark_background', 'fast', 'fivethirtyeight']
```

```python
with plt.style.context("ggplot"):
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3], [2, 3, 2])
    fig.savefig("context.png", dpi=100)

print("после контекста axes.grid:", plt.rcParams["axes.grid"])
```

```text
после контекста axes.grid: False
```

| Способ | Действие |
|---|---|
| `plt.style.use("ggplot")` | меняет стиль **для всей программы** дальше |
| `with plt.style.context("ggplot"):` | меняет стиль только внутри блока |
| `matplotlib.rcParams["figure.figsize"] = (8, 4.5)` | настройка по умолчанию |

Контекстный менеджер аккуратнее: один график в другом стиле не «покрасит» остальные.
Это видно по `rcParams["axes.grid"]`: после выхода из блока значение вернулось к `False`.

# Русские подписи

Шрифт по умолчанию — DejaVu Sans; он поддерживает кириллицу, и предупреждений о пропущенных
символах при сохранении нет:

```python
fig, ax = plt.subplots()
ax.plot([1, 2, 3], [2, 3, 1])
ax.set_title("Успеваемость группы: осень 2026")
ax.set_ylabel("Средний балл")
fig.savefig("cyrillic.png", dpi=100)
```

```text
предупреждений: 0
```

Если подписи всё же «квадратиками», причина обычно одна из трёх: выбран другой шрифт
(`font.family: serif` без поддержки кириллицы), используется математическая вёрстка
(`mathtext`, LaTeX) или старая сборка Matplotlib без шрифтов с кириллицей. Лечится
явным шрифтом:

```python
plt.rcParams["font.family"] = "DejaVu Sans"
```

# Как это делают в проекте

1. **PNG для вставки и просмотра, PDF/SVG для отчётов и печати.** Формат выбирают
   по тому, куда пойдёт картинка.
2. **`dpi` зависит от назначения**: 100 — экран, 150 — документ, 300 — печать.
3. **`bbox_inches="tight"`** почти всегда: лишние поля портят вёрстку.
4. **Стиль применяют контекстом**, а не глобально — особенно в библиотеках и тестах.
5. **Тяжёлые линии растрируют** при сохранении в SVG: иначе файл не откроется в браузере.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «PNG можно увеличить без потерь» | Это растр: при увеличении видны ступеньки; для масштаба — PDF/SVG |
| «`dpi` меняет компоновку» | Меняет только количество пикселей; компоновку задаёт `figsize` |
| «`rasterized=True` — в `savefig`» | Только у artist: `ax.plot(..., rasterized=True)` |
| «Стиль можно менять когда угодно» | `plt.style.use` меняет всё дальше; для одного графика — `context` |
| «Русские подписи сломаны всегда» | По умолчанию кириллица работает: предупреждений нет |

# Проверь себя

1. Чем PNG отличается от SVG?
2. Какой `dpi` выбрать для вставки в документ?
3. Что делает `bbox_inches="tight"`?
4. Как уменьшить SVG с 50 000 точек и куда передаётся параметр?
5. Чем `plt.style.use` отличается от `plt.style.context`?

> [!success]- Ответы
> 1. PNG — сетка пикселей (при увеличении ступеньки), SVG — описание линий, масштабируется без потерь.
> 2. Около 150; для печати — 300.
> 3. Обрезает белые поля вокруг фигуры при сохранении.
> 4. Растрировать линию: `ax.plot(..., rasterized=True)`; файл уменьшается примерно в 8 раз.
> 5. `use` меняет стиль до конца программы, `context` — только внутри блока.
