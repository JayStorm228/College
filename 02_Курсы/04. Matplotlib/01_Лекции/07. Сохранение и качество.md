# 07. Сохранение и качество

> [!abstract] О чём лекция
> График на экране — черновик; результат — файл, который вставят в отчёт, слайды или печать. Формат и разрешение решают, будет ли картинка чёткой, лёгкой и масштабируемой.
>
> Здесь — чем PNG отличается от PDF и SVG, как выбор `dpi` и `bbox_inches` влияет на пиксели и вес, зачем `rasterized` для тяжёлых линий, как применять стили контекстом и почему кириллица «внезапно» работает.

# Форматы: PNG, PDF, SVG

Один и тот же график `fig, ax = plt.subplots(); ax.plot([1,2,3],[2,3,1])` можно сохранить тремя способами:

```python
import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt
from pathlib import Path

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [2, 3, 1])

fig.savefig("plot.png", dpi=100)  # растр: сетка пикселей
fig.savefig("plot.pdf")            # вектор: описание линий
fig.savefig("plot.svg")            # вектор: описание линий, удобно для веба и правки

for name in ("plot.png", "plot.pdf", "plot.svg"):
    print(f"{name}: {Path(name).stat().st_size:_} байт".replace("_", " "))
```

```text
plot.png: 25 622 байт
plot.pdf: 5 043 байт
plot.svg: 16 032 байт
```

Размеры зависят от версии Matplotlib и шрифтов, но соотношение обычно такое же: PDF легче всего, PNG тяжелее.

| Формат | Что внутри | Масштабирование | Где используется | Размер для примера выше |
|---|---|---|---|---|
| **PNG** | растр — сетка пикселей | при увеличении — ступеньки | чат, предпросмотр, вставка в документ | 25 622 байта, 640×480 |
| **PDF** | вектор — команды «линия от … до …» | без потерь, печать | отчёт, статья, печать | 5 043 байта |
| **SVG** | вектор — XML с линиями | без потерь, правка в Inkscape | слайды, веб, ручная правка | 16 032 байта |

Растровый PNG зависит от `dpi`: чем выше, тем больше пикселей и тем тяжелее файл. Векторные PDF/SVG от `dpi` почти не зависят — они хранят описание, а не пиксели, поэтому масштабируются без потерь.

Правило курса: **PNG — для просмотра и вставки «как есть», PDF — для печати, SVG — когда график будут править или вставлять в веб.** Для отчёта чаще берут PDF (лучше сжимает однотипные команды) и дублируют PNG для предпросмотра.

# Разрешение и размер

Для PNG размер = `figsize` × `dpi`; для вектора `dpi` не важен, но `figsize` задаёт пропорции:

```python
from PIL import Image

print("figsize:", plt.rcParams["figure.figsize"], "| dpi:", plt.rcParams["figure.dpi"])
fig, ax = plt.subplots(figsize=(8, 4.5))
ax.plot([1, 2, 3, 4], [3, 4, 4, 5], marker="o")
fig.savefig("screen.png", dpi=100)
fig.savefig("print.png", dpi=150)
fig.savefig("tight.png", dpi=100, bbox_inches="tight")

for name in ("screen.png", "print.png", "tight.png"):
    width, height = Image.open(name).size
    size = Path(name).stat().st_size
    print(f"{name:10} → {width}×{height} пикселей, {size:_} байт".replace("_", " "))
```

```text
figsize: [6.4, 4.8] | dpi: 100.0
screen.png → 800×450 пикселей, 21 840 байт
print.png  → 1200×675 пикселей, 34 555 байт
tight.png  → 680×390 пикселей, 21 109 байт
```

`tight.png` вышел меньше `800×450`: белые поля обрезаны.

| Настройка | Что делает | Типичные значения |
|---|---|---|
| `figsize=(8, 4.5)` | форма фигуры в дюймах | `6.4×4.8` — по умолчанию; `8×4.5` — шире для подписей |
| `dpi=100` | пиксели на дюйм для PNG | 100 — экран, 150 — документ, 300 — печать |
| `bbox_inches="tight"` | обрезает лишние поля при записи | почти всегда — экономит место |
| `fig.tight_layout()` | распределяет место внутри фигуры | перед `savefig`, чтобы подписи не наезжали |

`dpi` не меняет компоновку — только число пикселей. Компоновку задаёт `figsize`. `bbox_inches="tight"` и `tight_layout` — вместе: первый режет поля, второй распределяет место между заголовком и осями.

> [!warning] Путать `tight_layout` и `bbox_inches` — легко
> `fig.tight_layout()` — метод фигуры, вызывается **до** `savefig`. `bbox_inches="tight"` — параметр `savefig`. Обычно в проекте пишут так: `fig.tight_layout(); fig.savefig(path, dpi=100, bbox_inches="tight")`. Если подписи всё равно обрезаны, увеличь `figsize`.

# Большие данные и SVG

Векторный формат удобен, пока линий немного. С 40 000 точек `plot` в SVG становится списком из 40 000 команд — файл растёт:

```python
import numpy as np
rng = np.random.default_rng(7)
x = np.linspace(0, 10, 40_000)
y = np.sin(x) + rng.normal(0, 0.15, x.size)

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, y, linewidth=0.3, color="tab:blue")
fig.savefig("big.svg")
fig.savefig("big.png", dpi=100)

for name in ("big.svg", "big.png"):
    print(f"{name}: {Path(name).stat().st_size:_} байт".replace("_", " "))
```

```text
big.svg: 270 932 байт
big.png: 31 997 байт
```

SVG в 8.5 раза тяжелее PNG, тяжелее открывается и правится. Решение — **растрировать только тяжёлую линию**, а оси и подписи оставить векторными:

```python
fig2, ax2 = plt.subplots(figsize=(8, 4))
ax2.plot(x, y, linewidth=0.3, color="tab:blue", rasterized=True)
ax2.set_title("40 000 точек — линия растром, подписи вектором")
fig2.savefig("big_raster.svg")
fig2.savefig("big_raster.png", dpi=100)

for name in ("big_raster.svg", "big_raster.png"):
    size = Path(name).stat().st_size
    print(f"{name}:", f"{size:,}".replace(",", " "), "байт")
```

```text
big_raster.svg: 47 681 байт
big_raster.png: 36 034 байт
```

Файл уменьшился почти в 6 раз: `big.svg` 271 КБ → `big_raster.svg` 48 КБ, того же порядка, что PNG (в этом примере добавился заголовок, поэтому `big_raster.png` чуть тяжелее `big.png`). Разница — в растре только линия, остальное (оси, сетка, заголовок) — вектор и остаётся чётким при масштабировании.

> [!warning] `rasterized` не принимает `savefig`
> Попытка `fig.savefig("big.svg", rasterized=True)` заканчивается ошибкой `TypeError: FigureCanvasSVG.print_svg() got an unexpected keyword argument 'rasterized'`. Параметр относится к **artist** — линии, точкам, картинке: `ax.plot(..., rasterized=True)`, `ax.scatter(..., rasterized=True)`, `ax.imshow(..., rasterized=True)`.

# Стили

Стиль — набор `rcParams` (цвет фона, сетка, шрифт). Два способа применять:

```python
print("доступные стили (первые 6):", plt.style.available[:6])
```

```text
доступные стили (первые 6): ['Solarize_Light2', 'bmh', 'classic', 'dark_background', 'fast', 'fivethirtyeight']
```

```python
# локально — только внутри блока
with plt.style.context("ggplot"):
    print("внутри контекста axes.grid:", plt.rcParams["axes.grid"])
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3], [2, 3, 2])
    fig.savefig("context.png", dpi=100)
print("после контекста axes.grid:", plt.rcParams["axes.grid"])

# глобально — на всю программу дальше
plt.style.use("ggplot")
print("после use axes.grid:", plt.rcParams["axes.grid"])
```

```text
внутри контекста axes.grid: True
после контекста axes.grid: False
после use axes.grid: True
```

| Способ | Действие | Когда |
|---|---|---|
| `plt.style.use("ggplot")` | меняет стиль для всей программы дальше | в начале скрипта, если весь отчёт в одном стиле |
| `with plt.style.context("ggplot"):` | только внутри блока, затем возвращает | для одного графика в библиотеке/тестах |
| `matplotlib.rcParams["figure.figsize"] = (8, 4.5)` | тонкая настройка одного параметра | когда стиль почти подходит |

Контекстный менеджер аккуратнее: один график в другом стиле не «покрасит» остальные — видно по `rcParams["axes.grid"]`, который вернулся к `False` после выхода из блока. В тестах и библиотеках `use` опасен — он меняет глобальное состояние.

# Русские подписи

Шрифт по умолчанию Matplotlib — DejaVu Sans; он поддерживает кириллицу, и предупреждений о пропущенных символах при сохранении нет:

```python
import warnings

with warnings.catch_warnings(record=True) as caught:
    warnings.simplefilter("always")
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3], [2, 3, 1])
    ax.set_title("Успеваемость группы: осень 2026")
    ax.set_ylabel("Средний балл")
    ax.set_xlabel("Неделя")
    fig.tight_layout()
    fig.savefig("cyrillic.png", dpi=100)

print("предупреждений:", len(caught), "| шрифт:", plt.rcParams["font.sans-serif"][0])
```

```text
предупреждений: 0 | шрифт: DejaVu Sans
```

Если подписи «квадратиками», причина обычно одна из трёх: выбран другой шрифт без кириллицы (`font.family: serif` на старой сборке), используется математическая вёрстка `mathtext` с `$…$`, или старая сборка Matplotlib без шрифтов. Лечится явным шрифтом:

```python
plt.rcParams["font.family"] = "DejaVu Sans"
# или для конкретного графика
ax.set_title("Осень 2026", fontfamily="DejaVu Sans")
```

Проверить, что шрифт поддерживает символ, можно по логу: Matplotlib выдаёт предупреждение вида `Glyph … missing from font(s) DejaVu Sans`, если символа в шрифте нет (его видно в блоке `warnings.catch_warnings` выше).

# Как это делают в проекте

Формат и качество — решение на уровне отчёта, а не каждой функции, но каждая функция должна уметь их обеспечить.

1. **PNG для вставки и просмотра, PDF/SVG для отчётов и печати.** Формат выбирают по тому, куда пойдёт картинка, а функция принимает `path: Path` и не решает за вызывающего:

```python
# src/report/charts.py
def save_average_bars(subjects, averages, path: Path) -> Path:
    fig, ax = plt.subplots(figsize=(7, 4.5))
    bars = ax.bar(subjects, averages, color="tab:blue")
    ax.set_ylim(0, 5)
    ax.bar_label(bars, fmt="%.1f")
    fig.tight_layout()
    fig.savefig(path, dpi=150 if path.suffix==".pdf" else 100, bbox_inches="tight")
    plt.close(fig)
    return path
```

2. **`dpi` зависит от назначения, а не «по умолчанию».** 100 — экран и чат, 150 — документ, 300 — печать. В `main.py` это константа `DPI = 150`, а не магическое число в каждой `savefig`.

3. **`bbox_inches="tight"` почти всегда, плюс `tight_layout` до него.** Лишние поля портят вёрстку отчёта, а наложение подписей — признак незавершённой картинки. В проекте это правило, а не рекомендация: `fig.tight_layout(); fig.savefig(path, dpi=DPI, bbox_inches="tight")`.

4. **Стиль — контекстом, а не глобально.** В библиотеке графиков `plt.style.use("ggplot")` сломает тесты, которые ждут `axes.grid == False`. Для одного графика — `with plt.style.context(...)`, для всего отчёта — `use` в `main.py` до импорта своих модулей.

5. **Тяжёлые линии растрируют при сохранении в SVG/PDF.** `ax.plot(x, y, rasterized=True)` — у линии, не у `savefig`. В отчёте с 40 000 точек это разница между 271 КБ и 48 КБ: файл меньше и быстрее открывается.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «PNG можно увеличить без потерь» | Это растр: при увеличении видны ступеньки; для масштаба — PDF/SVG |
| «`dpi` меняет компоновку графика» | Меняет только число пикселей; компоновку задаёт `figsize`, а поля — `bbox_inches` |
| «`rasterized=True` — параметр `savefig`» | Только у artist: `ax.plot(..., rasterized=True)` — иначе `TypeError` |
| «Стиль можно менять когда угодно глобально» | `plt.style.use` меняет всё дальше; для одного графика — `context`, иначе тесты падают |
| «Русские подписи сломаны всегда» | По умолчанию DejaVu Sans поддерживает кириллицу — предупреждений `missing from font` нет |

> [!success]- Ответы
