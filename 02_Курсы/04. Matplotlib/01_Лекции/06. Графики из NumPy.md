# 06. Графики из NumPy

> [!abstract] О чём лекция
> Matplotlib и NumPy работают в паре: массивы — это данные, Matplotlib — их картинка.
> Он принимает массивы точно так же, как списки, но с ними доступны вещи, которые
> на списках неудобны: сглаживание, коридоры значений, планки погрешностей, вычисления
> по осям.
>
> Здесь — типичные приёмы: линия со сглаживанием, заливка «коридора», столбцы с разбросом.

# Массивы вместо списков

```python
import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(42)
days = np.arange(1, 31)
temperature = 12 + 4 * np.sin(days / 4) + rng.normal(0, 1.2, days.size)
```

Здесь `days` — массив от 1 до 30, а `temperature` — «сезонная волна» плюс случайный шум.
Так удобно получать **правдоподобные данные** для учебных графиков: без файла и без
ручного ввода тридцати чисел.

```python
fig, ax = plt.subplots(figsize=(8, 4.5))
ax.plot(days, temperature, color="tab:blue", alpha=0.5, label="по дням")
```

Свойство `days.size` — число элементов; в NumPy это привычнее, чем `len(days)` из Python
(результат тот же).

# Сглаживание: скользящее среднее

Шумную линию трудно читать. Скользящее среднее «усредняет окно» из нескольких соседних
точек:

```python
window = 7
smooth = np.convolve(temperature, np.ones(window) / window, mode="valid")
smooth_days = days[window - 1 :]

ax.plot(smooth_days, smooth, color="tab:red", linewidth=2, label="сглаживание (7 дней)")
```

```text
длина сглаживания (окно 7, 30 дней): 24
```

Почему 24, а не 30: режим `mode="valid"` считает среднее только там, где окно целиком
помещается в данных — то есть с 7-го дня по 30-й. Отсюда и `smooth_days = days[6:]`:
у сглаженной линии меньше точек, и ось X для неё своя.

```text
средняя: 12.43
минимум: 6.94 | максимум: 16.49
первое сглаженное значение: 14.59 на день 7
последнее: 13.72 на день 30
```

| Приём | Что делает |
|---|---|
| `window=7` | окно в 7 дней: неделя |
| `np.ones(window) / window` | равные веса: каждый день даёт 1/7 |
| `mode="valid"` | без «краёв»: средние только по полным окнам |
| `mode="same"` | результат той же длины, что и данные (края считаются иначе) |

Правило: сглаженная линия хорошо показывает **тенденцию**, но она не заменяет данные;
рисуйте обе линии — исходную полупрозрачной и сглаженную яркой.

# Коридор значений: `fill_between`

```python
ax.fill_between(
    smooth_days,
    smooth - 1,
    smooth + 1,
    color="tab:red",
    alpha=0.15,
    label="коридор ±1°",
)
```

`fill_between(x, низ, верх)` закрашивает область между двумя линиями. Так показывают:

- разброс (среднее ± отклонение);
- прогноз (оптимистичный и пессимистичный сценарий);
- допустимый диапазон (норма, план).

# Планки погрешностей: `errorbar`

```python
subjects = ["Python", "Математика", "Физика", "Информатика"]
means = np.array([4.4, 4.1, 3.7, 4.3])
errors = np.array([0.3, 0.4, 0.6, 0.2])

fig, ax = plt.subplots(figsize=(7, 4))
ax.errorbar(subjects, means, yerr=errors, fmt="o", capsize=5, color="tab:blue")
ax.set_ylim(2.5, 5.2)
ax.set_title("Средний балл и разброс (стандартное отклонение)")
```

```text
столбцы с отклонениями: разброс от [4.1 3.7 3.1 4.1] до [4.7 4.5 4.3 4.5]
```

`yerr` — насколько значение может отклониться; `capsize` — ширина «усиков» на концах.
Такая картинка честнее: видно, что физика отстаёт не только в среднем, но и «разбросана» сильнее.

> [!note] Откуда берутся `errors`
> Стандартное отклонение и ошибку среднего считает NumPy: `np.std`, `np.std(ddof=1) / np.sqrt(n)`.
> Как это делать правильно — в курсе [[00. NumPy]] (лекции про агрегаты и оси).

# Как это делают в проекте

1. **Данные готовят до рисования.** График — последний шаг: сначала массивы, затем картинка.
2. **Сглаживание подписывают.** Читатель должен видеть, что линия усреднена и по какому окну.
3. **Разброс показывают вместе со средним** — планкой, коридором или отдельным графиком.
4. **Держат случайность воспроизводимой**: `default_rng(42)` — при повторном запуске
   картинка та же ([[00. NumPy]], лекция про генерацию).
5. **Проверяют числа текстом.** `print(temperature.mean())` перед рисованием: если средняя
   не та, что ожидалось, график только запутает.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «Matplotlib хочет списки» | Массивы NumPy подходят напрямую — и это удобнее для вычислений |
| «Сглаженная линия точнее исходной» | Она показывает тенденцию и скрывает детали; рисуйте обе |
| «`mode="valid"` не меняет длину» | Меняет: точек меньше, ось X тоже должна стать короче |
| «Случайные данные каждый раз разные — это нормально» | Для учебных и тестовых графиков фиксируйте `seed`, иначе картинки не сравнить |
| «Разброс не важен, если средние разные» | У «Физики» среднее ниже **и** разброс выше — это часть вывода |
