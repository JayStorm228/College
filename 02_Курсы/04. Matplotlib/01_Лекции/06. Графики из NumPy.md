# 06. Графики из NumPy

> [!abstract] О чём лекция
> Matplotlib и NumPy работают в паре: массивы — это данные, Matplotlib — их картинка. Он принимает массивы точно так же, как списки, но с ними доступны вещи, которые на списках неудобны: сглаживание, коридоры значений, планки погрешностей и вычисления по осям.
>
> Здесь — типичные приёмы: линия со сглаживанием скользящим средним, заливка коридора `fill_between`, столбцы с разбросом `errorbar` и воспроизводимая случайность `default_rng`.

# Массивы вместо списков

NumPy даёт короткие и быстрые способы получить правдоподобные данные для графиков — без файла и без ручного ввода тридцати чисел:

```python
import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(42)
days = np.arange(1, 31)                         # 1 .. 30
temperature = 12 + 4 * np.sin(days / 4) + rng.normal(0, 1.2, days.size)
print("дней:", days.size, "| средняя:", round(float(temperature.mean()), 2))
print("первые три:", np.round(temperature[:3], 2))
```

```text
дней: 30 | средняя: 12.43
первые три: [13.36 12.67 15.63]
```

Здесь `days` — массив `arange(1,31)`, а `temperature` — «сезонная волна» `12 + 4*sin(days/4)` плюс случайный шум `normal(0,1.2)`. Так удобно получать **правдоподобные данные** для учебных графиков: формула + шум.

```python
fig, ax = plt.subplots(figsize=(8, 4.5))
ax.plot(days, temperature, color="tab:blue", alpha=0.5, label="по дням")
ax.set_xlabel("День")
ax.set_ylabel("Температура, °C")
ax.legend()
```

Свойство `days.size` — число элементов; в NumPy это привычнее, чем `len(days)` из Python (результат тот же: 30). Matplotlib принимает массивы напрямую — `ax.plot(days, temperature)` работает с `np.ndarray` так же, как со списками, но дальнейшие вычисления (среднее, сглаживание) уже «нумпайные».

> [!note] Почему `default_rng(42)`
> `42` — фиксированное зерно. При повторном запуске график тот же, и тесты не ломаются от случайности. В курсе [[00. NumPy]] это разбирается как «воспроизводимые случайные данные»; здесь — маленький приём, который делает учебные графики сравнимыми. Без фиксированного зерна каждый `pytest` давал бы новую картинку.

# Сглаживание: скользящее среднее

Шумную линию трудно читать: точки прыгают, тенденция теряется. Скользящее среднее усредняет окно из нескольких соседних точек:

```python
window = 7
smooth = np.convolve(temperature, np.ones(window) / window, mode="valid")
smooth_days = days[window - 1 :]
print("длина сглаживания (окно 7, 30 дней):", smooth.size)
print("первое сглаженное:", round(float(smooth[0]), 2), "на день", int(smooth_days[0]))
print("последнее:", round(float(smooth[-1]), 2), "на день", int(smooth_days[-1]))
```

```text
длина сглаживания (окно 7, 30 дней): 24
первое сглаженное: 14.59 на день 7
последнее: 13.72 на день 30
```

Почему 24, а не 30: режим `mode="valid"` считает среднее только там, где окно целиком помещается в данных — с 7-го дня по 30-й. Отсюда и `smooth_days = days[6:]`: у сглаженной линии меньше точек, и ось X для неё своя — с 7 по 30.

```python
ax.plot(smooth_days, smooth, color="tab:red", linewidth=2, label="сглаживание (7 дней)")
ax.fill_between(smooth_days, smooth - 1, smooth + 1, color="tab:red", alpha=0.15, label="коридор ±1°")
```

| Приём | Что делает | Когда другой режим |
|---|---|---|
| `window=7` | окно в 7 дней — неделя | 3 — шумнее, 14 — глаже, но скрывает детали |
| `np.ones(window) / window` | равные веса: каждый день даёт 1/7 | для взвешенного окна — другие веса |
| `mode="valid"` | без «краёв»: средние только по полным окнам | длина меньше, зато честно |
| `mode="same"` | результат той же длины, что и данные (края считаются с нулями) | удобно, но края искажены |
| `smooth_days = days[window-1:]` | своя ось X для сглаженной линии | без неё линия «сдвинется» влево |

Правило: сглаженная линия хорошо показывает **тенденцию**, но она не заменяет данные; рисуй обе — исходную полупрозрачной `alpha=0.5` и сглаженную яркой `linewidth=2`. Читатель должен видеть, что сглаживание — усреднение, а не новые измерения.

# Коридор значений: `fill_between`

`ax.fill_between(x, низ, верх)` закрашивает область между двумя линиями. Так показывают:

- разброс — среднее ± отклонение;
- прогноз — оптимистичный и пессимистичный сценарий;
- допустимый диапазон — норма, план, коридор.

```python
ax.fill_between(
    smooth_days,
    smooth - 1,
    smooth + 1,
    color="tab:red",
    alpha=0.15,
    label="коридор ±1°",
)
ax.set_title("Температура: по дням и сглаживание")
ax.legend()
fig.tight_layout()
fig.savefig("smooth.png", dpi=100)
```

Коридор — не «украшение», а честность: он показывает, где данные могли бы быть. Прозрачность `alpha=0.15` делает заливку фоном, а не спорящей с линией. Если коридоров несколько (например, ±1 и ±2), клади более широкий с меньшим `alpha` первым.

# Планки погрешностей: `errorbar`

Когда есть среднее и разброс по категориям, их показывают планками погрешностей:

```python
subjects = ["Python", "Математика", "Физика", "Информатика"]
means = np.array([4.4, 4.1, 3.7, 4.3])
errors = np.array([0.3, 0.4, 0.6, 0.2])  # стандартное отклонение

fig2, ax2 = plt.subplots(figsize=(7, 4))
ax2.errorbar(subjects, means, yerr=errors, fmt="o", capsize=5, color="tab:blue", ecolor="gray")
ax2.set_ylim(2.5, 5.2)
ax2.set_title("Средний балл и разброс (стандартное отклонение)")
ax2.set_ylabel("Балл")
ax2.grid(True, axis="y", linestyle=":", alpha=0.5)
fig2.tight_layout()
fig2.savefig("errorbar.png", dpi=100)
print("разброс от", np.round(means-errors,1), "до", np.round(means+errors,1))
```

```text
разброс от [4.1 3.7 3.1 4.1] до [4.7 4.5 4.3 4.5]
```

`yerr` — насколько значение может отклониться; `capsize` — ширина «усиков» на концах; `fmt="o"` — маркер точки; `ecolor` — цвет усов. Такая картинка честнее: видно, что физика отстаёт не только в среднем (3.7), но и «разбросана» сильнее (`±0.6`).

> [!note] Откуда берутся `errors` и почему это NumPy
> Стандартное отклонение `np.std`, ошибку среднего `np.std(ddof=1) / np.sqrt(n)`, корреляцию `np.corrcoef` считает NumPy — см. лекции курса [[00. NumPy]] про агрегаты и оси. Здесь важно, что среднее без разброса — половина правды.

# Как это делают в проекте

Данные готовят до рисования; график — последний шаг, где уже не считают, а показывают.

1. **Данные — `np.ndarray`, график — `ax.plot(ndarray, ndarray)`.** В `src/report/data.py` — массивы `days`, `temperature` как `np.ndarray`, в `src/report/charts.py` — только `ax.plot(x, y)`. Так сглаживание, `mean`, `fill_between` — без циклов Python, как в [[00. NumPy]].

```python
# src/report/data.py
import numpy as np
rng = np.random.default_rng(42)
days = np.arange(1, 31)
temperature = 12 + 4*np.sin(days/4) + rng.normal(0, 1.2, days.size)

# src/report/charts.py
def save_temperature(days: np.ndarray, temp: np.ndarray, smooth: np.ndarray, path: Path) -> Path:
    fig, ax = plt.subplots(figsize=(8,4.5))
    ax.plot(days, temp, color="tab:blue", alpha=0.5, label="по дням")
    ax.plot(days[6:], smooth, color="tab:red", linewidth=2, label="7 дней")
    ax.fill_between(days[6:], smooth-1, smooth+1, color="tab:red", alpha=0.15)
    fig.tight_layout(); fig.savefig(path, dpi=100); plt.close(fig)
    return path
```

2. **Сглаживание подписывают и не прячут исходные точки.** Читатель должен видеть, что линия усреднена и по какому окну (`label="сглаживание (7 дней)"`) — иначе график врёт, как обрезанная ось.

3. **Разброс показывают вместе со средним — планкой или коридором, а не отдельным числом в таблице.** `errorbar` и `fill_between` — часть одной картинки, а не «показатель в сноске».

4. **Случайность — воспроизводима.** `default_rng(42)` в `data.py` и в тестах — при повторном запуске картинка та же, и `pytest` не зависит от фазы луны.

5. **Числа проверяют текстом до рисования.** `print(temperature.mean(), temperature.std())` перед `savefig`: если средняя 12.43, а ожидалось 15 — график только запутает. В `main.py` — сначала `print` чисел, затем графики, как в мини-проекте.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «Matplotlib хочет списки» | Массивы NumPy подходят напрямую — и это удобнее для вычислений и сглаживания |
| «Сглаженная линия точнее исходной» | Она показывает тенденцию и скрывает детали; рисуй обе, иначе теряешь шум и выбросы |
| «`mode="valid"` не меняет длину» | Меняет: точек меньше (30→24), и ось X тоже должна стать короче (`days[6:]`) |
| «Случайные данные каждый раз разные — это нормально» | Для учебных и тестовых графиков фиксируй `seed` (`default_rng(42)`), иначе картинки не сравнить |
| «Разброс не важен, если средние разные» | У «Физики» среднее ниже **и** разброс выше — это часть вывода, без неё сравнение неполно |
