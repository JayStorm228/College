# Matplotlib — курс

> [!abstract] О чём курс
> Matplotlib превращает числа в картинки: линии, столбцы, гистограммы, точки. Он показывает
> то, что трудно увидеть в таблице, — динамику, распределение, разброс и связь величин.
>
> **Кому:** тому, кто знает основы Python (дисциплина 02, лекции 05–16). Опыт с NumPy
> полезен, но не обязателен: графики строятся и по обычным спискам.
>
> **Зачем:** отчёт, исследование, выступление — везде картинка убеждает сильнее таблицы.
> Но чтобы график не обманывал, нужно знать две-три вещи: честные пределы осей, правильный
> вид диаграммы и разницу между растром и вектором.

> [!important] Как проходить
> 1. Лекции — по порядку: сначала график и сохранение, затем линии, столбцы и подписи.
> 2. После лекций 01–02 — практика [[01. Практика. Линии и оформление]], после 03–04 —
>    [[02. Практика. Столбцы и распределения]], после 05–07 — [[03. Практика. Несколько осей и сохранение]].
> 3. Каждый график **сохраняй в файл и смотри глазами**: подписи наехали? числа читаются?
> 4. В конце — мини-проект [[04. Мини-проект. Отчёт по успеваемости]].
>
> **Можно проходить параллельно с [[00. NumPy]]** — библиотеки работают в паре: NumPy готовит
> массивы, Matplotlib рисует. Если NumPy ещё не пройден, начни с него: он даст данные,
> статистику и сглаживание ([[06. Графики из NumPy]]).

| VS Code с расширением Python | просмотр картинок прямо в редакторе | `.vscode/extensions.json` в `04_Код/` |
| `pytest`, `mypy`, `black`, `ruff` | тесты и проверки (мини-проект) | `uv add --dev pytest mypy black ruff` |

Проверить установку:

```bash
uv run python -c "import matplotlib; print(matplotlib.__version__)"
```

```text
3.11.2
```

> [!note] Про версии и бэкенд
> В примерах курса — Matplotlib 3.11 (проверено на 3.11.2). Скрипты сохраняют картинки
> через `matplotlib.use("Agg")`: этот бэкенд не требует окна и работает в контейнере,
> на сервере и в тестах. В Jupyter и VS Code бэкенд другой — там график показывается
> на экране (`inline`, `QtAgg`), и `plt.show()` уместен.

# Место в обучении

Курс опирается на базовый Python (дисциплина 02, лекции 05–16) и лучше всего идёт
**после или параллельно с [[00. NumPy]]**: массивы дают данные, статистику и сглаживание
для графиков. Инженерные привычки из [[00. Инженерные практики Python]] нужны в мини-проекте:
функции, тесты, структура пакета, логирование.

| Связь | Как связаны |
|---|---|
| [[00. NumPy]] | массивы и вычисления → данные для графиков |
| [[00. Pydantic]] | проверенные данные приятно рисовать: неожиданных значений уже не будет |
| [[00. Инженерные практики Python]] | упаковка рисования в функции, тесты, `.gitignore` для `out/` |
