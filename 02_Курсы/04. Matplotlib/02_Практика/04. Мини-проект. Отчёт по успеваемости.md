> [!abstract] Что это за проект
> Программа строит отчёт по успеваемости: сначала **числа** (средние по предметам,
> распределение оценок, рост балла от часов подготовки), затем **четыре графика** —
> столбцы, гистограмма, линии и точки.

> подписи ([[04. Подписи и оси]]), сохранение файлов ([[07. Сохранение и качество]])
> и упаковку рисования в функции с тестами ([[08. Графики в проекте]]).
>
> **Перед началом** пройди практики [[01. Практика. Линии и оформление]],
> [[02. Практика. Столбцы и распределения]] и [[03. Практика. Несколько осей и сохранение]],
> а также курс [[00. Инженерные практики Python]] — тесты, структура пакета и логирование
> здесь используются как в любом проекте.

Данные (`data.py`) — руками, без случайности: так числа отчёта воспроизводимы.

```python
MARKS_BY_SUBJECT: dict[str, list[int]] = {
    "Python": [5, 5, 4, 5, 4, 5, 4, 5],
    "Математика": [4, 5, 4, 4, 5, 3, 4, 4],
    "Физика": [4, 3, 4, 4, 3, 4, 5, 3],
    "Информатика": [5, 4, 5, 4, 4, 5, 5, 4],
}

WEEKS = ["1", "2", "3", "4"]
DYNAMICS: dict[str, list[float]] = {
    "Python": [3.5, 4.0, 4.5, 4.8],
    "Математика": [4.2, 4.0, 4.4, 4.6],
}

HOURS = [1, 2, 3, 4, 5, 6, 7, 8]
SCORE = [2.5, 3.0, 3.4, 3.9, 4.1, 4.3, 4.4, 4.5]

ALL_MARKS: list[int] = [mark for marks in MARKS_BY_SUBJECT.values() for mark in marks]
```

Подсказки по реализации, чтобы не искать:

- **Средние:** `sum(marks) / len(marks)`, округлять через `round(..., 2)`.
- **Распределение:** словарь «оценка → сколько раз встретилась», затем `dict(sorted(...))`.
- **Наклон («рост балла за час»):** сумма `(часы − средние часы) × (балл − средний балл)`,
  делённая на сумму квадратов отклонений часов. Это коэффициент наклона прямой —
  средний прирост балла на один час.
- **Путь к файлу:** `fig.savefig(path, dpi=100)` принимает и `Path`, и строку.

# Как идти

1. **Структура и первый коммит.** Папки `src/report`, `tests`, `.gitignore` с `out/`,
   короткий `README.md`, пустые модули с docstring.
2. **`data.py`.** Данные и `averages()`. Сразу проверь в консоли, что средние —
   `4.62`, `4.12`, `3.75`, `4.50`.
3. **`summary.py`.** Числа и текст отчёта. Это **основа**: пока числа неверны, графики
   только запутают. Тесты на числа пишутся здесь же.
4. **Один график.** `save_average_bars` — самый простой. Убедись, что файл появился
   и открывается, значения подписаны, а столбцы начинаются от нуля.
5. **Остальные графики** — по одному, с проверкой после каждого. Не забудь `plt.close(fig)`.
6. **`main.py`.** Порядок важен: `matplotlib.use("Agg")` **до** импорта `pyplot`,
   затем сборка отчёта, затем графики.
7. **Тесты.** Числа — точно, графики — через `tmp_path` и проверку «файл создан и не пустой».
8. **Проверки.** `pytest`, `mypy`, `black --check`, `ruff check`, затем запуск из корня —
   и сверь числа со списком ниже.
9. **Коммиты по шагам.** «Структура и данные», «Текстовый отчёт», «Графики», «Тесты и README».

# Пример-аналог

> [!example]- Магазин: отчёт по продажам (другая задача, то же устройство)
> Это **не решение** твоего проекта: другой сюжет, но то же устройство — числа считаются
> до графиков, каждая картинка строится своей функцией, та же последовательность
> `subplots` → подписи → `tight_layout` → `savefig` → `close`.
>
> ```python
> """Магазин: отчёт по продажам — числа и три картинки."""
>
> import logging
> from pathlib import Path
>
> import matplotlib
>
> matplotlib.use("Agg")
>
> import matplotlib.pyplot as plt
>
> logger = logging.getLogger("shop")
>
> GOODS = {"ручки": 320, "тетради": 540, "линейки": 180, "блокноты": 260}
> CHECKS = [120, 250, 180, 420, 310, 90, 260, 380, 150, 200, 270, 330]
> PRICE = [10, 15, 20, 25, 30, 35, 40]
> SOLD = [95, 80, 72, 60, 48, 40, 33]
>
>
> def totals() -> dict[str, int]:
>     """Сумма продаж по товарам."""
>     return dict(sorted(GOODS.items(), key=lambda item: item[1], reverse=True))
>
>
> def check_sizes() -> dict[str, int]:
>     """Сколько чеков попали в интервалы по 100 рублей."""
>     buckets = {"до 150": 0, "150–249": 0, "250–349": 0, "350–500": 0}
>     for amount in CHECKS:
>         if amount < 150:
>             buckets["до 150"] += 1
>         elif amount < 250:
>             buckets["150–249"] += 1
>         elif amount < 350:
>             buckets["250–349"] += 1
>         else:
>             buckets["350–500"] += 1
>     return buckets
>
>
> def save_bars(path: Path) -> Path:
>     """Столбцы: продажи по товарам."""
>     data = totals()
>     fig, ax = plt.subplots(figsize=(7, 4))
>     bars = ax.bar(list(data), list(data.values()), color="tab:blue")
>     ax.bar_label(bars, fmt="%d")
>     ax.set_title("Продажи по товарам за неделю")
>     ax.set_ylabel("Штук")
>     ax.set_ylim(0, max(data.values()) * 1.15)
>     fig.tight_layout()
>     fig.savefig(path, dpi=100)
>     plt.close(fig)
>     return path
>
>
> def save_hist(path: Path) -> Path:
>     """Гистограмма: размеры чеков."""
>     fig, ax = plt.subplots(figsize=(7, 4))
>     ax.hist(CHECKS, bins=[0, 100, 200, 300, 400, 500], color="tab:green", rwidth=0.9)
>     ax.set_title("Размеры чеков")
>     ax.set_xlabel("Сумма, руб.")
>     ax.set_ylabel("Чеков")
>     fig.tight_layout()
>     fig.savefig(path, dpi=100)
>     plt.close(fig)
>     return path
>
>
> def save_scatter(path: Path) -> Path:
>     """Точки: цена и сколько купили."""
>     fig, ax = plt.subplots(figsize=(7, 4))
>     ax.scatter(PRICE, SOLD, s=70, color="tab:orange", edgecolor="black")
>     ax.set_title("Цена и спрос")
>     ax.set_xlabel("Цена, руб.")
>     ax.set_ylabel("Продано, штук")
>     ax.set_ylim(0, 100)
>     fig.tight_layout()
>     fig.savefig(path, dpi=100)
>     plt.close(fig)
>     return path
> ```
>
> Точка входа — сначала числа, потом картинки:
>
> ```python
> def main() -> None:
>     """Печатает числа и сохраняет три графика."""
>     logging.basicConfig(level=logging.INFO, format="%(levelname)s %(message)s")
>     out = Path("out")
>     out.mkdir(exist_ok=True)
>     data = totals()
>     print("Продажи по товарам:", ", ".join(f"{name} — {count}" for name, count in data.items()))
>     print("Чеков всего:", len(CHECKS), "| средний чек:", round(sum(CHECKS) / len(CHECKS), 2))
>     print("Размеры чеков:", check_sizes())
>     print("дорогие товары (30–40 руб.) продаются хуже:", sum(SOLD[4:]) < sum(SOLD[:3]))
>     for saver in (save_bars, save_hist, save_scatter):
>         path = saver(out / f"{saver.__name__.removeprefix('save_')}.png")
>         logger.info("сохранено: %s, %d байт", path, path.stat().st_size)
> ```
>
> Запуск:
>
> ```text
> Продажи по товарам: тетради — 540, ручки — 320, блокноты — 260, линейки — 180
> Чеков всего: 12 | средний чек: 246.67
> Размеры чеков: {'до 150': 2, '150–249': 3, '250–349': 5, '350–500': 2}
> дорогие товары (30–40 руб.) продаются хуже: True
> INFO сохранено: out/bars.png, 18095 байт
> INFO сохранено: out/hist.png, 15903 байт
> INFO сохранено: out/scatter.png, 17267 байт
> ```
>
> Обрати внимание на **устройство**: числа считаются обычным Python до всякого Matplotlib;
> каждая функция рисует ровно одну картинку и закрывает фигуру; размеры файлов логируются —
> по ним сразу видно, что график не пустой. У тебя будет то же самое, только про оценки.

# Если застрял

| Симптом | Куда смотреть |
|---|---|
| `TypeError: Object of type int64 is not JSON serializable` при сохранении файла | [[00. NumPy]]: значения NumPy нужно приводить к `float`/`int` |
| Файл картинки пустой или весит 0 байт | [[08. Графики в проекте]]: `savefig` должен идти **до** `plt.close(fig)` |
| Подписи обрезаны | [[01. Первый график]]: вызови `fig.tight_layout()` перед `savefig` |
| Тест открывает окно с графиком | [[08. Графики в проекте]]: `matplotlib.use("Agg")` в `conftest.py` до импорта `pyplot` |
| `INFO Using categorical units to plot a list of strings…` | Подписи недель `"1"…"4"` похожи на числа — Matplotlib сообщает, что считает их категориями. Не ошибка; чтобы сообщение не мешало, возьми подписи вида `"нед. 1"` |
| Столбцы выглядят «неправильно» | [[03. Столбцы, гистограммы, точки]]: проверь `set_ylim(0, 5)` — без нуля столбцы врут |
| `ModuleNotFoundError: No module named 'report'` | [[09. Структура проекта и модули]]: запуск из корня с `PYTHONPATH=src` |
| `mypy` ругается на `list[int]` в словаре | [[02. Типизация и аннотации]]: аннотируй словарь целиком, а не отдельные значения |

# Типичные ошибки

| Ошибка | Чем плоха |
|---|---|
| Рисовать графики до проверки чисел | красивая картинка с неверными числами выглядит убедительно |
| `plt.show()` в скрипте | в консоли окна нет, программа «виснет» или ничего не сохраняет |
| Забыть `plt.close(fig)` | в цикле по ученикам фигуры накапливаются и программа тормозит |
| Хардкодить путь `"average.png"` в каждой функции | нельзя сохранить в `tmp_path` и собрать все картинки в `out/` |
| Проверять в тесте «картинка точно как эталон» | тест ломается от версии Matplotlib и шрифтов |
| `set_ylim(4, 5)` у столбцов | разница 4.62 и 4.12 превращается в «пропасть» |
| Коммитить папку `out/` | результаты раздувают репозиторий и устаревают |
