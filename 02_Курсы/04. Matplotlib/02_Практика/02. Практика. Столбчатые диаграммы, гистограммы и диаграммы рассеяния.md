# 02. Практика. Столбчатые диаграммы, гистограммы и диаграммы рассеяния

> [!abstract] Цель и задачи практического занятия
> **Цель:** отработать выбор и оформление `bar`/`hist`/`scatter` по вопросу — сравнение, распределение, связь.
> **Задачи:** построить `bar` с `bar_label` и осью от нуля; собрать `hist(bins=[1.5,…], rwidth=0.9)` с проверкой `counts.sum()==32`; нанести `scatter(s=80, edgecolor="black")` + `axhline(mean)` и корреляцию; обосновать отказ от `pie`.
>
> *Пояснение для начинающих (для чайника):* столбцы — для «кто выше?», гистограмма — для «как часто?», точки — для «вместе ли растут?»; подпись на столбце экономит глаз от угадывания высоты.
>
> ```mermaid
> flowchart LR
>   A[данные<br>категории] --> B[bar<br>сравнение]
>   B --> C[hist<br>распределение]
>   C --> D[scatter<br>связь]
> ```
> [!important] Как работать с задачей
> 1. Сначала своя попытка, разбор — потом.
> 2. Сравнивай **вид**: где столбцы, где гистограмма, где точки.
> 3. Проверяй числами: `counts.sum()` и `mean` должны совпасть с графиком.
> 4. Смотри глазами: подписи читаются? `bar_label` не наезжает?

## Задача 1. Столбцы: сравнение предметов

★☆☆ · `bar`, `bar_label`, шкала от нуля

**Условие.** Средние баллы по трём предметам:

```python
subjects = ["Python", "Математика", "Физика"]
averages = [4.4, 4.1, 3.7]
```

**Задание.** 1) Построй столбчатую диаграмму. 2) Подпиши значения прямо на столбцах
с одним знаком после запятой. 3) Сделай шкалу от 0 до 5, заголовок «Средний балл
по предметам» и подпись оси «Балл». 4) Сделай так, чтобы «Физика» отличалась цветом.
5) Объясни, почему для столбцов шкала обязательно начинается с нуля.

> [!example]- Разбор
> **Идея.** Столбцы сравнивают величины: длина столбца должна быть пропорциональна
> значению, поэтому ноль обязателен. Подписи значений избавляют читателя от сверки
> с осью.
>
> **Код.**
>
> ```python
> import matplotlib
>
> matplotlib.use("Agg")
> import matplotlib.pyplot as plt
>
> subjects = ["Python", "Математика", "Физика"]
> averages = [4.4, 4.1, 3.7]
>
> fig, ax = plt.subplots(figsize=(7, 4.5))
> bars = ax.bar(subjects, averages, color=["tab:blue", "tab:blue", "tab:red"])
> ax.set_title("Средний балл по предметам")
> ax.set_ylabel("Балл")
> ax.set_ylim(0, 5)
> ax.bar_label(bars, fmt="%.1f")
> fig.tight_layout()
> fig.savefig("bars.png", dpi=100)
> ```
>
> **Что здесь важно.** `fmt="%.1f"` печатает ровно один знак после запятой: 4.4, 4.1, 3.7.
> Цвета списком позволяют выделить один столбец, не перестраивая данные.
> `set_ylim(0, 5)` оставляет место над столбцами — подписи не липнут к рамке.
>
> **Типичная ошибка.** Задать `set_ylim(3.5, 4.5)`: тогда «Физика» выглядит «почти
> на нуле», а разница между 4.4 и 4.1 — как пропасть. Вторая ошибка — подписывать ось
> «Значение» без единиц.
>
> **Граница.** Если предметов больше 8 или названия длинные, столбцы лучше сделать
> горизонтальными: `ax.barh(subjects, averages)` — подписи читаются слева направо.

## Задача 2. Гистограмма оценок

★★☆ · `hist`, `bins`, проверка чисел

**Условие.** Оценки учеников за контрольную:

```python
marks = [5, 5, 4, 5, 3, 4, 5, 2, 5, 4, 4, 5, 5, 3, 4]
```

**Задание.** 1) Построй гистограмму с границами по целым оценкам: 1.5, 2.5, 3.5, 4.5, 5.5.
2) Сделай столбики чуть уже (`rwidth=0.9`). 3) Выведи числа по интервалам и границы,
   проверь, что сумма равна количеству оценок. 4) Озаглавь график и подпиши оси
   («Оценка», «Число учеников»).

> [!example]- Разбор
> **Идея.** Гистограмма показывает, как распределены значения. Границы по «серединам»
> между оценками (1.5, 2.5, …) превращают интервалы в «двойки», «тройки» и так далее.
> `hist` возвращает всё нужное для проверки: числа, границы и прямоугольники.
>
> **Код.**
>
> ```python
> import matplotlib
>
> matplotlib.use("Agg")
> import matplotlib.pyplot as plt
>
> marks = [5, 5, 4, 5, 3, 4, 5, 2, 5, 4, 4, 5, 5, 3, 4]
>
> fig, ax = plt.subplots(figsize=(7, 4.5))
> counts, edges, _ = ax.hist(
>     marks,
>     bins=[1.5, 2.5, 3.5, 4.5, 5.5],
>     color="tab:purple",
>     rwidth=0.9,
> )
> ax.set_title("Распределение оценок за контрольную")
> ax.set_xlabel("Оценка")
> ax.set_ylabel("Число учеников")
> fig.tight_layout()
> fig.savefig("hist.png", dpi=100)
>
> print("границы:", edges)
> print("числа по интервалам:", counts)
> print("сумма:", counts.sum(), "| оценок всего:", len(marks))
> ```
>
> **Вывод:**
>
> ```text
> границы: [1.5 2.5 3.5 4.5 5.5]
> числа по интервалам: [1. 2. 5. 7.]
> сумма: 15.0 | оценок всего: 15
> ```
>
> **Что здесь важно.** Читается так: одна двойка, две тройки, пять четвёрок, семь пятёрок.
> Сумма совпала с числом оценок — значит, данные попали в интервалы полностью, ничего
> не потеряно. `counts` — массив NumPy, поэтому `.sum()` работает сразу.
>
> **Типичная ошибка.** Оставить `bins=10`: оценки «размажутся» по десяти узким интервалам,
> и вместо «сколько пятёрок» получится шум. Вторая ошибка — не проверить сумму.
>
> **Граница.** Если оценок станет 200, границы по целым останутся верными, а вот интервалы
> для других данных (например, времени решения задачи) подбирают по смыслу: слишком узкие
> дают «гребёнку», слишком широкие прячут форму распределения.

## Задача 3. Точки: связь величин

★★★ · `scatter`, средняя линия, вывод по графику

**Условие.** Часы подготовки в неделю и средний балл:

```python
hours = [1, 2, 3, 4, 5, 6, 7, 8]
score = [2.5, 3.0, 3.4, 3.9, 4.1, 4.3, 4.4, 4.5]
```

**Задание.** 1) Построй диаграмму рассеяния: точки крупные, с обводкой. 2) Добавь
горизонтальную линию среднего балла и подпиши её в легенде. 3) Подпиши оси
(«Часов в неделю», «Балл») и сделай шкалу 2–5. 4) Ответь, есть ли связь между величинами
и какая. 5) Объясни, почему по этому графику нельзя утверждать, что причина именно
в часах.

> [!example]- Разбор
> **Идея.** Рассеяние показывает связь: чем больше часы, тем выше балл — точки
> выстраиваются почти по прямой. Но «связь» не равна «причина»: возможно, старательные
> ученики и занимаются больше, и учатся лучше по другим причинам.
>
> **Код.**
>
> ```python
> import matplotlib
>
> matplotlib.use("Agg")
> import matplotlib.pyplot as plt
> import numpy as np
>
> hours = np.array([1, 2, 3, 4, 5, 6, 7, 8])
> score = np.array([2.5, 3.0, 3.4, 3.9, 4.1, 4.3, 4.4, 4.5])
>
> fig, ax = plt.subplots(figsize=(7, 4.5))
> ax.scatter(hours, score, s=80, color="tab:orange", edgecolor="black", label="ученики")
> ax.axhline(score.mean(), color="gray", linestyle=":", label=f"средний балл {score.mean():.2f}")
> ax.set_title("Часы подготовки и балл")
> ax.set_xlabel("Часов в неделю")
> ax.set_ylabel("Балл")
> ax.set_ylim(2, 5)
> ax.grid(True, linestyle=":", alpha=0.5)
> ax.legend(loc="lower right")
> fig.tight_layout()
> fig.savefig("scatter.png", dpi=100)
>
> print("средний балл:", round(float(score.mean()), 2))
> print("корреляция:", round(float(np.corrcoef(hours, score)[0, 1]), 2))
> ```
>
> **Вывод:**
>
> ```text
> средний балл: 3.76
> корреляция: 0.96
> ```
>
> **Что здесь важно.** Числа поддерживают вывод: средний балл 3.76, корреляция 0.96 —
> связь сильная и положительная. Линия среднего помогает увидеть, кто выше, кто ниже
> среднего уровня. `size=80` и `edgecolor="black"` делают точки заметными.
>
> **Типичная ошибка.** Писать в заголовке «больше часов → выше балл» как вывод о причине.
> Корректная формулировка: «чем больше часов подготовки, тем выше балл **в этих данных**».
> Вторая ошибка — считать корреляцию, когда точек пять: на маленьких выборках она случайна.
>
> **Граница.** `np.corrcoef` — из курса [[00. NumPy]]; если он ещё не пройден, пропусти
> эту строку, вывод по картинке останется тем же. Если точки накладываются (много учеников
> с одинаковыми значениями), добавь `alpha=0.5` — станет видно плотность.

# Подробный разбор практики — выбор типа и проверка числами

## Задача 1 — bar + bar_label

```python
import matplotlib; matplotlib.use("Agg"); import matplotlib.pyplot as plt
subjects=["Python","Матем","Физика"]; means=[4.6,4.1,3.8]
fig, ax = plt.subplots()
bars=ax.bar(subjects, means, color="tab:blue", edgecolor="black")
ax.bar_label(bars, fmt="%.2f", padding=3)
ax.set_ylim(0,5); ax.set_ylabel("Средний балл")
fig.tight_layout(); fig.savefig("bar.png"); plt.close(fig)
# без 0–5 столбцы 4.6 vs 3.8 выглядели бы в 6 раз выше
```

`rwidth` — ширина столбца гистограммы, `barh` — когда подписи длинные.

## Задача 2 — hist + bins

```python
import numpy as np, matplotlib; matplotlib.use("Agg"); import matplotlib.pyplot as plt
marks=np.array([3]*4+[4]*16+[5]*12)
fig, ax=plt.subplots()
counts,bins,patches=ax.hist(marks, bins=[1.5,2.5,3.5,4.5,5.5], rwidth=0.9, edgecolor="black")
print(counts, counts.sum(), bins)  # 4,16,12 sum 32
ax.set_xticks([2,3,4,5]); ax.set_xticklabels(["2","3","4","5"])
fig.savefig("hist.png"); plt.close(fig)
```

`bins=[1.5,2.5,3.5,4.5,5.5]` — корзины ровно под оценки `2,3,4,5`; `rwidth=0.9` — зазор.

## Задача 3 — scatter + axhline

```python
hours=np.array([2,5,7,10]); marks=np.array([3.2,4.0,4.5,5])
fig, ax=plt.subplots()
ax.scatter(hours, marks, s=80, color="tab:orange", edgecolor="black", alpha=0.8)
ax.axhline(marks.mean(), color="gray", linestyle="--", label=f"среднее {marks.mean():.2f}")
ax.set_xlabel("Часы"); ax.set_ylabel("Балл"); ax.legend()
corr=np.corrcoef(hours, marks)[0,1]
ax.set_title(f"r={corr:.2f}")
fig.savefig("scatter.png"); plt.close(fig)
```

`s=80` — размер, `edgecolor="black"` — контур для контраста, `corr` — проверка связи.

# Что запомнить из практики

| Приём | Когда |
|---|---|
| `ax.bar(...)`, `ax.barh(...)` | сравнение категорий |
| `ax.bar_label(bars, fmt="%.1f")` | значения на столбцах |
| `ax.set_ylim(0, …)` | честная шкала для столбцов |
| `ax.hist(..., bins=[...])` | распределение по заданным интервалам |
| `counts, edges, _ = ax.hist(...)` | проверить числами |
| `ax.scatter(..., s=..., edgecolor=...)` | связь двух величин |
| `ax.axhline(...)` | средний уровень или порог |
