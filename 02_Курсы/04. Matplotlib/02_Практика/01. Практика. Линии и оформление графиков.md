# 01. Практика. Линии и оформление графиков

> [!abstract] Цель и задачи практического занятия
> **Цель:** закрепить базовую цепочку `Figure→Axes→plot→savefig` и оформление линий.
> **Задачи:** построить график из списков с `marker="o"` и проверить пиксели `640×480`; наложить 2–4 линии с разными `color/linestyle/marker`, `legend`+`grid`, честная ось `0–5`; добавить `annotate` лучшего результата и проверить `dpi`/`figsize`.
>
> *Пояснение для начинающих (для чайника):* первая картинка — как первый блин: проверить, что бэкенд `Agg` не открывает окно, а файл действительно 640×480; легенда — подписи, без них линии безымянны.
>
> ```mermaid
> flowchart LR
>   A[списки<br>days/marks] --> B[plot<br>marker o]
>   B --> C[легенда<br>legend]
>   C --> D[сохранение<br>savefig]
> ```
> [!important] Как работать с задачей
> 1. Начни с `matplotlib.use("Agg")` **до** импорта `pyplot`.
> 2. Своя попытка — потом разбор.
> 3. Открывай сохранённый файл и смотри на него глазами: подписи не наехали? числа читаются?
> 4. Сравнивай размеры файлов и пиксели: это показывает, как работают `dpi` и `figsize`.

## Задача 1. Первый график из списков

★☆☆ · `subplots`, `plot`, `savefig`, размер картинки

**Условие.** Есть список дней и список баллов:

```python
days = [1, 2, 3, 4, 5]
marks = [3, 4, 4, 5, 5]
```

**Задание.** 1) Построй график баллов по дням с маркерами-кружками. 2) Добавь заголовок
«Баллы по дням» и подписи осей «День» и «Балл». 3) Сохрани в `marks.png` с `dpi=100`.
4) Выведи размер получившейся картинки в пикселях и вес файла. 5) Объясни, откуда взялись
именно такие числа.

> [!example]- Разбор
> **Идея.** Размер картинки — это `figsize` (в дюймах), умноженный на `dpi`. По умолчанию
> фигура 6.4×4.8 дюйма и 100 точек на дюйм — значит, 640×480 пикселей.
>
> **Код.**
>
> ```python
> import os
> import struct
>
> import matplotlib
>
> matplotlib.use("Agg")
> import matplotlib.pyplot as plt
>
> days = [1, 2, 3, 4, 5]
> marks = [3, 4, 4, 5, 5]
>
> fig, ax = plt.subplots()
> ax.plot(days, marks, marker="o")
> ax.set_title("Баллы по дням")
> ax.set_xlabel("День")
> ax.set_ylabel("Балл")
> fig.savefig("marks.png", dpi=100)
>
> with open("marks.png", "rb") as file:
>     head = file.read(24)
> width, height = struct.unpack(">II", head[16:24])
> print("пиксели:", width, "×", height, "| байт:", os.path.getsize("marks.png"))
> ```
>
> **Вывод:**
>
> ```text
> пиксели: 640 × 480 | байт: 24282
> ```
>
> **Что здесь важно.** `fig, ax = plt.subplots()` создаёт фигуру и область осей; дальше
> почти всё делается через `ax`. Числа 640×480 — это 6.4 × 100 и 4.8 × 100.
> Вес файла (около 24 КБ) зависит от содержимого картинки, а не только от размера.
>
> **Типичная ошибка.** Ставить `matplotlib.use("Agg")` после `import matplotlib.pyplot`:
> переключение всё же произойдёт, но созданные фигуры закроются. Вторая ошибка — забыть `savefig` и удивляться, что файла нет.
>
> **Граница.** При `dpi=150` те же 6.4×4.8 дюйма дадут 960×720 пикселей, а файл станет
> тяжелее. `figsize` меняет форму картинки, `dpi` — «плотность» пикселей.

## Задача 2. Две линии и честная шкала

★★☆ · легенда, стили линий, `set_ylim`

**Условие.** Баллы двух предметов по неделям:

```python
weeks = ["1", "2", "3", "4"]
python_marks = [3.5, 4.0, 4.5, 4.8]
math_marks = [4.2, 4.0, 4.4, 4.6]
```

**Задание.** 1) Построй два графика на одних осях: Python — сплошная с кружками,
математика — пунктир с квадратами. 2) Добавь легенду в правом нижнем углу и сетку.
3) Сделай шкалу от 0 до 5 и озаглавь «Средний балл по неделям, шкала 0–5».
4) Построй вторую картинку с той же данными, но со шкалой 3–5, и объясни, чем она хуже.
5) Посчитай, какую долю высоты графика занимает разница 0.7 балла в обоих случаях.

> [!example]- Разбор
> **Идея.** Одна и та же разница выглядит по-разному в зависимости от пределов оси.
> На шкале 0–5 разрыв 0.7 балла — 14 % высоты, на шкале 3–5 — уже 35 %.
> Обрезанная ось делает разницу в 2.5 раза «страшнее».
>
> **Код.**
>
> ```python
> import matplotlib
>
> matplotlib.use("Agg")
> import matplotlib.pyplot as plt
>
> weeks = ["1", "2", "3", "4"]
> python_marks = [3.5, 4.0, 4.5, 4.8]
> math_marks = [4.2, 4.0, 4.4, 4.6]
>
> fig, ax = plt.subplots(figsize=(7, 4.5))
> ax.plot(weeks, python_marks, marker="o", linestyle="-", color="tab:blue", label="Python")
> ax.plot(weeks, math_marks, marker="s", linestyle="--", color="tab:orange", label="Математика")
> ax.set_title("Средний балл по неделям, шкала 0–5")
> ax.set_ylabel("Балл")
> ax.set_ylim(0, 5)
> ax.grid(True, linestyle=":", alpha=0.6)
> ax.legend(loc="lower right")
> fig.tight_layout()
> fig.savefig("honest.png", dpi=100)
>
> # та же картинка со шкалой 3–5
> ax.set_ylim(3, 5)
> ax.set_title("Средний балл по неделям, шкала 3–5")
> fig.savefig("cropped.png", dpi=100)
>
> gap = math_marks[0] - python_marks[0]
> print(f"разница Python и Математика на 1-й неделе: {gap:.1f} балла")
> print(f"на шкале 0–5 это {gap / 5 * 100:.1f} % высоты графика")
> print(f"на шкале 3–5 — {gap / 2 * 100:.1f} % высоты")
> ```
>
> **Вывод:**
>
> ```text
> разница Python и Математика на 1-й неделе: 0.7 балла
> на шкале 0–5 это 14.0 % высоты графика
> на шкале 3–5 — 35.0 % высоты
> ```
>
> **Что здесь важно.** Легенда берёт подписи из `label`; цвета `tab:blue` и `tab:orange`
> различимы и в большинстве случаев дальтонизма. Стиль линии (`-` против `--`)
> и маркер (`o` против `s`) спасут картинку в чёрно-белой печати.
>
> **Типичная ошибка.** Оставить шкалу «как получилось» и получить драму на ровном месте.
> Вторая ошибка — задать `set_ylim(3, 5)` и не написать об этом в подписи.
>
> **Граница.** Иногда обрезанная ось оправдана: например, при сравнении двух методов,
> которые оба «в диапазоне 4.0–4.2». Но тогда это указывают в заголовке или подписи,
> а не оставляют читателя догадываться.

## Задача 3. Оформление «для печати»

★★★ · стили линий, маркеры, аннотация, `dpi=150`

**Условие.** Четыре предмета, баллы по неделям:

```python
series = {
    "Python": [3.5, 4.0, 4.5, 4.8],
    "Математика": [4.2, 4.0, 4.4, 4.6],
    "Физика": [3.0, 3.5, 4.0, 4.2],
    "Информатика": [4.0, 4.1, 4.2, 4.5],
}
```

**Задание.** 1) Нарисуй четыре линии, у каждой — свой цвет, стиль и маркер.
2) Сделай легенду в две колонки. 3) Найди лучший результат среди всех предметов
и недель и подпиши его стрелкой. 4) Сохрани картинку с `dpi=150` и `tight_layout()`.
5) Проверь, что график понятен человеку, который не знает задачи: что по осям, в каких
единицах, где лучший результат.

> [!example]- Разбор
> **Идея.** Для печати нужны различия не только по цвету, поэтому у каждой линии —
> свои стиль и маркер. Аннотация показывает главный вывод графика; поиск лучшего значения
> делается кодом, а не глазами.
>
> **Код.**
>
> ```python
> import os
>
> import matplotlib
>
> matplotlib.use("Agg")
> import matplotlib.pyplot as plt
>
> weeks = ["1", "2", "3", "4"]
> series = {
>     "Python": ([3.5, 4.0, 4.5, 4.8], "-", "o", "tab:blue"),
>     "Математика": ([4.2, 4.0, 4.4, 4.6], "--", "s", "tab:orange"),
>     "Физика": ([3.0, 3.5, 4.0, 4.2], ":", "^", "tab:green"),
>     "Информатика": ([4.0, 4.1, 4.2, 4.5], "-.", "D", "tab:red"),
> }
>
> fig, ax = plt.subplots(figsize=(8, 4.5))
> for name, (values, style, marker, color) in series.items():
>     ax.plot(weeks, values, linestyle=style, marker=marker, color=color, label=name)
> ax.set_title("Средний балл по неделям (для печати)")
> ax.set_xlabel("Неделя")
> ax.set_ylabel("Балл")
> ax.set_ylim(2.5, 5)
> ax.grid(True, linestyle=":", alpha=0.5)
> ax.legend(loc="lower right", ncol=2)
>
> best = max(
>     ((value, name, week) for name, (values, *_) in series.items() for week, value in zip(weeks, values)),
>     key=lambda item: item[0],
> )
> ax.annotate(
>     f"лучший: {best[1]} ({best[0]})",
>     xy=(best[2], best[0]),
>     xytext=("2", 4.9),
>     arrowprops={"arrowstyle": "->", "color": "black"},
> )
> fig.tight_layout()
> fig.savefig("print.png", dpi=150)
> print("лучший результат:", best)
> print("print.png:", os.path.getsize("print.png"), "байт")
> ```
>
> **Вывод:**
>
> ```text
> лучший результат: (4.8, 'Python', '4')
> print.png: 79894 байт
> ```
>
> **Что здесь важно.** Словарь «имя → (значения, стиль, маркер, цвет)» позволяет добавить
> пятый предмет одной строкой. Поиск максимума через `max(...)` не ошибается, в отличие
> от «на глаз». Файл при `dpi=150` весит около 80 КБ — это нормально для картинки в отчёте.
>
> **Типичная ошибка.** Рисовать четыре линии только цветом и без легенды: в чёрно-белой
> печати получится «серый клубок». Вторая ошибка — подписывать лучший результат вручную
> и перепутать неделю.
>
> **Граница.** Если предметов станет 8–10, одна фигура уже не подходит: нужны отдельные
> графики или сетка областей ([[05. Компоновка графиков. Сетки subplot и двойные оси]]). И помни: аннотация — не замена
> подписям осей.

# Подробный разбор практики — на что смотреть глазами и числами

## Задача 1 — 640×480 и Agg

```python
import matplotlib; matplotlib.use("Agg"); import matplotlib.pyplot as plt
from pathlib import Path; from PIL import Image
fig, ax = plt.subplots()  # figsize 6.4,4.8 dpi 100 → 640×480
ax.plot([1,2,3],[2,3,4], marker="o")
ax.set_title("Баллы"); fig.savefig("marks.png", dpi=100); plt.close(fig)
w,h = Image.open("marks.png").size
print(w,h, Path("marks.png").stat().st_size)
# если Agg после pyplot — бэкенд переключится, но фигуры закроются: проверяй порядок
```

Почему `use` до `pyplot` — см. лекцию 01. Проверь `matplotlib.get_backend() == "Agg"`.

## Задача 2 — честная ось и легенда

```python
fig, ax = plt.subplots()
ax.plot([1,2,3],[4.5,4.6,4.7], color="tab:blue", linestyle="--", marker="o", label="А")
ax.plot([1,2,3],[4.4,4.5,4.6], color="tab:orange", linestyle=":", marker="s", label="Б")
ax.set_ylim(0,5)  # честная, иначе рост в 5 раз преувеличен
ax.legend(loc="upper left"); ax.grid(True, alpha=0.3)
fig.tight_layout(); fig.savefig("two.png"); plt.close(fig)
```

Маркеры `o`/`s` различают линии в ч/б; `grid(alpha=0.3)` — не забивает данные.

## Задача 3 — аннотация и размер для печати

```python
fig, ax = plt.subplots(figsize=(8,4.5))
ax.plot([1,2,3,4,5],[3,4,4,5,5], marker="o")
ax.annotate("лучший: 5", xy=(5,5), xytext=(3,5.2), arrowprops=dict(arrowstyle="->"))
ax.set_title("Динамика"); fig.savefig("print.png", dpi=150, bbox_inches="tight"); plt.close(fig)
# dpi 150 — для печати, bbox_inches обрезает поля
```

Чек-лист перед сверкой:
☐ `use("Agg")` до `pyplot` и `640×480` совпало?
☐ `legend` есть и не перекрывает?
☐ `set_ylim(0,5)` честная?
☐ `annotate` со стрелкой видна и `dpi` 150 тяжелее `dpi 100`?

# Что запомнить из практики

| Приём | Когда |
|---|---|
| `fig, ax = plt.subplots()` | всегда: фигура и область отдельно |
| `marker`, `linestyle`, `color` | несколько линий на одних осях |
| `label` + `ax.legend()` | больше одной линии |
| `ax.grid(True, linestyle=":", alpha=0.5)` | чтобы читались значения |
| `ax.set_ylim(0, …)` | честные шкалы для сравнения |
| `ax.annotate(...)` | показать главный вывод графика |
| `fig.tight_layout()` перед `savefig` | подписи не наезжают |
| `dpi=100` / `150` | экран / документ и печать |
