# 04. Арифметика и broadcasting

> [!abstract] О чём лекция
> В NumPy операция над массивом — это операция над **каждым** элементом сразу: `a + 5` прибавляет пятёрку ко всем, `a + b` складывает поэлементно. Когда формы не совпадают, NumPy пытается «растянуть» меньшую — это **broadcasting**. Здесь — правила формы, примеры и ошибки, которые ловят `shape`.
>
> После лекции вы напишете `prices * 1.1 + 5` вместо цикла и прочтёте `ValueError: operands could not be broadcast` как подсказку.

# Поэлементные операции

```python
import numpy as np

a = np.array([1, 2, 3, 4])
print("a + 5 =", a + 5)
print("a * 2 =", a * 2)
print("a ** 2 =", a ** 2)
print("a / 2 =", a / 2)

b = np.array([10, 20, 30, 40])
print("a + b =", a + b)
print("a * b =", a * b)
print("np.sqrt(a) =", np.sqrt(a))
```

```text
a + 5 = [6 7 8 9]
a * 2 = [2 4 6 8]
a ** 2 = [ 1  4  9 16]
a / 2 = [0.5 1.  1.5 2. ]
a + b = [11 22 33 44]
a * b = [ 10  40  90 160]
np.sqrt(a) = [1.  1.41 1.73 2.]
```

Все операции — **поэлементно**: `a * b` — не матричное произведение, а `a[0]*b[0], a[1]*b[1]`. Функции `np.sqrt`, `np.sin`, `np.exp`, `np.log` — тоже по каждому элементу.

| Операция | Что делает | Пример |
|---|---|---|
| `a + 5` | прибавить число ко всем | `a + 5` |
| `a * b` | поэлементно | `[1,2]*[10,20]=[10,40]` |
| `a ** 2` | степень каждого | `a ** 2` |
| `a / 2` | деление каждого | `a / 2` |
| `np.sqrt(a)` | корень каждого | `np.sqrt` |

Цикл не нужен — он внутри NumPy на C.

# Broadcasting: правило формы

Что если `a` — `(3,)` а `b` — `(3,1)`? Или `a` — `(4,)` а `b` — число? NumPy сравнивает формы **справа налево**:

```python
a = np.array([1, 2, 3])        # shape (3,)
print("a + 10:", a + 10)        # (3,) и () → (3,)
print("a + np.array([10]):", a + np.array([10]))  # (3,) и (1,) → (3,)

row = np.array([[1, 2, 3]])     # (1,3)
col = np.array([[10],[20],[30]]) # (3,1)
print("row + col:\n", row + col)  # (1,3) и (3,1) → (3,3)
```

```text
a + 10: [11 12 13]
a + np.array([10]): [11 12 13]
row + col:
 [[11 12 13]
 [21 22 23]
 [31 32 33]]
```

Правила:

1. Сравнивать формы справа налево.
2. Если размерности не совпадают — добавить `1` слева к меньшей.
3. Каждое измерение должно либо совпадать, либо быть `1` (тогда его «растягивают»).

Примеры:

| `a` | `b` | Результат | Почему |
|---|---|---|---|
| `(4,)` | `()` скаляр | `(4,)` | скаляр растягивается на все |
| `(4,)` | `(1,)` | `(4,)` | `1 → 4` |
| `(3,4)` | `(4,)` | `(3,4)` | `(4,)` → `(1,4)` → растянуть первую |
| `(1,3)` | `(3,1)` | `(3,3)` | оба растягиваются |
| `(2,3)` | `(2,)` | ошибка | `(2,)` → `(1,2)` — `3` и `2` не совпадают, не `1` |

Ошибка `ValueError: operands could not be broadcast together with shapes (2,3) (2,)` — подсказка: посмотри `shape`.

Частый приём — добавить измерение `None` (`np.newaxis`), чтобы столбец стал матрицей:

```python
a = np.array([1, 2, 3])  # (3,)
print(a[:, None].shape)  # (3,1)
print(a + a[:, None])    # (3,) + (3,1) → (3,3) таблица сумм
```

# Зачем это нужно на практике

Broadcasting экономит создание промежуточных массивов:

```python
prices = np.array([199.9, 249.5, 99.9])
print("наценка 10%:", prices * 1.1)
discounts = np.array([[0, 5, 10]])  # строка
print("три сценария:\n", prices + discounts.T)  # (3,) + (3,1) → (3,3)
```

Нормировка столбцов таблицы (вычесть среднее по каждому столбцу):

```python
table = np.array([[5, 4, 5], [3, 4, 3], [4, 5, 5]], dtype=float)
means = table.mean(axis=0)  # (3,)
print("средние:", means)
print("центрировано:\n", table - means)  # (3,3) - (3,) → (3,3)
```

Без broadcasting — цикл по столбцам; с ним — одна строка.

# Как это делают в проекте

1. **Не пишут циклы по элементам для `+5` — пишут `array + 5`.** В `src/weather/report.py` — `temps_c = (temps_f - 32) * 5/9` — одна строка вместо `for`.

2. **Форму проверяют до расчёта.** `assert prices.shape == discounts.shape` или `assert table.shape[1] == means.size` — как в [[03. Тесты]]: ошибка «не та форма» ловится на входе.

3. **`None` для таблицы сумм.** `a + a[:, None]` — таблица `a[i]+a[j]` без двойного цикла — приём из [[13. Вложенные последовательности]] с вложенными циклами, только теперь без циклов.

4. **Ошибку `broadcast` читают как подсказку.** `shapes (2,3) (2,)` → сравнить справа: `3` и `2` — не `1`, не совпадают → нужен `reshape` или `[:,None]`.

5. **Держат `dtype` стабильным.** `prices * 1.1` — `float64`; `prices + 5` — остаётся `float64`; лишние `astype` не плодят.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «`a * b` — матричное умножение» | Поэлементно; матричное — `a @ b` или `np.matmul` |
| «Broadcasting — это копирование» | Логическое растягивание, без копирования памяти |
| «Любые формы совместятся» | Только если каждое измерение совпадает или `1`; иначе `ValueError` |
| «Скаляр — shape `(1,)`» | Скаляр — `()`, и он совместим с любой формой |
| «`a[:,None]` — лишнее» | Без него `(3,)+(3,)` не даст таблицу `(3,3)` |

# Проверь себя

1. Что делает `np.array([1,2,3]) * 2`?
2. Почему `np.sqrt` работает с массивом?
3. Совместятся ли `shape (3,4)` и `(4,)`?
4. Что делает `a[:, None]` и зачем?
5. Как прочитать ошибку `could not be broadcast`?

> [!success]- Ответы
> 1. Умножает каждый элемент на 2 — `[2 4 6]`.
> 2. Это векторизованная функция — применяет `sqrt` к каждому элементу.
> 3. Да: `(4,)` → `(1,4)`, первая `1→3` — результат `(3,4)`.
> 4. Добавляет измерение: `(3,)` → `(3,1)` — чтобы `a + a[:,None]` дала таблицу.
> 5. Сравнить формы справа налево: найти измерение, где не `1` и не совпадает.
