# 06. Логические маски и фильтрация

> [!abstract] О чём лекция
> Маска — это массив `bool` той же формы, что и данные: `grades > 4` → `[False True False]`. По маске выбирают нужные элементы без цикла `for` с `if`. Здесь — как строить маски, комбинировать (`&`/`|`/`~`), выбирать `np.where`, сортировать отобранное и фильтровать строки таблицы.
>
> После лекции ты заменишь `if` в цикле на `grades[grades > 4]` и не перепутаешь `and` с `&`.

# Маска — это массив `bool`

```python
import numpy as np

grades = np.array([5, 4, 3, 5, 4, 3, 5])
print("grades > 4:", grades > 4)
print("grades == 5:", grades == 5)
mask = grades >= 4
print("mask:", mask, mask.dtype)
print("отобраны:", grades[mask])
print("сколько:", mask.sum(), "доля:", mask.mean().round(2))
```

```text
grades > 4: [ True False False  True False False  True]
grades == 5: [ True False False  True False False  True]
mask: [ True  True False  True  True False  True] bool
отобраны: [5 4 5 4 5]
сколько: 5 доля: 0.71
```

Маска той же `shape`, что и `grades`, но `dtype=bool`. `grades[mask]` — новый массив только из `True`. `mask.sum()` считает `True` как `1` — число отобранных; `mask.mean()` — долю.

| Операция | Что даёт |
|---|---|
| `a > 4` | маска `bool` |
| `a[mask]` | элементы где `True` — копия |
| `mask.sum()` | сколько `True` |
| `mask.mean()` | доля `True` |
| `a[a > 4] = 0` | запись по маске (меняет исходный) |

# Комбинирование условий — `&`, `|`, `~` вместо `and`/`or`

```python
temps = np.array([ -5, 0, 7, 12, 3, -2])
print("в диапазоне 0..10:", temps[(temps >= 0) & (temps <= 10)])
print("вне диапазона:", temps[(temps < 0) | (temps > 10)])
print("не холодно:", temps[~(temps < 0)])
```

```text
в диапазоне 0..10: [0 7 3]
вне диапазона: [-5 12 -2]
не холодно: [ 0  7 12  3]
```

Важно: для массивов нужны **поэлементные** `&`/`|`/`~`, а не `and`/`or`/`not` (последние работают только с одним `bool`). Скобки обязательны: `a > 0 & a < 10` прочитается как `a > (0 & a) < 10` и даст ошибку.

# `np.where`: выбор значений, а не индексов

```python
scores = np.array([2.5, 3.0, 4.5, 3.9, 4.8])
print("where >4:", np.where(scores > 4, scores, 0))
print("индексы где:", np.where(scores > 4)[0])
print("тернарно:", np.where(scores >= 4, "зачёт", "незачёт"))
```

```text
where >4: [0.  0.  4.5 0.  4.8]
индексы где: [2 4]
тернарно: ['незачёт' 'незачёт' 'зачёт' 'незачёт' 'зачёт']
```

- `np.where(mask, x, y)` — как тернарный оператор по всему массиву: где `True` — `x`, иначе `y`.
- `np.where(mask)` — индексы, где `True` (кортеж массивов по осям).

# Сортировка отобранного и `argsort`

```python
grades = np.array([5, 4, 3, 5, 4])
good = grades[grades >= 4]
print("отобраны:", good)
print("отсортированы:", np.sort(good))
print("argsort:", np.argsort(grades))
print("по argsort:", grades[np.argsort(grades)])
print("unique:", np.unique(grades, return_counts=True))
```

```text
отобраны: [5 4 5 4]
отсортированы: [4 4 5 5]
argsort: [2 1 4 0 3]
по argsort: [3 4 4 5 5]
unique: (array([3, 4, 5]), array([1, 2, 2]))
```

`argsort` возвращает **порядок индексов**, а не значения — удобно сортировать таблицу по одному столбцу.

# Фильтрация строк таблицы

```python
data = np.array([[5, 4, 5], [3, 4, 3], [4, 5, 5], [2, 3, 2]])
mask = data[:, 0] >= 4  # первая оценка >=4
print("mask по строкам:", mask)
print("строки где:", data[mask])
```

```text
mask по строкам: [ True False  True False]
строки где: [[5 4 5]
 [4 5 5]]
```

Маска по строкам — одномерная `shape (4,)`, а `data` — `(4,3)`; broadcasting не нужен — `data[mask]` выбирает строки.

# Как это делают в проекте

1. **Маска вместо `if` в цикле.** В `src/weather/report.py` — `hot = temps[temps > 30]` вместо `for t in temps: if t>30: hot.append(t)`.

2. **`&`/`|` со скобками.** `mask = (grades >=3) & (grades <=4)` — по условию «тройки и четвёрки»; без скобок — приоритет `&` сломает.

3. **`np.where` для «заменить негодные».** `clean = np.where(scores < 0, 0, scores)` — отрицательные → 0, как валидация.

4. **`argsort` для топа.** `idx = np.argsort(scores)[::-1]; top = scores[idx[:3]]` — три лучших без сортировки исходного.

5. **Запись по маске осторожно.** `grades[grades < 3] = 3` меняет исходный массив; если исходный нужен, сначала делают копию: `work = grades.copy()`, затем `work[work < 3] = 3`.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «`and` для масок» | Нужно `&` поэлементно, с `()` |
| «`a[mask]` — вид» | Это копия — `shares_memory` `False` |
| «`np.where` всегда индексы» | С тремя аргументами — значения, с одним — индексы |
| «Маска меняет исходный» | Выбор `a[mask]` — нет; присваивание `a[mask]=0` — да |
| «Сортировка портит исходный» | `np.sort` возвращает копию; `a.sort()` — на месте |

# Проверь себя

1. Что такое маска и что даст `grades > 4`?
2. Почему `&` а не `and` для двух условий?
3. Чем `np.where(mask, x, y)` отличается от `np.where(mask)`?
4. Как посчитать долю `True` в маске?
5. Как выбрать строки таблицы, где первый столбец `>=4`?

> [!success]- Ответы
> 1. Массив `bool` той же формы; `grades` → `[True False …]`.
> 2. `&` — поэлементно по массивам; `and` — для одного `bool`.
> 3. Первое — выбор значений (`x` где `True`, `y` где `False`), второе — индексы где `True`.
> 4. `mask.mean()` — `True` как `1`.
> 5. `mask = data[:,0] >=4; data[mask]`.
