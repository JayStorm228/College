# 06. Логические маски и фильтрация

> [!abstract] О чём лекция
> Сравнение массива с числом даёт массив `True`/`False` — **маску**. Маску можно подставить
> в квадратные скобки, и получится отфильтрованный массив. Это главный инструмент работы
> с данными в NumPy: «оставить те строки, где условие истинно» без единого `if`.
>
> Здесь — маски, комбинирование условий (`&`, `|`, `~`), функция `np.where`,
> подсчёт и сортировка отфильтрованного.

# Маска — это массив

```python
import numpy as np

marks = np.array([5, 2, 4, 5, 3, 2, 4])
mask = marks >= 4
print("маска:", mask)
print("хорошие оценки:", marks[mask])
print("двойки:", marks[marks == 2])
print("сколько хороших:", mask.sum(), "доля:", mask.mean())
```

```text
маска: [ True False  True  True False False  True]
хорошие оценки: [5 4 5 4]
двойки: [2 2]
сколько хороших: 4 доля: 0.5714285714285714
```

Приём, который стоит запомнить: `True` в арифметике — это `1`, а `False` — `0`.
Поэтому `mask.sum()` считает «сколько подходит», а `mask.mean()` — долю.

# Комбинирование условий

```python
print("и-или:", marks[(marks >= 3) & (marks <= 4)])
print("отрицание:", marks[~(marks == 5)])
```

```text
и-или: [4 3 4]
отрицание: [2 4 3 2 4]
```

| Оператор | Смысл | Пример |
|---|---|---|
| `&` | и | `marks >= 3 & marks <= 4` — «от трёх до четырёх» |
| `\|` | или | `marks == 2 \| marks == 5` — «двойки и пятёрки» |
| `~` | не | `~(marks == 5)` — «всё, кроме пятёрок» |

> [!warning] Скобки обязательны
> Писать `marks >= 3 & marks <= 4` нельзя: `&` имеет больший приоритет, чем сравнение, и
> выражение посчитается не так, как читается. Скобки вокруг **каждого** условия — правило.
> К тому же `and` и `or` из Python здесь не работают: они вычисляют одно значение,
> а нужны операторы для массивов.

# `np.where`: выбор значений

```python
print("where:", np.where(marks >= 4, "зачёт", "долг"))
print("индексы хороших:", np.where(marks >= 4)[0])
print("условная замена:", np.where(marks < 3, 3, marks))
```

```text
where: ['зачёт' 'долг' 'зачёт' 'зачёт' 'долг' 'долг' 'зачёт']
индексы хороших: [0 2 3 6]
условная замена: [5 3 4 5 3 3 4]
```

`np.where(условие, значение_если_да, значение_если_нет)` — «тернарный оператор сразу
для всего массива». Если второй аргумент не указан, возвращается массив **индексов**,
где условие истинно: `np.where(marks >= 4)[0]` → `[0 2 3 6]`.

Сравни с фильтрацией: `marks[marks >= 4]` даёт **значения**, `np.where(...)[0]` — **позиции**.
Позиции нужны, когда есть другой массив той же длины (имена учеников), и хочется узнать,
кто именно подошёл:

```python
names = np.array(["Аня", "Борис", "Вика", "Гена"])
print("кто получил 5:", names[marks[:4] == 5])
```

```text
кто получил 5: ['Аня' 'Гена']
```

# Сортировка отобранного

```python
print("сортировка оценок:", np.sort(marks))
print("аргументы сортировки:", np.argsort(marks))
print("топ-3:", np.sort(marks)[-3:])
```

```text
сортировка оценок: [2 2 3 4 4 5 5]
аргументы сортировки: [1 5 4 2 6 0 3]
топ-3: [4 5 5]
```

`np.argsort(marks)` даёт **порядок индексов**: самая низкая оценка — у элемента 1,
потом 5, и так далее. Это способ отсортировать связанные данные:

```python
names = np.array(["Аня", "Борис", "Вика", "Гена", "Даша", "Егор", "Жанна"])
order = np.argsort(marks)[::-1]
print("оценки по убыванию:", marks[order])
print("имена в том же порядке:", names[order])
```

```text
оценки по убыванию: [5 5 4 4 3 2 2]
имена в том же порядке: ['Гена' 'Аня' 'Жанна' 'Вика' 'Даша' 'Егор' 'Борис']
```

Так решается классическая задача: «вывести учеников по убыванию балла», не теряя связь
между именем и оценкой. `[::-1]` разворачивает порядок индексов: по умолчанию `argsort`
сортирует по возрастанию.

# Фильтрация двумерных данных

```python
table = np.array([[5, 4, 5], [3, 4, 3], [5, 5, 2]])
print("отличники (средний балл >= 4.5):", table[table.mean(axis=1) >= 4.5])
```

```text
отличники (средний балл >= 4.5): [[5 4 5]]
```

Порог 4.5 прошёл только первый ученик: его среднее — `4.67`, у третьего — ровно `4.0`.

В фильтре стоит маска **по строкам** (`axis=1` даёт по одному значению на строку),
поэтому результат — отобранные строки. Если бы маска была по элементам,
получился бы один плоский список значений.

# Как это делают в проекте

1. **Строят маску один раз, если она нужна дважды.** `mask = data > 0` и дальше
   `data[mask]`, `mask.sum()` — читается лучше, чем повторять условие.
2. **Помнят про скобки и `&` вместо `and`.** Это самые частые ошибки при фильтрации.
3. **Проверяют, что фильтр не опустошил данные.** `if filtered.size == 0` перед `mean`
   избавляет от `nan` ([[05. Агрегаты и оси]]).
4. **Используют `np.where` для замены, а не для фильтра** — когда результат должен быть
   той же формы, что вход.
5. **Помнят, что фильтрация создаёт копию** ([[03. Индексация, срезы и представления]]):
   изменение отобранного не меняет исходный массив.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «`marks > 4 and marks < 5` сработает» | Нужны `&` и скобки; `and` работает только с одиночными значениями |
| «`np.where` фильтрует» | `np.where` строит новый массив той же формы; для фильтра — маска в скобках |
| «`mask.sum()` — количество `True`» | Да, и `mask.mean()` — доля `True` |
| «Фильтр меняет исходный массив» | Фильтрация возвращает копию |
| «`argsort` сортирует массив» | Он возвращает индексы; сортирует `np.sort` |

# Проверь себя

1. Что вернёт `np.array([5, 2, 4]) > 3`?
2. Как отфильтровать оценки «от 3 до 4 включительно»?
3. Чем `np.where(mask)` отличается от `np.where(mask, a, b)`?
4. Как узнать долю учеников с оценкой 5?
5. Как отсортировать имена по убыванию оценок?

> [!success]- Ответы
> 1. `[ True False  True]`.
> 2. `marks[(marks >= 3) & (marks <= 4)]`.
> 3. Без второго аргумента — возвращает индексы, где условие истинно; с аргументами —
>    массив значений той же формы.
> 4. `(marks == 5).mean()`.
> 5. `order = np.argsort(marks)[::-1]`, затем `names[order]`.
