# 08. Векторизация и скорость

> [!abstract] О чём лекция
> Векторизация — это привычка писать вычисления «целиком по массиву», а не поэлементно
> в цикле. Здесь — сколько это даёт на самом деле, как генерировать случайные данные
> воспроизводимо (`default_rng`) и какие конструкции чаще всего тормозят код.

# Цикл против массива

```python
import timeit

import numpy as np

rng = np.random.default_rng(seed=42)
rows = 200_000
data = rng.normal(4, 1, rows)

by_loop = timeit.timeit("total = 0.0\nfor value in data: total += value", globals={"data": data}, number=1)
by_numpy = timeit.timeit("total = data.sum()", globals={"data": data}, number=1)
```

```text
цикл: 0.0119 с
numpy: 0.000158 с
быстрее в 75 раз
```

Разница в 75 раз — на одной строке кода. Дальше — важный вывод: **в Python цикл по массиву
означает отказ от NumPy.** Правило простое: если пишешь `for` по элементам массива,
скорее всего есть векторный вариант.

| Задача | Цикл | Векторно |
|---|---|---|
| сумма | `for x in a: total += x` | `a.sum()` |
| прибавить число | `for i in range(len(a)): a[i] += 5` | `a + 5` |
| только положительные | цикл с `if` | `a[a > 0]` |
| среднее по строкам | двойной цикл | `a.mean(axis=1)` |
| нормировка | цикл по столбцам | `a / a.max(axis=0)` |

# Случайные числа: воспроизводимость

```python
rng = np.random.default_rng(seed=42)
print("целые 1..5:", rng.integers(1, 6, size=8))
print("дробные:", np.round(rng.random(4), 3))
print("нормальное, среднее 4, отклонение 1:", np.round(rng.normal(4, 1, 5), 2))
print("выбор из списка:", rng.choice(["Аня", "Борис", "Вика"], size=3))
print("перемешивание:", rng.permutation(np.arange(1, 6)))
```

```text
целые 1..5: [1 4 4 3 3 5 1 4]
дробные: [0.094 0.976 0.761 0.786]
нормальное, среднее 4, отклонение 1: [3.98 3.15 4.88 4.78 4.07]
выбор из списка: ['Борис' 'Вика' 'Борис']
перемешивание: [2 1 4 5 3]
```

Что здесь важно:

1. **`np.random.default_rng(seed=...)` — современный способ.** Устаревший `np.random.seed`
   и функции `np.random.*` оставлены для совместимости; новый генератор называют «rng».
2. **`seed` делает результат воспроизводимым.** Один и тот же `seed` — одни и те же числа
   на любой машине. Это обязательно для тестов и отчётов.
3. **`integers(1, 6)` — правый конец не входит**, как в `range`. Чтобы получить оценки
   от 1 до 5, пишут `integers(1, 6)`.

Основные методы генератора:

| Метод | Что даёт |
|---|---|
| `rng.integers(low, high, size)` | целые в диапазоне `[low, high)` |
| `rng.random(size)` | дробные в `[0, 1)` |
| `rng.normal(mean, std, size)` | нормальное распределение |
| `rng.choice(items, size)` | случайный выбор из набора |
| `rng.permutation(array)` | перестановка (копия) |
| `rng.shuffle(array)` | перемешивание **на месте** |

# Реалистичный пример: оценки класса

```python
grades = np.clip(np.round(rng.normal(4, 1, 12)), 1, 5).astype(int)
print("оценки:", grades)
print("средний балл:", grades.mean().round(2))
print("отличников:", int((grades == 5).sum()))
mask = grades >= 4
print("успеваемость:", f"{mask.mean():.0%}")
```

```text
оценки: [5 5 4 5 3 4 4 4 3 3 3 4]
средний балл: 3.92
отличников: 3
успеваемость: 67%
```

Разберём цепочку `np.clip(np.round(rng.normal(4, 1, 12)), 1, 5).astype(int)`:

1. `rng.normal(4, 1, 12)` — 12 «оценок» со средним 4 и разбросом 1 (может выйти 2.7 или 6.1);
2. `np.round(...)` — округляем до целых (получаются `float`, например `5.0`);
3. `np.clip(..., 1, 5)` — обрезаем всё, что вышло за пределы шкалы;
4. `.astype(int)` — превращаем в целые.

Одна строка — вместо цикла с проверками. Это и есть векторизация: **идея читается
в последовательности операций, а не в теле цикла.**

# Что замедляет код чаще всего

| Причина | Как выглядит | Что делать |
|---|---|---|
| цикл по элементам | `for i in range(len(a))` | векторные операции |
| `np.append` в цикле | `a = np.append(a, x)` | заранее известная длина или список |
| создание массива в цикле | `np.array([...])` внутри | собрать список, один `np.array` в конце |
| `if` внутри цикла по массиву | `if a[i] > 0` | маска: `a[a > 0]` |
| лишний `astype`/`copy` | копии на каждой итерации | приводить тип один раз |
| повторный расчёт | `a.mean()` в цикле | вынести за цикл ([[13. Сложность и производительность]]) |

> [!note] Векторизация не всегда выигрывает
> Если данные маленькие (десятки чисел) или логика сложная (разные действия для разных
> случаев), цикл может оказаться понятнее — и это нормально. Векторизация нужна там, где
> объём данных большой, а действие одинаковое. И помни: временные массивы занимают память.
> Иногда «в лоб» через цикл — экономнее по памяти, чем десять промежуточных массивов.

# Как это делают в проекте

1. **Сначала правильность, потом скорость.** Код на массивах и так быстрее цикла;
   оптимизируют только после замера ([[13. Сложность и производительность]]).
2. **Всегда фиксируют `seed` в тестах.** Иначе тест «иногда» падает.
3. **Держат данные в массивах, а не в списках.** Преобразование списка в массив делают
   один раз на границе (при чтении файла).
4. **Проверяют память.** Для больших данных промежуточный массив размером с исходный —
   это удвоение памяти; иногда лучше считать частями.
5. **Читают ошибки формы как подсказки.** `ValueError: operands could not be broadcast`
   — сообщение не «плохо», а точное: посмотри `shape`.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «NumPy просто ускоряет тот же цикл» | Он выполняет цикл на C, поэтому разница не в процентах, а в разах |
| «Векторизация — это `for ... in np.nditer`» | Это отказ от цикла на Python: операции над массивами целиком |
| «`np.random.seed` и `default_rng` — одно и то же» | Рекомендуемый способ — `default_rng`; глобальный `seed` устаревает |
| «Случайные данные нельзя тестировать» | С фиксированным `seed` — можно: числа воспроизводимы |
| «Чем больше операций в строке, тем быстрее» | Важна векторность, а не краткость записи |

# Проверь себя

1. Почему цикл по массиву NumPy медленный?
2. Как сделать случайные данные воспроизводимыми?
3. Что делает `np.clip(x, 1, 5)`?
4. Что даст `rng.integers(1, 6, size=10)`?
5. Что не так с `a = np.append(a, x)` внутри цикла?

> [!success]- Ответы
> 1. Каждый элемент «вынимается» из массива в объект Python, и цикл выполняется
>    интерпретатором, а не скомпилированным кодом NumPy.
> 2. Фиксировать seed: `rng = np.random.default_rng(seed=42)`.
> 3. Обрезает значения по границам: всё меньше 1 становится 1, всё больше 5 — становится 5.
> 4. Десять целых чисел от 1 до 5 (6 не входит).
> 5. Каждый вызов создаёт новый массив и копирует данные: время растёт квадратично.
>    Нужен список (или заранее известный размер), а `np.array` — один раз в конце.
