# 04. Поэлементные операции и механизм broadcasting

> [!abstract] Цель и задачи лекции
> **Цель:** формализовать поэлементные операции `ndarray` и механизм согласования форм broadcasting.
> **Задачи:** разграничить `a+5`/`a*b`/`a**2`/`sqrt(a)` как векторные операции; сформулировать правило «сравнение форм справа, размер `1` растягивается»; показать приём `a[:,None]` и диагностику `ValueError: could not be broadcast`.
>
> *Пояснение для начинающих (для чайника):* в NumPy `a+5` — «прибавь 5 к каждому» без цикла, `a+b` — поэлементно; если формы разные, меньшую «ксероксят» на большую (broadcasting) без копирования памяти.

---

# Поэлементные операции: семантика

```python
import numpy as np
a = np.array([1,2,3,4])
print(a+5)   # [6 7 8 9] — 5 к каждому
print(a*2)   # [2 4 6 8]
print(a**2)  # [1 4 9 16]
print(a/2)   # [0.5 1. 1.5 2.]
b = np.array([10,20,30,40])
print(a+b)   # [11 22 33 44] — поэлементно, не матрично!
print(np.sqrt(a).round(2))  # [1. 1.41 1.73 2.]
```

| Для чайника | Что | Пример |
|---|---|---|
| `a+5` | число ко всем | `a+5` |
| `a*b` | поэлементно | `[1,2]*[10,20]=[10,40]` |
| `a**2` | степень каждому | `a**2` |
| `np.sqrt(a)` | корень каждому | `sqrt([1,4,9])→[1.2.3.]` |

Цикл внутри NumPy на C — ты пишешь одну строку.

> `a*b` — **не** матричное! Матричное — `a@b` (лекция 09).

# Механизм broadcasting: правило согласования форм

```mermaid
flowchart LR
  A[(3,)<br>1 2 3] --> C[(3,3)<br>растянули]
  B[(3,1)<br>10<br>20<br>30] --> C
  C --> D[11 12 13<br>21 22 23<br>31 32 33]
```

Сравни формы **справа налево**:

1. Добавь `1` слева к меньшей пока размерностей поровну.
2. Каждое измерение: совпадает или `1` → `1` растягивается (ксерокс) без копии памяти.

Иллюстративные примеры:

| `a` | `b` | Что делает | Результат |
|---|---|---|---|
| `(4,)` | `()` скаляр | растягивает скаляр | `(4,)` |
| `(4,)` | `(1,)` | `1→4` | `(4,)` |
| `(3,4)` | `(4,)` | `(4,)→(1,4)` `1→3` | `(3,4)` |
| `(1,3)` | `(3,1)` | оба растягиваются | `(3,3)` |
| `(2,3)` | `(2,)` | `(2,)→(1,2)` `3≠2` не `1` | **ошибка** |

Диагностика `ValueError: could not be broadcast` (пояснение для начинающих): смотри справа `3` vs `2` — не `1` и не равны → не растянется. Подсказка, а не баг.

Приём `[:,None]` — добавить ось, сделать столбец:

```python
a = np.array([1,2,3])  # (3,)
print(a[:,None].shape)  # (3,1) — столбец
print(a + a[:,None])    # (3,)+(3,1)→(3,3) таблица сумм
# [[2 3 4][3 4 5][4 5 6]] — a[i]+a[j] без двойного for
```

Для чайника: `(3,)` — полоска, `(3,1)` — столбик, вместе — таблица.

# Практическая значимость

**Наценка:**

```python
prices = np.array([199.9, 249.5, 99.9])
print(prices*1.1)  # [219.89 274.45 109.89] — без цикла
```

**Три сценария скидки:**

```python
discounts = np.array([[0,5,10]])  # (1,3)
print(prices - discounts.T)  # (3,) - (3,1) → (3,3)
# [[199.9 249.5 99.9][194.9 244.5 94.9][189.9 239.5 89.9]] — скидка 0/5/10 на каждую
```

**Центрирование таблицы (вычесть среднее столбца):**

```python
table = np.array([[5,4,5],[3,4,3],[4,5,5]], dtype=float)
means = table.mean(axis=0)  # (3,) [4. 4.33 4.33]
print(np.round(table - means,2).tolist())
# [[1.,-0.33,0.67],[-1.,-0.33,-1.33],[0.,0.67,0.67]] — (3,3)-(3,)→(3,3)
```

Без broadcasting — цикл по столбцам, с ним — одна строка.

# Рекомендации по применению в проектах

1. **Не цикл для `+5` — `arr+5`.** `temps_c = (temps_f-32)*5/9` — одна строка.
2. **Проверяй `shape` до.** `assert table.shape[1]==means.size` — ловит `broadcast` на входе.
3. **`[:,None]` для таблицы.** `a + a[:,None]` — `a[i]+a[j]` без `for`.
4. **Ошибку `broadcast` читай справа:** `3` vs `2` не `1` → нужен `reshape`.
5. **`dtype` стабилен.** `float64` остаётся `float64`.

# Типичные заблуждения

| Думают | На самом деле |
|---|---|
| `a*b` матричное | Поэлементно; матричное `a@b` |
| Broadcasting копирует | Ксерокс без копии памяти |
| Любые формы совместятся | Только `1` или совпадает |
| Скаляр `(1,)` | Скаляр `()` — совместим со всеми |
| `[:,None]` лишнее | Без него `(3,)+(3,)→(3,)` не таблица |

# Вопросы для самопроверки

1. Что `np.array([1,2,3])*2`?
2. Почему `np.sqrt` с массивом?
3. `(3,4)+(4,)` совместятся?
4. Что `a[:,None]`?
5. Как читать `could not broadcast`?

> [!success]- Ответы
> 1. Каждый ×2 → `[2 4 6]`.
> 2. Векторизована — каждому.
> 3. Да `(4,)→(1,4)` `1→3` → `(3,4)`.
> 4. `(3,)→(3,1)` столбик для таблицы.
> 5. Справа налево найди несовпадение не `1`.
