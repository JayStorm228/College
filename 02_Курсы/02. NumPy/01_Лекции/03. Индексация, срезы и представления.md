# 03. Индексация, срезы и представления

> [!abstract] О чём лекция
> Обращение к элементам массива похоже на списки, но с тремя важными отличиями:
> индексы можно перечислять списком, маску (`a > 5`) можно подставить прямо в квадратные
> скобки, а **срез не копирует данные** — это «вид» на тот же блок памяти.
>
> Третье отличие — источник самых неприятных ошибок: правишь срез, а «неожиданно» меняется
> исходный массив. Здесь разбирается, когда так и задумано, а когда нужна копия.

# Индексы и срезы

```python
import numpy as np

a = np.array([10, 20, 30, 40, 50])
print("первый:", a[0], "последний:", a[-1])
print("срез 1:4:", a[1:4])
print("шаг 2:", a[::2])
print("обратный порядок:", a[::-1])
```

```text
первый: 10 последний: 50
срез 1:4: [20 30 40]
шаг 2: [10 30 50]
обратный порядок: [50 40 30 20 10]
```

Правила те же, что у списков: правый конец не входит, `-1` — последний элемент,
`step` может быть отрицательным.

# Два измерения

```python
matrix = np.array([[1, 2, 3], [4, 5, 6]])
print("строка 0:", matrix[0])
print("элемент [1, 2]:", matrix[1, 2])
print("столбец 1:", matrix[:, 1])
print("без первой строки и первого столбца:\n", matrix[1:, 1:])
```

```text
строка 0: [1 2 3]
элемент [1, 2]: 6
столбец 1: [2 5]
без первой строки и первого столбца:
 [[5 6]]
```

Ключ к двумерным массивам — запятая: `matrix[строка, столбец]`. Двоеточие означает «все»:
`matrix[:, 1]` — все строки второго столбца.

| Запись | Что получается |
|---|---|
| `matrix[0]` | вся первая строка |
| `matrix[:, 0]` | весь первый столбец |
| `matrix[1, 2]` | число |
| `matrix[:, :]` | весь массив |
| `matrix[::-1, :]` | строки в обратном порядке |

# Выбор по списку индексов и по маске

```python
a = np.array([10, 20, 30, 40, 50])
print("выбор по списку индексов:", a[[0, 2, 4]])
print("маска:", a[a > 25])
```

```text
выбор по списку индексов: [10 30 50]
маска: [30 40 50]
```

`a[[0, 2, 4]]` — «взять элементы 0, 2 и 4»; список индексов **создаёт копию**.
`a[a > 25]` — «взять те, где условие истинно»; подробнее об этом в
[[06. Логические маски и фильтрация]].

# Срез — это вид, а не копия

```python
part = a[1:4]
part[0] = 999
print("после правки среза:", a)
print("срез — это вид:", part.base is a)
```

```text
после правки среза: [ 10 999  30  40  50]
срез — это вид: True
```

Правка `part` изменила `a`: срез не хранит своих данных, а смотрит на те же числа.
Так сделано ради скорости: копировать миллион значений только чтобы «посмотреть» —
слишком дорого.

Когда нужна настоящая копия, её просят явно:

```python
copy = a[[1, 2]]          # выбор по списку индексов — уже копия
copy[0] = -1
print("после правки копии:", a, copy)
print("у копии нет base:", copy.base is None)
```

```text
после правки копии: [ 10 999  30  40  50] [-1 30]
у копии нет base: True
```

| Получено так | Что это | Меняет исходный массив при правке? |
|---|---|---|
| `a[1:3]` (срез) | вид | **да** |
| `a[[1, 2]]` (список индексов) | копия | нет |
| `a[a > 25]` (маска) | копия | нет |
| `a.reshape(...)` | вид | да |
| `a.copy()` | копия | нет |
| `a.flatten()` | копия | нет |

> [!tip] Как проверить, вид это или копия
> Атрибут `.base`: если он не `None`, массив — вид на другой массив.
> Второй способ: `np.shares_memory(a, b)` возвращает `True`, если данные общие.

# Зачем нужны виды

Виды экономят память и время. Полезные примеры:

```python
data = np.arange(12).reshape(3, 4)
print("вся вторая строка:", data[1])
print("каждый второй элемент:\n", data[:, ::2])
column = data[:, 1]
print("вид на столбец (общая память):", np.shares_memory(data, column))
```

```text
вся вторая строка: [4 5 6 7]
каждый второй элемент:
 [[ 0  2]
 [ 4  6]
 [ 8 10]]
вид на столбец (общая память): True
```

| Приём | Что делает |
|---|---|
| `data[:, 1]` | вид на столбец (не копирует) |
| `data[data > 5]` | копия отфильтрованных значений |
| `data.copy()` | полная копия, когда нужна независимость |
| `np.shares_memory(a, b)` | проверка, общие ли данные |

# Как это делают в проекте

1. **Помнят про вид и случайно не портят данные.** Если нужна независимая копия —
   `.copy()` пишут явно, даже если кажется, что «и так скопируется».
2. **Не индексируют массивы в цикле.** `for i in range(len(a)): a[i]` медленно
   и чаще всего заменяется векторизацией ([[08. Векторизация и скорость]]).
3. **Используют `[:, 1]` для столбцов, но помнят: строки — копия, столбцы — вид.**
   Точнее, `data[1]` (строка) — тоже вид; «копией» становится только выбор по списку
   или маске.
4. **Читают `shape` после среза.** `data[:, 1]` даёт форму `(3,)`, а не `(3, 1)` —
   это две разные формы, и при сложении они ведут себя по-разному.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «Срез копирует, как в списках» | Срез — вид; данные общие |
| «Маска копирует, но это неважно» | Маска копирует, и это важно: изменение результата не затронет исходник |
| «`reshape` копирует» | Возвращает вид, когда это возможно |
| «`a[1]` и `a[1:2]` — одно и то же» | Формы разные: `(4,)` и `(1, 4)` |
| «`a[[0, 0]]` вернёт два разных элемента» | Вернёт один и тот же элемент дважды |

# Проверь себя

1. Что выведет `a[::2]` для `a = np.array([0, 1, 2, 3, 4, 5])`?
2. Как получить весь второй столбец матрицы?
3. Что произойдёт с исходным массивом, если изменить срез?
4. Как проверить, что два массива используют общую память?
5. Чем `a[1]` отличается от `a[1:2]` для двумерного массива?
6. Какой способ индексации даёт копию: срез, список индексов или маска?

> [!success]- Ответы
> 1. `[0 2 4]`.
> 2. `matrix[:, 1]`.
> 3. Изменится: срез — это вид на те же данные.
> 4. `np.shares_memory(a, b)` — самый надёжный способ. Атрибут `.base` показывает,
>    что это вид, но может указывать не на тот массив, с которым вы сравниваете.
> 5. `a[1]` — форма `(4,)` (строка), `a[1:2]` — форма `(1, 4)` (таблица из одной строки).
> 6. Список индексов и маска; срез — вид.
