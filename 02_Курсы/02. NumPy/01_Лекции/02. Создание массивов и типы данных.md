# 02. Создание массивов и типы данных

> [!abstract] О чём лекция
> Массив можно получить пятью способами: из готовых данных, «нулями», «единицами», диапазоном и равномерной сеткой. Здесь — все пять, плюс тип элементов (`dtype`) и приведение типов, которое чаще всего ломает ожидания новичка: `astype` не округляет, а отбрасывает дробную часть.
>
> После лекции ты выберешь правильный способ создать массив под задачу и не потеряешь данные на приведении типов.

# Пять способов получить массив

```python
import numpy as np

print("из списка:", np.array([3, 1, 2]))
print("нули 4:", np.zeros(4))
print("единицы 2×3:\n", np.ones((2, 3)))
print("диапазон 0..10 шаг 2:", np.arange(0, 10, 2))
print("равномерно 5 точек 0..1:", np.linspace(0, 1, 5))
print("случайно 3 числа:", np.random.default_rng(42).random(3))
```

```text
из списка: [3 1 2]
нули 4: [0. 0. 0. 0.]
единицы 2×3:
 [[1. 1. 1.]
 [1. 1. 1.]]
диапазон 0..10 шаг 2: [0 2 4 6 8]
равномерно 5 точек 0..1: [0.   0.25 0.5  0.75 1.  ]
случайно 3 числа: [0.77395605 0.43887844 0.85859792]
```

| Функция                           | Что даёт                                     | Типичный случай                     | Запомнить                              |
| --------------------------------- | -------------------------------------------- | ----------------------------------- | -------------------------------------- |
| `np.array(data)`                  | массив из списка/кортежа                     | данные уже есть                     | `dtype` выводится из данных            |
| `np.zeros(shape)`                 | нули                                         | заготовка под накопление результата | `shape` — число или кортеж             |
| `np.ones(shape)`                  | единицы                                      | тесты, начальные значения           | `np.ones((2,3))` — 2 строки, 3 столбца |
| `np.arange(start, stop, step)`    | диапазон, шаг может быть дробным             | счётчики, координаты                | **stop не входит**                     |
| `np.linspace(start, stop, count)` | `count` равномерных точек **включая** `stop` | графики, сетки, шкалы               | задаётся количество точек              |
| `rng.random(size)`                | случайные в `[0,1)`                          | генерация данных                    | `default_rng(seed)` — воспроизводимо   |

Разница `arange` и `linspace` — в последней точке:

```python
print("arange 0..1 шаг 0.25:", np.arange(0, 1, 0.25))
print("linspace 0..1 5 точек:", np.linspace(0, 1, 5))
```

```text
arange 0..1 шаг 0.25: [0.   0.25 0.5  0.75]
linspace 0..1 5 точек: [0.   0.25 0.5  0.75 1.  ]
```

`arange` не включает `1` — как `range` в Python; `linspace` включает — как шкала с концами. Для графиков и сеток почти всегда нужен `linspace`: в нём задаётся **количество точек**, а не шаг, поэтому не бывает «неполного последнего интервала» и не накапливается ошибка дробного шага.

Ещё способы, которые встретятся позже: `np.empty`, `np.full`, `np.eye` (единичная матрица), `np.zeros_like` (нули той же формы).

# Тип элементов: `dtype`

Каждый массив хранит элементы одного типа — `int64`, `float64`, `bool` и т.д.:

```python
marks = np.array([5, 4, 5, 3])
print("целые:", marks, marks.dtype, "размер элемента", marks.itemsize, "байт")
print("вещественные:", marks.astype(float), marks.astype(float).dtype)

print("bool:", np.array([True, False, True]).dtype)
print("строки:", np.array(["Аня", "Борис"]).dtype)
```

```text
целые: [5 4 5 3] int64 размер элемента 8 байт
вещественные: [5. 4. 5. 3.] float64
bool: bool
строки: <U5
```

Основные типы:

| `dtype` | Что хранит | Размер | Пример | Когда |
|---|---|---|---|---|
| `int64` | целые | 8 байт | оценки, индексы, счётчики | по умолчанию для целых |
| `int32` | целые | 4 байта | большие массивы, если числа <2e9 | экономия памяти |
| `float64` | вещественные | 8 байт | среднее, проценты, измерения | по умолчанию для дробных |
| `bool` | `True`/`False` | 1 байт | маски [[06. Логические маски и фильтрация]] | `marks > 4` |
| `<U5` | строки фикс. длины 5 | 20 байт | имена, метки | редко в NumPy |
| `object` | ссылки на объекты | — | всё подряд | почти не используют |

Приведение делается `astype`:

```python
a = np.array([5, 4, 5, 3])
b = a.astype(float)
print("новый:", b, b.dtype, "| исходный не изменился:", a.dtype)

print("обрезание:", np.array([2.7, 2.2]).astype(int))
print("округление:", np.round([2.7, 2.2]).astype(int))
print("деление целых:", np.array([7, 8]) / 2, "| целочисленное:", np.array([7, 8]) // 2)
```

```text
новый: [5. 4. 5. 3.] float64 | исходный не изменился: int64
обрезание: [2 2]
округление: [3 2]
деление целых: [3.5 4. ] | целочисленное: [3 4]
```

Важно: `astype` **создаёт новый массив**, исходный не меняется. И `astype(int)` **отбрасывает** дробную часть, а не округляет — нужно округление, ставь `np.round` до приведения.

# Опасности преобразования типов

```python
mixed = np.array([1, 2.5, 3])
print("смешанный список:", mixed, mixed.dtype)

print("числа + строки:", np.array([1, "два"]).dtype)
print("числа + None:", np.array([1, None], dtype=object).dtype)

a = np.array([1.5, 2.5])
print("astype(int) без round:", a.astype(int))
```

```text
смешанный список: [1.  2.5 3. ] float64
числа + строки: <U21
числа + None: object
astype(int) без round: [1 2]
```

Две ловушки, которые ловят почти всех:

1. **Один тип на весь массив.** Список с числами и строками ` [1, "два"]` превращается в массив строк `['1', 'два']`, и арифметика с ним перестанет работать (`array * 1.1` даст ошибку). Нужны разные типы — бери `list` или `pandas`.
2. **Потеря точности при приведении.** `np.array([1.5, 2.5]).astype(int)` даёт `[1 2]`: дробная часть просто отброшена. Если нужны целые с округлением — сначала `np.round`, затем `astype(int)`. Но и `np.round` округляет не «школьно»: половинки уходят к ближайшему чётному (`np.round([1.5, 2.5])` даёт `[2. 2.]`, как встроенный `round`). Для денег — округляй до копеек явно и помни об этом правиле.

> [!warning] Целые и деление
> Деление целых в NumPy даёт вещественное: `np.array([7, 8]) / 2` → `[3.5 4.]` (`float64`). А вот `//` даёт целые: `[3 4]`. Путаница между `/` и `//` в расчётах встречается постоянно — проверяй `dtype` результата.

# Размерности и форма `()`

^42cafb

```python
print("2×3:", np.zeros((2, 3)).shape, np.zeros((2, 3)).size, np.zeros((2, 3)).ndim)
print("скаляр:", np.array(5).shape, "ndim", np.array(5).ndim, "size", np.array(5).size)
print("вектор из 1:", np.array([5]).shape, "ndim", np.array([5]).ndim)
```

```text
2×3: (2, 3) 6 2
скаляр: () ndim 0 size 1
вектор из 1: (1,) ndim 1
```

`np.array(5)` — массив **нулевой размерности** `shape ()` (одно число без измерений). Иногда это удобно (результат `sum`), иногда мешает: `shape ()` не равна `(1,)`. Если нужен «вектор из одного числа» — пиши `np.array([5])`, а скаляр — `np.array(5)` или просто `5`.

# Как это делают в проекте

В проекте массив создают один раз, тип выбирают явно, а форму проверяют.

1. **Не создают массивы в цикле с `np.append`.** Вместо `a = np.array([]); for x in data: a = np.append(a, x)` — заранее известная длина или список:

```python
# плохо: квадратично
a = np.array([])
for x in range(1000):
    a = np.append(a, x)

# хорошо: один раз
a = np.zeros(1000, dtype=int)
for i, x in enumerate(range(1000)):
    a[i] = x
# ещё лучше: вообще без цикла
a = np.arange(1000)
```

В `src/weather/data.py` — `np.array(raw, dtype=np.float64)` один раз на границе, дальше — `ndarray`.

2. **Указывают `dtype`, когда важно.** Для счётчиков — `int64`, для экономии — `int32`, для масок — `bool`. Для денег иногда хранят копейки `int64`, чтобы не терять на `float`.

3. **Проверяют `shape` и `dtype` до расчёта.** `assert temps.shape == (30,)` и `assert temps.dtype == np.float64` — как `assert` в [[08. Тесты]]: ошибка «не та форма» ловится на входе, а не `ValueError` в середине `broadcast`.

4. **`linspace` для шкал, `arange` для счётчиков.** Это разные задачи, и выбор виден в коде: `np.linspace(0, 1, 100)` — сетка для графика, `np.arange(len(marks))` — индексы.

5. **Приведение — с `round` и одним `astype`.** `np.round(temps).astype(int)` — округление + приведение за один проход, без потери `0.5` → `0`.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «`np.array` копирует список «как есть»» | Тип приводится к общему: `[1, 2.5]` → `float64`, `[1, "два"]` → строки |
| «`astype(int)` округляет» | Отбрасывает дробную часть; для округления — `np.round` до `astype` |
| «В массиве можно держать разные типы» | Один `dtype` на массив; остальное приводится или `object` (медленно) |
| «`arange(0, 1, 0.25)` включает 1» | Не включает: правый конец всегда исключён, как в `range` |
| «Массив нулевой размерности — то же, что `(1,)`» | Формы `()` и `(1,)` разные: скаляр и вектор из одного элемента |
| «`np.append` в цикле — нормально» | Каждый вызов копирует массив — квадратично; нужен `zeros` или список |

# Проверь себя

1. Чем `np.arange(0, 1, 0.25)` отличается от `np.linspace(0, 1, 5)`?
2. Что вернёт `np.array([1, 2.5, 3]).dtype` и почему?
3. Как превратить массив `int64` в `float64`? Изменится ли исходный массив?
4. Что даст `np.array([2.7, 2.2]).astype(int)` и как получить `[3 2]`?
5. Чем опасен `np.append` в цикле и что использовать вместо него?

> [!success]- Ответы
> 1. Первый задаёт шаг и не включает правый конец: `[0. 0.25 0.5 0.75]`; второй — количество точек и включает: `[0. 0.25 0.5 0.75 1.]`.
> 2. `float64`: тип общий для массива, целое `1` приведено к вещественному, чтобы вместить `2.5`.
> 3. `marks.astype(float)` — создаётся новый массив; исходный не меняется.
> 4. `[2 2]` — дробная часть отброшена; для округления — `np.round([2.7,2.2]).astype(int)` → `[3 2]`.
> 5. Каждый `append` копирует массив — квадратично; нужен `np.zeros(n)` с индексами или `np.arange`, или список с одним `np.array` в конце.
