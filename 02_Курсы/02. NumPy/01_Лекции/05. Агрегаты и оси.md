# 05. Агрегаты и оси

> [!abstract] О чём лекция
> Агрегат — операция, которая превращает много чисел в одно (или в меньшее число):
> сумма, среднее, минимум, максимум, стандартное отклонение.
>
> Главное в лекции — параметр `axis`. Он отвечает на вопрос «сворачиваем по строкам
> или по столбцам», и именно тут чаще всего путаются. После этой лекции
> `table.mean(axis=1)` должно читаться без раздумий.

# Базовые агрегаты

```python
import numpy as np

marks = np.array([5, 4, 5, 3, 4])
print("сумма:", marks.sum(), "среднее:", marks.mean())
print("минимум:", marks.min(), "максимум:", marks.max())
print("разброс:", marks.max() - marks.min())
print("стандартное отклонение:", round(float(marks.std()), 3))
print("медиана:", np.median(marks))
```

```text
сумма: 21 среднее: 4.2
минимум: 3 максимум: 5
разброс: 2
стандартное отклонение: 0.748
медиана: 4.0
```

| Функция | Что считает |
|---|---|
| `a.sum()` | сумма |
| `a.mean()` | среднее арифметическое |
| `a.min()`, `a.max()` | минимум и максимум |
| `a.std()` | стандартное отклонение (разброс) |
| `np.median(a)` | медиана (середина упорядоченного ряда) |
| `np.percentile(a, 25)` | процентиль: значение, ниже которого 25% данных |
| `np.cumsum(a)` | накопленная сумма (не одно число, а массив) |

Обрати внимание: у массива целых чисел `mean()` возвращает **вещественное** число
(`4.2`, тип `float64`), а `median` для целых тоже даёт `4.0`. Это нормально: средние
и медианы почти всегда дробные.

# Оси: `axis=0` и `axis=1`

```python
table = np.array([[5, 4, 5], [3, 4, 3]])
print("среднее по всему:", table.mean())
print("среднее по ученикам (axis=1):", table.mean(axis=1))
print("среднее по предметам (axis=0):", table.mean(axis=0))
```

```text
среднее по всему: 4.0
среднее по ученикам (axis=1): [4.66666667 3.33333333]
среднее по предметам (axis=0): [4. 4. 4.]
```

Правило запоминания: **`axis` — это измерение, которое исчезает.**

| Форма | `axis=None` | `axis=0` | `axis=1` |
|---|---|---|---|
| `(2, 3)` | одно число | форма `(3,)` — по столбцам | форма `(2,)` — по строкам |
| смысл | по всей таблице | «средний балл предмета» | «средний балл ученика» |
| строк в результате | 0 (число) | 3 | 2 |

> [!tip] Как не путать
> `axis=0` — «свернуть первый индекс», то есть строки: остаются столбцы.
> `axis=1` — «свернуть второй индекс», то есть столбцы: остаются строки.
> Если сомневаешься — посмотри на `shape` результата: он показывает, какое измерение
> исчезло.

# Кумулятивные и парные операции

```python
print("сумма с накоплением:", np.cumsum(np.array([1, 2, 3, 4])))
print("кумулятивный максимум:", np.maximum.accumulate(np.array([3, 1, 4, 2, 5])))
```

```text
сумма с накоплением: [ 1  3  6 10]
кумулятивный максимум: [3 3 4 4 5]
```

`np.cumsum` показывает «итог на каждый день» — полезно для графиков и отчётов
по нарастающей. `np.maximum.accumulate` — «рекорд на текущий момент».

Ещё две операции, которые нужны постоянно:

| Операция | Что делает |
|---|---|
| `np.sort(a)` | сортирует (по умолчанию по последней оси) |
| `np.argsort(a)` | даёт **индексы** в порядке сортировки |
| `np.unique(a)` | уникальные значения |
| `np.argmax(a)`, `np.argmin(a)` | индекс максимума и минимума |
| `np.diff(a)` | разности соседних элементов |
| `np.clip(a, low, high)` | «зажимает» значения в границы |

# Пустой массив и предупреждения

```python
empty = np.array([])
print("сумма пустого:", empty.sum())
print("среднее пустого:", empty.mean())
```

```text
сумма пустого: 0.0
RuntimeWarning: Mean of empty slice
среднее пустого: nan
```

`sum` пустого массива — честный ноль, а `mean` не определён: NumPy не поднимает исключение,
а выдаёт `nan` и предупреждение. Это важное отличие от Python-функций: **NumPy предпочитает
`nan`, а не падение.** Проверять такие случаи нужно самому: `if data.size == 0`.

Предупреждение выдаётся стандартным механизмом Python `warnings`, поэтому его можно
превратить в ошибку при отладке:

```python
import warnings

import numpy as np

warnings.simplefilter("error")
np.array([]).mean()
```

```text
RuntimeWarning: Mean of empty slice
```

В обычном коде достаточно явной проверки размера: `if data.size == 0`.

# Как это делают в проекте

1. **Проверяют пустые массивы** перед `mean`, `std`, делением на количество.
2. **Пишут `axis` явно.** Даже если по умолчанию «кажется, что так и надо»: через месяц
   придётся разбираться, по какой оси считалось.
3. **Разделяют «по всей таблице» и «по строкам».** В отчётах это разные числа, и их
   не смешивают в одной переменной.
4. **Помнят про `np.nan`-функции.** Если в данных есть пропуски, обычные `mean`/`sum`
   дадут `nan`; для таких случаев есть `np.nanmean`, `np.nansum` и т. д.
5. **Используют `keepdims=True`**, когда результат усреднения нужно вычесть из исходной
   таблицы: форма `(2, 1)` вместо `(2,)` избавляет от дополнительного `reshape`.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «`axis=0` — это по строкам» | `axis=0` сворачивает строки, результат — по столбцам |
| «`mean` пустого массива даст 0» | Даст `nan` и предупреждение |
| «`median` для целых даст целое» | Обычно `float64`: `4.0` |
| «Одного `mean` достаточно» | Среднее чувствительно к выбросам; смотри и медиану |
| «`sum` и `cumsum` — одно и то же» | `sum` — одно число, `cumsum` — массив накоплений |

# Проверь себя

1. Что даст `table.mean(axis=0)` для таблицы `(2, 3)` и какова форма результата?
2. Как получить средний балл по каждому ученику в таблице «ученики × предметы»?
3. Что вернёт `np.array([]).mean()`?
4. Зачем нужен `np.argsort`?
5. Что делает `keepdims=True`?

> [!success]- Ответы
> 1. Средние по столбцам, форма `(3,)`.
> 2. `axis=1` — сворачиваем столбцы, остаются ученики.
> 3. `nan` (с предупреждением `RuntimeWarning`), а не ошибку и не ноль.
> 4. Даёт индексы в порядке сортировки — например, чтобы переставить массив имён
>    в порядке оценок.
> 5. Сохраняет «свёрнутое» измерение размером 1: результат формы `(2, 1)` вместо `(2,)`.
