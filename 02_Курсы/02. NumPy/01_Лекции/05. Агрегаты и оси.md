# 05. Агрегаты и оси

> [!abstract] О чём лекция
> Агрегат — это свёртка массива в меньший: сумма, среднее, максимум. С параметром `axis` свёртка идёт по одной оси: `sum(axis=0)` — по столбцам, `axis=1` — по строкам. Здесь — базовые агрегаты, оси, `keepdims`, кумулятивные операции и поведение пустых массивов с `seterr`.
>
> После лекции ты посчитаешь среднее по предметам `table.mean(axis=0)` и не потеряешь измерение, когда оно нужно.

# Базовые агрегаты

```python
import numpy as np

marks = np.array([5, 4, 5, 3, 4])
print("sum:", marks.sum(), "mean:", marks.mean(), "std:", marks.std().round(2))
print("min:", marks.min(), "max:", marks.max(), "median:", np.median(marks))

table = np.array([[5, 4, 5], [3, 4, 3], [4, 5, 5]])
print("вся сумма:", table.sum(), "среднее:", table.mean().round(2))
```

```text
sum: 21 mean: 4.2 std: 0.75
min: 3 max: 5 median: 4.0
вся сумма: 38 среднее: 4.22
```

| Функция | Что считает | Без `axis` |
|---|---|---|
| `a.sum()` | сумма | весь массив |
| `a.mean()` | среднее | весь массив |
| `a.std()` | стандартное отклонение | весь массив |
| `a.min()`/`a.max()` | минимум/максимум | весь массив |
| `np.median(a)` | медиана | весь массив (функция, не метод) |

Все они — методы массива, кроме `median`/`percentile` — функции `np.*`.

# Оси: `axis=0` и `axis=1` — тонкость курса

Ось — направление свёртки. Для таблицы `shape (3,3)`:

```python
table = np.array([[5, 4, 5], [3, 4, 3], [4, 5, 5]], dtype=float)
print("столбцы axis=0:", table.sum(axis=0))
print("строки axis=1:", table.sum(axis=1))
print("средние по предметам axis=0:", table.mean(axis=0).round(2))
```

```text
столбцы axis=0: [12. 13. 13.]
строки axis=1: [14. 10. 14.]
средние по предметам axis=0: [4.   4.33 4.33]
```

| `axis` | Что значит | Результат для `(3,3)` |
|---|---|---|
| `None` (по умолчанию) | весь массив | скаляр `shape ()` |
| `0` | «схлопнуть» строки, идти по вертикали | вектор `shape (3,)` — по столбцам |
| `1` | «схлопнуть» столбцы, идти по горизонтали | вектор `shape (3,)` — по строкам |

Мнемоника: `axis=0` — «ноль — вдоль строк», убирает нулевое измерение. На таблице 2×3: `axis=0` → `shape (3,)` (было `(2,3)`), `axis=1` → `(2,)`.

> [!warning] Частая путаница `axis`
> `table.mean(axis=0)` — среднее **по столбцам** (по вертикали), `axis=1` — по строкам. Если перепутать, получишь средние по ученикам вместо средних по предметам. Проверяй `shape` результата: `(3,)` для `axis=0` от `(3,3)` — три предмета.

Кумулятивные и парные: `a.cumsum()`, `a.cumprod()`, `np.maximum(a,b)`.

# `keepdims`: сохранить измерение

Иногда свёртка должна оставить размерность `1`, чтобы broadcasting (растягивание форм при арифметике, лекция 04) сработал:

```python
table = np.array([[5, 4, 3], [2, 4, 6]], dtype=float)  # 2 строки, 3 столбца
means = table.mean(axis=1)                             # средние по строкам
means_k = table.mean(axis=1, keepdims=True)

print("без keepdims:", means.shape, means)
print("с keepdims:", means_k.shape, means_k.tolist())
try:
    table - means
except ValueError as error:
    print("table - means:", type(error).__name__)
print("table - means_k:\n", table - means_k)
```

```text
без keepdims: (2,) [4. 4.]
с keepdims: (2, 1) [[4.0], [4.0]]
table - means: ValueError
table - means_k:
 [[ 1.  0. -1.]
 [-2.  0.  2.]]
```

Что произошло. Форма `(2,)` при вычитании выравнивается по **последней** оси: NumPy пытается вычесть из таблицы `(2, 3)` вектор длиной 2 вдоль столбцов и не может — `ValueError`. Форма `(2, 1)` растягивается вдоль столбцов, и каждая строка теряет своё среднее — получилось центрирование по строкам.

> [!warning] Тихая ошибка на квадратной таблице
> Для таблицы `(3, 3)` выражение `table - table.mean(axis=1)` **не падает**: форма `(3,)` подходит, но вычитается среднее по строкам из **столбцов**, то есть не то, что нужно. `keepdims=True` защищает от этой ошибки: форма `(3, 1)` растягивается только одним правильным способом.

Для `axis=0` (средние по столбцам) форма `(3,)` уже подходит, и `keepdims` нужен, только чтобы результат остался двумерным `(1, 3)`, — например, перед `concatenate`.

# Пустой массив и предупреждения

```python
import warnings

empty = np.array([])
print("size:", empty.size, "sum:", empty.sum())

with warnings.catch_warnings():
    warnings.simplefilter("ignore")
    print("mean пустого:", empty.mean())

with np.errstate(divide="ignore"):
    print("1/0:", np.array([1.0]) / 0)
```

```text
size: 0 sum: 0.0
mean пустого: nan
1/0: [inf]
```

Пустой массив (`size 0`): `sum = 0`, `mean = nan`, и NumPy при этом выдаёт `RuntimeWarning` (в этой лекции он погашен через `warnings.catch_warnings`, иначе он печатается в поток ошибок). Деление на ноль тоже не падает, как в чистом Python: получается `inf` и предупреждение, которое погашено через `np.errstate`. Управлять предупреждениями сразу для всей программы — `np.seterr`, на участке кода — `np.errstate` или `warnings.catch_warnings`. В отчёте пустые данные — это баг на границе, лучше проверить `if arr.size == 0: ...` до агрегата.

# Как это делают в проекте

1. **Среднее по столбцам — `axis=0`, по строкам — `axis=1`.** В `src/weather/report.py` — `temps.mean(axis=0)` для средних по дням месяца, `temps.mean(axis=1)` — по станциям.

2. **`keepdims` когда нужен broadcasting.** `table - table.mean(axis=0, keepdims=True)` — явно, что вычитаем «строку средних».

3. **`size==0` до агрегата.** `if grades.size == 0: return np.nan` — вместо ловли `nan` после.

4. **`mean` vs `median` — выбор по смыслу.** Среднее чувствительно к выбросам, медиана — нет; в отчёте указывают оба.

5. **Кумулятивные для «накоплено».** `np.cumsum(daily)` — накопленные продажи, не цикл.

# Типичные заблуждения

| Заблуждение | Как на самом деле |
|---|---|
| «`axis=0` — по строкам» | `axis=0` — по столбцам (схлопывает строки) — проверяй `shape` |
| «Агрегат всегда скаляр» | С `axis` — массив меньшей размерности |
| «`keepdims` не нужен» | Без него `(3,)` и `(1,3)` ведут себя по-разному в `concatenate` |
| «Пустой массив даст 0 для всех» | `sum=0`, `mean=nan` + warning |
| «`np.median` — метод массива» | Функция `np.median(arr)` |

# Проверь себя

1. Что даст `table.sum(axis=0)` для `shape (3,3)`?
2. Чем `axis=0` отличается от `axis=1`?
3. Зачем `keepdims=True`?
4. Что вернёт `np.array([]).mean()`?
5. Как убрать `RuntimeWarning` для пустого массива?

> [!success]- Ответы
> 1. Суммы по столбцам — вектор `shape (3,)` с тремя числами.
> 2. `0` — свёртка по строкам (по вертикали), `1` — по столбцам (по горизонтали).
> 3. Оставить измерение `1`: `(1,3)` вместо `(3,)` для явного broadcasting и `concatenate`.
> 4. `nan` и `RuntimeWarning` — пустой массив не имеет среднего.
> 5. Проверить `if arr.size==0` до агрегата или `np.seterr`/`warnings.catch_warnings`.
