# 04. Мини-проект. Дневник погоды

> [!abstract] Что это за проект
> Программа, которая генерирует дневник погоды за месяц, сохраняет его в файл и строит
> отчёт: средняя и медианная температура, самый холодный и самый тёплый день, доля дней
> теплее 20 °C, список самых тёплых дней.
>
> Проект собирает всё, что было в курсе: массивы и типы ([[02. Создание массивов и типы данных]]),
> индексацию ([[03. Индексация, срезы и представления]]), агрегаты по осям
> ([[05. Агрегаты и оси]]), маски ([[06. Логические маски и фильтрация]]), воспроизводимые
> случайные данные и векторизацию ([[08. Векторизация и скорость]]).
>
> **Перед началом** стоит пройти практики [[01. Практика. Массивы и индексация]],
> [[02. Практика. Вычисления и маски]] и [[03. Практика. Форма и скорость]].

# Что должно получиться

```text
$ PYTHONPATH=src python3 main.py
INFO сохранено дней: 30
Дней: 30
Средняя: 14.0 °C (медиана 13.4)
Минимум: 4.5 °C (2026-09-03), максимум: 23.1 °C (2026-09-26)
Разброс (std): 3.98
Дней теплее 20 °C: 10%
Самые тёплые дни: 2026-09-26 (23.1), 2026-09-04 (21.0), 2026-09-28 (20.7)
```

И подробный отчёт по дням — началом и концом:

```text
$ REPORT_FORMAT=text PYTHONPATH=src python3 main.py
2026-09-01: 10.0 °C
2026-09-02: 15.4 °C
...
2026-09-30: 14.9 °C
```

Файл `data/temperatures.csv` после запуска:

```text
date;temperature
2026-09-01;10.0
2026-09-02;15.4
...
```

Подсказки по реализации, чтобы не искать:

- **Даты:** `np.array([f"2026-09-{day:02d}" for day in range(1, days + 1)])`.
- **Температуры:** `np.round(rng.normal(14, 5, days), 1)` — средняя 14 °C, разброс 5.
- **Сохранение:** список строк, затем одна запись `Path(...).write_text("\n".join(lines) + "\n")`.
- **Чтение:** пропустить заголовок, разобрать строки, собрать два массива.
- **Связь дат и температур:** массивы одной длины; `zip(..., strict=True)`.

# Как идти

1. **Структура и первый коммит.** Папки, пустые модули с docstring, `.gitignore`,
   короткий `README.md`.
2. **`data.py`.** Сначала `generate` (проверь, что при одном и том же `seed` числа
   повторяются), потом `save` и `load`. После `load` полезно проверить, что данные
   совпадают с сохранёнными: `np.allclose`.
3. **`stats.py`.** Начни со сводки, затем крайние дни и топ. Каждую функцию проверяй
   на маленьком ручном массиве — например, `[10.0, 22.5, 5.0, 18.0]`, где ответы видно
   глазами.
4. **`report.py`.** Два отчёта и реестр; класс `WeatherReport`, который не знает, откуда
   данные, а только вызывает переданную функцию.
5. **`main.py`.** Сгенерировать, сохранить, залогировать, напечатать отчёт.
6. **Настройка.** Добавь чтение `REPORT_FORMAT`: если переменная не задана — `summary`;
   если формат неизвестен — понятная ошибка со списком доступных.
7. **Проверки.** `pytest`, `mypy`, `black --check`, `ruff check`, затем оба запуска —
   и сверь числа со списком ниже.
8. **Коммиты по шагам.** «Структура и генерация данных», «Сохранение и чтение дневника»,
   «Статистика и отчёты», «Настройки, тесты, README».

# Пример-аналог

> [!example]- Дневник пробежек (другая задача, то же устройство)
> Это **не решение** проекта: другой сюжет и другая предметная область, но то же устройство —
> пакет, генерация данных, статистика, реестр отчётов, точка входа.
>
> **Генерация данных:**
>
> ```python
> import numpy as np
>
>
> def generate(days: int = 28, seed: int = 11) -> dict[str, np.ndarray]:
>     """Генерирует дневник пробежек: даты и дистанции в километрах."""
>     rng = np.random.default_rng(seed=seed)
>     dates = np.array([f"2026-09-{day:02d}" for day in range(1, days + 1)])
>     distances = np.round(
>         rng.choice([0.0, 3.0, 5.0, 7.0, 10.0], size=days, p=[0.3, 0.25, 0.25, 0.15, 0.05]),
>         1,
>     )
>     return {"dates": dates, "distances": distances}
> ```
>
> **Статистика:**
>
> ```python
> def average_run(distances: np.ndarray) -> float:
>     """Средняя дистанция по дням, когда бег был."""
>     runs = distances[distances > 0]
>     if runs.size == 0:
>         return 0.0
>     return round(float(runs.mean()), 2)
>
>
> def best_day(dates: np.ndarray, distances: np.ndarray) -> str:
>     """Дата самой длинной пробежки."""
>     return str(dates[int(np.argmax(distances))])
>
>
> def share_of_days(distances: np.ndarray, minimum: float) -> float:
>     """Доля дней с дистанцией не меньше порога."""
>     return float((distances >= minimum).mean())
> ```
>
> **Отчёт и реестр:**
>
> ```python
> def report_summary(dates: np.ndarray, distances: np.ndarray) -> str:
>     """Короткий отчёт: итог, средняя, лучший день."""
>     return "\n".join(
>         [
>             f"Дней с бегом: {int((distances > 0).sum())} из {distances.size}",
>             f"Всего: {total(distances):.1f} км",
>             f"Средняя пробежка: {average_run(distances):.2f} км",
>             f"Лучший день: {best_day(dates, distances)}",
>             f"Дней от 5 км: {share_of_days(distances, 5):.0%}",
>         ]
>     )
>
>
> REPORTS = {"summary": report_summary, "text": report_text}
>
>
> class RunningReport:
>     """Отчёт по дневнику пробежек: данные из источника, формат — из реестра."""
>
>     def __init__(self, source: dict, report):
>         self.source = source
>         self.report = report
>
>     def build(self) -> str:
>         """Возвращает отчёт строкой."""
>         return self.report(self.source["dates"], self.source["distances"])
> ```
>
> **Запуск:**
>
> ```text
> $ PYTHONPATH=src python3 main.py
> Дней с бегом: 19 из 28
> Всего: 94.0 км
> Средняя пробежка: 4.95 км
> Лучший день: 2026-09-21
> Дней от 5 км: 43%
> ```
>
> **Подробный отчёт:**
>
> ```text
> 2026-09-01: 0.0 км
> 2026-09-02: 3.0 км
> 2026-09-03: 5.0 км
> 2026-09-04: 0.0 км
> 2026-09-05: 0.0 км
> ```
>
> Обрати внимание на **устройство**: данные приходят одним словарём, статистика — маленькие
> функции над массивами, отчёт выбирается из реестра, точка входа собирает всё вместе.
> У тебя будет то же самое, только про погоду и с датами, связанными с температурами.

# Если застрял

| Симптом | Куда смотреть |
|---|---|
| **`nan`** в средней температуре | [[05. Агрегаты и оси]]: пустой массив; проверяй `size` |
| Всегда «самый тёплый день» — первый | [[05. Агрегаты и оси]]: `np.max` вместо `np.argmax` — нужен индекс |
| Даты и температуры разъехались | [[06. Логические маски и фильтрация]]: массивы должны быть одной длины |
| Числа меняются от запуска к запуску | [[08. Векторизация и скорость]]: не задан `seed` |
| `ValueError: could not broadcast` | [[04. Арифметика и broadcasting]]: проверь `shape` обоих массивов |
| Долго считает на 100 000 дней | [[08. Векторизация и скорость]]: убери цикл `for` по элементам |

# Типичные ошибки

| Ошибка | Чем плоха |
|---|---|
| `for i in range(len(temperatures))` для статистики | цикл вместо векторизации: медленно и длинно |
| `np.max` вместо `np.argmax` для «лучшего дня» | получаешь температуру, а тебе нужна дата |
| `seed` внутри функции без параметра | нельзя воспроизвести результат и тест невозможно написать |
| Дата строкой «1 сентября» вместо `2026-09-01` | сортировка и сравнение дат ломаются |
| Файл читается в цикле по строкам с `float(row[1])` без проверок | `ValueError` на первой же пустой строке |
| Отчёт формируется прямо в `main()` | нельзя проверить тестом и переиспользовать |
