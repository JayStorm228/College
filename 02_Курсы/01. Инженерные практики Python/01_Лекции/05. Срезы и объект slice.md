# 05. Срезы и объект slice — глубоко, разжёвано для новичка

> [!abstract] О чём лекция
> В базовом курсе срез — запись `items[1:4]` «кусочек списка». Здесь — вся механика: как работают `start:stop:step`, что такое объект `slice` отдельно от скобок, почему срез всегда копия (а не вид как в NumPy), когда срез экономит память, а когда её тратит, и как не наступить на главные ловушки.
> **Ключевая мысль:** срез — не магия скобок, а объект с тремя числами; поняв его, ты читаешь любой `a[::-1]` как формулу.

> [!tip] Что нужно знать заранее
> [[11. Кортежи, списки, словари]] — индексы и поверхностная копия `a[:]`; [[13. Вложенные последовательности]] — копия матрицы `[row[:] for row in matrix]`. Опыт с `range` тоже помогает: срез устроен почти как `range`.

---

# Срез как «окно» с тремя числами

Запись `seq[start:stop:step]` — это три числа, а не «начало и конец»:

| Параметр | Что значит | По умолчанию |
|---|---|---|
| `start` | откуда брать (включая) | 0, если `step>0`, иначе `len-1` |
| `stop` | докуда (не включая) | `len`, если `step>0`, иначе «до -1» |
| `step` | шаг | 1 |

```python
nums = [0, 1, 2, 3, 4, 5]

print(nums[1:4])      # [1, 2, 3] — с 1 по 3
print(nums[:3])       # [0, 1, 2] — от начала до 3
print(nums[3:])       # [3, 4, 5] — от 3 до конца
print(nums[::2])      # [0, 2, 4] — шаг 2
print(nums[::-1])     # [5, 4, 3, 2, 1, 0] — развернуть!
print(nums[4:1:-1])   # [4, 3, 2] — назад
```

Как это читается: `a:b:c` — «возьми `a`, потом `a+c`, `a+2c` ... пока не дойдёшь до `b` (не включая)».

> [!note] Отрицательные индексы
> `-1` — последний, `-2` — предпоследний. В срезе они работают так же: `nums[-3:]` — последние три.

# Объект `slice` отдельно от скобок

Скоба `seq[...]` — синтаксис, а `slice` — объект, который можно хранить и передавать:

```python
# эти две записи делают одно и то же
nums[1:4:2]           # синтаксис
nums[slice(1, 4, 2)]  # объект

# удобно, когда «окно» приходит извне
window = slice(1, 4)
print(nums[window])          # [1, 2, 3]

# slice умеет «поправлять» границы под длину
print(slice(1, 100).indices(5))   # (1, 5, 1) — 100 урезали до 5
```

Где встречается:
- свой тип-как-последовательность (реализуешь `__getitem__(self, key)` — там приходит `slice`);
- передача «окна» в функцию: `def take(data, window: slice): return data[window]`;
- в pandas/NumPy `slice` тоже часть синтаксиса, но там он часто означает «вид», а не копию.

# Срез — всегда копия (в Python), не вид

В чистом Python срез **копирует** верхний уровень:

```python
orig = [1, 2, 3, 4]
copy = orig[1:3]   # [2, 3] — новый список
copy[0] = 99
print(orig)  # [1, 2, 3, 4] — оригинал не изменился
print(copy)  # [99, 3]
```

Это отличие от NumPy, где срез — **вид** (view) на те же данные и изменения видны в оригинале. В инженерном модуле это важно различать:

| Мир | Что делает срез | Цена |
|---|---|---|
| `list`/`str`/`tuple` | копия верхнего уровня | память + время на копирование |
| `numpy.ndarray` | вид (без копирования) | быстро, но изменения видны |

Ловушка с вложенными списками (уже была в [[13. Вложенные последовательности]]):

```python
matrix = [[1, 2], [3, 4]]
shallow = matrix[:]        # копия только верхнего списка
shallow[0][0] = 99
print(matrix)  # [[99, 2], [3, 4]] — вложенный список общий!

deep = [row[:] for row in matrix]  # копия каждого уровня
```

Правило: сколько уровней вложенности — столько срезов/копирований.

# Присваивание срезу — мощный приём

Срезу можно не только читать, но и писать — и даже менять длину списка:

```python
nums = [0, 1, 2, 3, 4, 5]
nums[1:4] = [10, 20]        # заменили кусок 1:4 ([1,2,3]) на 2 элемента
print(nums)  # [0, 10, 20, 4, 5]

nums[2:2] = [99]            # вставка без удаления (пустой срез)
print(nums)  # [0, 10, 99, 20, 4, 5]

nums[3:] = []               # удаление хвоста
del nums[1:3]               # то же, что nums[1:3] = []
```

> [!warning] Срез справа может быть любой итерируемый
> `nums[1:2] = "hi"` вставит `['h','i']`, а не `["hi"]` — потому что строка — итерируема. Хочешь один элемент — оберни в список: `nums[1:2] = ["hi"]`.

# Шаг и отрицательные — граничные случаи

```python
s = "Python"
print(s[::-1])      # "nohtyP" — идиома разворота
print(s[::-2])      # "nhy" — каждый второй назад
print(s[5:1:-1])    # "noht" — с 5 по 2 назад
print(s[:])         # копия строки (строки неизменяемы, но синтаксис работает)
print(s[10:20])     # "" — выход за границы в срезе не ошибка!
```

Главные нюансы:

| Нюанс | Что происходит |
|---|---|
| `seq[100:200]` | не `IndexError`, а пустая последовательность |
| `seq[::0]` | `ValueError: slice step cannot be zero` — единственная ошибка среза |
| `len(seq[::2])` | не `len//2`, а `(len+1)//2` для нечётной длины — не угадывай, считай `len()` после |
| `seq[::-1]` для строки | вернёт новую строку (строки неизменяемы) — нормально |

# Производительность и когда срез дорожает

Срез делает мелкую копию — `O(k)` по размеру среза. На маленьком списке это бесплатно, на миллионах — заметно:

```python
big = list(range(10_000_00))
part = big[1000:2000]   # скопировал 1000 элементов — ~8 КБ для int'ов
# big остался прежним
```

Если нужно только обходить без копии — бери `itertools.islice` (ленивый) или генератор:

```python
from itertools import islice

for x in islice(big, 1000, 2000):   # не копирует, отдаёт по одному
    process(x)

# генераторное выражение — тоже лениво
lazy = (x*x for x in big if x % 2 == 0)
```

Правило новичка: **копируй, когда нужен результат целиком; бери `islice`/генератор, когда нужен только обход.**

# Хорошие практики

**Практика 1. Не хардкодь длину — считай границы.** `data[:n]` лучше `data[0:n]`, `data[-n:]` — последние `n`.

**Практика 2. Для копии — `list(a)` или `a[:]`, но явно.** `a[:]` и `list(a)` — одно и то же; второе читается как «хочу копию».

**Практика 3. Для разворота — `reversed()` быстрее `a[::-1]`, если нужна только итерация.** `reversed(a)` не копирует, `a[::-1]` копирует.

**Практика 4. Не изменяй список во время обхода срезом.** Собирай новый или присваивай срезу после цикла.

**Практика 5. В своём классе поддержи `slice`.** Пример:

```python
class Scores:
    def __init__(self, values):
        self._values = list(values)

    def __getitem__(self, key):
        if isinstance(key, slice):
            return Scores(self._values[key])
        return self._values[key]

s = Scores([1,2,3,4])
print(s[1:3]._values)  # [2, 3]
```

---

# Типичные заблуждения

- ❌ **«`a[1:3]` меняет `a`»** — нет, возвращает новый объект.
- ❌ **«Выход за границы в срезе — ошибка»** — нет, просто пусто или урезается.
- ❌ **«`a[:]` — всегда глубокая копия»** — только верхний уровень, вложенные списки общие.
- ❌ **«Шаг 0 можно»** — нельзя, `ValueError`.
- ❌ **«Срез в NumPy — то же, что в списке»** — там это вид, здесь копия.

---

# Ключевые термины

| Термин | Определение |
|---|---|
| **Срез** | часть последовательности `seq[start:stop:step]` |
| **`slice`** | объект `slice(start, stop, step)`, тот же срез без скобок |
| **Шаг** | `step`, через сколько брать; отрицательный — назад |
| **Поверхностная копия** | копия верхнего уровня (`a[:]`) |
| **`islice`** | ленивый срез без копирования |
| **Вид (view)** | в NumPy — ссылка на те же данные |

# Проверь себя

1. Что вернёт `[1,2,3,4,5][1:4]` и почему там нет `5`?
2. Чем `nums[::-1]` отличается от `reversed(nums)`?
3. Что сделает `nums[1:1] = [99]`?
4. Почему `matrix[:] = ...` не копирует вложенные списки?
5. Что хранит `slice(2,10,2)` и как его применить к `range(5)` через `.indices(5)`?

> [!example]- Ответы
> 1. `[2,3,4]` — `stop` не включается, берутся индексы 1,2,3.
> 2. `nums[::-1]` — новый список-копия в обратном порядке; `reversed(nums)` — ленивый итератор без копии.
> 3. Вставку `99` на позицию 1 без удаления.
> 4. Срез копирует только внешний список, вложенные остаются теми же объектами (ссылки).
> 5. `slice(2,10,2)` — «с 2 до 10 шаг 2»; `.indices(5)` урезает до длины 5 → `(2,5,2)`, реально `[2,4]`.
